# DSArc

JavaScript ভিত্তিক DSA (Data Structures and Algorithms) শেখার প্ল্যাটফর্ম, সম্পূর্ণ বাংলায়। গোছানো ডকুমেন্টেশন, চলমান কোড উদাহরণ এবং ইন্টারঅ্যাক্টিভ অ্যানিমেটেড ভিজ্যুয়ালাইজার দিয়ে একজন শিক্ষার্থী একদম শুরু থেকে ধাপে ধাপে DSA আয়ত্ত করতে পারবে।

## স্ট্যাক

- **Next.js** (App Router)
- **Fumadocs** (MDX ভিত্তিক ডকুমেন্টেশন ফ্রেমওয়ার্ক)
- **Tailwind CSS v4** + **shadcn/ui** (Base UI)
- **Motion** (অ্যানিমেশন, ভিজ্যুয়ালাইজারের জন্য)
- শেখার অগ্রগতি সংরক্ষণ হয় ব্রাউজারের localStorage-এ, কোনো অ্যাকাউন্ট লাগে না

## কনটেন্ট কোথায়

- `content/docs/` এ সাইটের সব পাঠ্য MDX ফাইলে থাকে। সোর্স কোড দেখলেই পুরো কনটেন্ট পড়া যায়।
- `docs/` ফোল্ডারে মূল কোর্স ম্যাটেরিয়াল (raw `.md` ফাইল) থাকে, সাইটের কনটেন্ট এখান থেকেই তৈরি হয়।

## চালানো

```bash
npm install
npm run dev
```

তারপর খুলো: http://localhost:3000

## গঠন

```
content/docs/       সাইটের MDX কনটেন্ট (সেকশন ও সাবসেকশন)
docs/               মূল কোর্স ম্যাটেরিয়াল (.md)
src/app/(home)/     ল্যান্ডিং পেজ
src/app/docs/       ডকুমেন্টেশন রুট
src/components/     UI কম্পোনেন্ট (shadcn)
src/lib/            shared config, progress tracking
```
