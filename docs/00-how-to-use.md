## ১. প্রতিটা Subsection-এর স্ট্যান্ডার্ড টেমপ্লেট

প্রতিটা টপিক নিচের ৭টা অংশে ভাগ করা থাকবে। এই কাঠামো পুরো কোর্সে একই থাকবে, তাই পাঠক সহজে অভ্যস্ত হয়ে যাবে।

| ক্রম | অংশ | কী থাকে |
|---:|------|---------|
| ১ | **কী শিখব** | এই টপিক শেষে পাঠক কী পারবে, সংক্ষিপ্ত লক্ষ্য |
| ২ | **ধারণা** | সহজ বাংলায় ব্যাখ্যা, সাথে বাস্তব জীবনের উদাহরণ (analogy) |
| ৩ | **কোড উদাহরণ** | কপি করে সরাসরি রান করা যায় এমন JavaScript |
| ৪ | **কোড ব্রেকডাউন** | কোডের লাইন ধরে ধরে ব্যাখ্যা |
| ৫ | **Complexity** | Time ও Space complexity, Big-O নোটেশনে |
| ৬ | **Animation Spec** | এই টপিকের visualizer কেমন হবে তার বর্ণনা |
| ৭ | **অনুশীলন** | নিজে সমাধান করার মতো প্র্যাকটিস সমস্যা |

## ২. কোড লেখার কনভেনশন

সব কোড একই ধরনের হবে, যাতে পাঠকের চোখ বুলোলেই বোঝা যায়:

- **ভাষা:** আধুনিক JavaScript (ES2020+): `const`/`let`, arrow function, `class`, `Map`, `Set`
- **`var` কখনোই না:** পুরনো ও সমস্যাজনক (function scope, hoisting-জটিলতা)। সবসময় `const`, মান বদলাতে হলে তবেই `let`
- **কমেন্ট:** বাংলা + English মিশিয়ে। টেকনিক্যাল টার্ম English-এ, ব্যাখ্যা বাংলায়
- **ভেরিয়েবল নাম:** English-এ ও অর্থপূর্ণ (`i`, `temp` নয়; `index`, `current`)
- **রানযোগ্য:** প্রতিটা কোড কপি করে সরাসরি রান করা যাবে, কোনো অংশ বাদ পড়া থাকবে না

একই কোড খারাপ ও ভালো স্টাইলে:

```js
// খারাপ: var, অর্থহীন নাম
function f(a) {
  var t = 0;
  for (var i = 0; i < a.length; i++) {
    t = t + a[i];
  }
  return t;
}
```

```js
// ভালো: const/let, অর্থপূর্ণ নাম, for...of loop
// একটি array-এর সব সংখ্যার যোগফল বের করি
function sum(numbers) {
  let total = 0;                    // যোগফল জমা রাখার box
  for (const n of numbers) {        // প্রতিটা সংখ্যার উপর loop
    total += n;                     // total-এর সাথে যোগ করি
  }
  return total;
}

console.log(sum([1, 2, 3, 4])); // 10
```

## ৩. Animation Spec: বিস্তারিত ফরম্যাট

প্রতিটা টপিকে ধাপে ধাপে একটা **interactive visualizer** যুক্ত হবে, যেখানে পাঠক ইনপুট পাল্টে দেখতে পারবে অ্যালগরিদম ঠিক কীভাবে কাজ করে। প্রতিটা subsection-এ ওই visualizer-এর বর্ণনা থাকবে ৫টা নির্দিষ্ট অংশে:

| অংশ | কী বলা থাকে |
|------|-------------|
| **দৃশ্য (Visual)** | স্ক্রিনে কী দেখা যাবে: বার, নোড, তীর, গ্রিড ইত্যাদি |
| **ইনপুট (Configurable Inputs)** | পাঠক কী কী বদলাতে পারবে: array-এর মান, target সংখ্যা, node সংখ্যা, speed |
| **ধাপ (Animation Steps)** | প্রতিটা ফ্রেমে কী ঘটবে, কোন এলিমেন্ট কোন রঙে highlight হবে |
| **নিয়ন্ত্রণ (Controls)** | Play / Pause / Step-forward / Step-back / Reset / Speed |
| **লক্ষ্য (What to observe)** | অ্যানিমেশনটা দেখে পাঠকের কী উপলব্ধি হওয়ার কথা |

লেখার ফরম্যাট:

```markdown
> **Animation Spec: <নাম>**
>
> - **দৃশ্য (Visual):** ...
> - **ইনপুট (Configurable Inputs):** ...
> - **ধাপ (Animation Steps):** ...
> - **নিয়ন্ত্রণ (Controls):** Play / Pause / Step-forward / Step-back / Reset / Speed
> - **লক্ষ্য (What to observe):** ...
```

### রঙের স্ট্যান্ডার্ড (সব visualizer-এ একই)

| অবস্থা | রঙ | কালার কোড | মানে |
|--------|-----|-----------|------|
| Default | ধূসর-নীল | `#64748b` | সাধারণ এলিমেন্ট |
| Comparing | হলুদ | `#eab308` | এখন তুলনা হচ্ছে |
| Active/Pointer | কমলা | `#f97316` | বর্তমান pointer/index |
| Swapping | লাল | `#ef4444` | জায়গা বদল হচ্ছে |
| Sorted/Done | সবুজ | `#22c55e` | চূড়ান্ত/সম্পন্ন |
| Visited | বেগুনি | `#a855f7` | আগে দেখা হয়েছে (graph/tree) |

### নমুনা: Linear Search-এর Animation Spec

> **Animation Spec: Linear Search**
>
> - **দৃশ্য:** একসারি box, প্রতিটাতে একটা সংখ্যা। উপরে target দেখানো।
> - **ইনপুট:** array-এর মান (editable), target সংখ্যা।
> - **ধাপ:** বাম থেকে ডানে একটা কমলা pointer সরবে; প্রতিটা box-এ থামলে হলুদ (comparing); মিলে গেলে সবুজ; না মিললে ধূসর করে পরের box-এ যাবে।
> - **নিয়ন্ত্রণ:** Play/Pause, Step, Speed, Reset।
> - **লক্ষ্য:** কেন worst case-এ পুরো array দেখতে হয়, অর্থাৎ O(n) শরীর দিয়ে অনুভব করা।

## ৪. Complexity নোটেশন (দ্রুত রেফারেন্স)

| নোটেশন | নাম | উদাহরণ | n = ১০০০ হলে প্রায় |
|--------|-----|--------|--------------------|
| O(1) | Constant | array index access | ১ ধাপ |
| O(log n) | Logarithmic | binary search | ১০ ধাপ |
| O(n) | Linear | একবার loop | ১ হাজার ধাপ |
| O(n log n) | Linearithmic | merge/quick sort | ১০ হাজার ধাপ |
| O(n²) | Quadratic | nested loop | ১০ লাখ ধাপ |
| O(2ⁿ) | Exponential | naive recursion | গণনার বাইরে |
| O(n!) | Factorial | permutation | ভাবনার বাইরে |

এই টেবিল শুধু চেনার জন্য। প্রতিটা নোটেশন কীভাবে বের করতে হয়, কেন এমন হয়, সব বিস্তারিত Section 03 (Algorithmic Complexity) অধ্যায়ে আছে।
