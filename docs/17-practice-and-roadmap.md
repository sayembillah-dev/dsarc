# ১৭: Practice & Roadmap to Expertise

শেখা শেষ নয়, শুরু। DSA-তে ভালো হওয়ার একমাত্র পথ - **নিয়মিত সমস্যা সমাধান**। এই section-এ কোথায় প্র্যাকটিস করবে, কীভাবে করলে দ্রুত ভালো হবে, আর beginner থেকে expert-এর একটা বাস্তব রোডম্যাপ।

## 17.2: কীভাবে একটা সমস্যা সমাধান করবে (Framework)

**কী শিখব**
- এলোমেলোভাবে না, একটা কাঠামো মেনে সমস্যা ধরা

**ধারণা**
ভালো problem solver-রা কোড লেখার আগেই ভাবে। এই ৬ ধাপ মেনে চললে অচেনা সমস্যাও গোছানো লাগবে:

1. **বুঝো (Understand):** ইনপুট/আউটপুট কী? edge case? উদাহরণ হাতে চালাও।
2. **উদাহরণ আঁকো:** ছোট ইনপুটে হাতে সমাধান করো - প্যাটার্ন চোখে পড়বে।
3. **Brute force ভাবো:** সবচেয়ে সরল (হয়তো ধীর) সমাধান আগে - কিছু না থাকার চেয়ে ভালো।
4. **অপ্টিমাইজ করো:** কোন প্যাটার্ন? ([section 16](16-problem-solving-techniques.md)) Two Pointer? Hash Map? Sorting? Heap?
5. **কোড লেখো:** ছোট ফাংশনে ভাগ করে, পরিষ্কার নামে।
6. **পরীক্ষা করো:** সাধারণ + edge case (খালি, ১টা উপাদান, সবচেয়ে বড়, নেগেটিভ)।

**কোড উদাহরণ (চিন্তার ধারা)**
```js
// সমস্যা: array-তে দুটো সংখ্যা যাদের যোগফল = target, তাদের index দাও।

// ধাপ 3 - Brute force: সব জোড়া চেক -> O(n²)
function twoSumBrute(nums, target) {
  for (let i = 0; i < nums.length; i++)
    for (let j = i + 1; j < nums.length; j++)
      if (nums[i] + nums[j] === target) return [i, j];
}

// ধাপ 4 - অপ্টিমাইজ: Hash Map প্যাটার্ন -> O(n)
function twoSum(nums, target) {
  const seen = new Map();               // মান -> index
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];      // এই সংখ্যাকে কার সাথে লাগবে?
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
}
console.log(twoSum([2, 7, 11, 15], 9)); // [0, 1]
```

**কোড ব্রেকডাউন**
- আগে brute force (O(n²)) - সমস্যাটা বুঝতে ও সঠিকতা যাচাইয়ে।
- তারপর "প্রতিবার বাকি সংখ্যা খুঁজছি" -> Hash Map (O(1) খোঁজা) দিয়ে O(n)।
- এই "brute -> optimize" যাত্রাটাই interview-তে দেখাতে হয়।

> **Animation Spec: Brute vs Optimized**
> - **দৃশ্য:** একই ইনপুটে দুই প্যানেল - বাঁয়ে O(n²) নেস্টেড লুপ, ডানে O(n) hash map।
> - **ইনপুট:** array, target।
> - **ধাপ:** দুই পাশে ধাপ-গণনা counter বাড়ে; hash map-এ মান জমা হওয়া দেখানো।
> - **নিয়ন্ত্রণ:** array সাইজ, speed।
> - **লক্ষ্য:** একই ফল, বিশাল ধাপ-পার্থক্য।

**অনুশীলন**
- এই ৬ ধাপে "একটা string palindrome কিনা" সমাধান করো।

## 17.3: প্যাটার্ন চেনার চিটশিট

**কী শিখব**
- সমস্যার ইঙ্গিত দেখে কোন কৌশল লাগবে আন্দাজ করা

**ধারণা**
বেশিরভাগ interview সমস্যা কয়েকটা চেনা প্যাটার্নের ছদ্মবেশ। ইঙ্গিত ধরতে পারলে অর্ধেক কাজ শেষ:

| ইঙ্গিত (সমস্যায় যা দেখবে) | সম্ভাব্য কৌশল |
|--------------------------|--------------|
| Sorted array, জোড়া/triplet | **Two Pointer** |
| টানা subarray/substring, "window" | **Sliding Window** |
| "সব কম্বিনেশন/পারমুটেশন/subset" | **Backtracking** |
| "সর্বোচ্চ/সর্বনিম্ন/কয় উপায়", overlapping subproblem | **DP** |
| Linked list-এ cycle/মধ্য | **Fast & Slow Pointer** |
| Top-K / k-তম | **Heap / Quickselect** |
| চলমান median | **Two Heaps** |
| রেঞ্জ/interval একত্র | **Merge Intervals** |
| 1..n সংখ্যা, missing/duplicate | **Cyclic Sort** |
| গ্রিড/matrix-এ অঞ্চল | **Grid DFS/BFS** |
| শব্দ/prefix খোঁজা | **Trie** |
| গ্রাফে ছোট পথ | **BFS (unweighted) / Dijkstra (weighted)** |
| "প্রতি ধাপে সেরা বাছাই" | **Greedy** |

**ব্রেকডাউন**
- এটা মুখস্থ নয়, বহু সমস্যা করলে নিজে থেকেই আসবে - চিটশিট শুধু গতি বাড়ায়।
- একই সমস্যায় একাধিক কৌশল খাটতে পারে; brute থেকে শুরু করে সেরাটায় যাও।

> **Animation Spec: Pattern Matcher**
> - **দৃশ্য:** সমস্যার বর্ণনা কার্ড; মূল শব্দ (keyword) highlight হয়ে সম্পর্কিত প্যাটার্নে তীর যায়।
> - **ইনপুট:** সমস্যার টেক্সট নির্বাচন।
> - **ধাপ:** keyword ধরা পড়ে -> মিলে যাওয়া প্যাটার্ন কার্ড জ্বলে ওঠে।
> - **নিয়ন্ত্রণ:** সমস্যা পাল্টানো।
> - **লক্ষ্য:** ইঙ্গিত -> কৌশল ম্যাপিং গেঁথে নেওয়া।

**অনুশীলন**
- সমাধান করা শেষ ৫টা সমস্যা কোন প্যাটার্নে পড়ে, লিখে রাখো।

## 17.4: Beginner থেকে Expert রোডম্যাপ

**কী শিখব**
- কোন পর্যায়ে কী করবে, একটা বাস্তব ধাপে-ধাপে পথ

**ধারণা**
তাড়াহুড়া নয়, ধারাবাহিকতা। আনুমানিক ৩টা ধাপ:

**ধাপ ১ - ভিত্তি (Foundation) - ~৪-৬ সপ্তাহ**
- Section 01-08 আয়ত্ত (JS, complexity, array, linked list, stack/queue, hash, recursion)।
- LeetCode **Easy** ৪০-৫০টা; Edabit warm-up।
- লক্ষ্য: syntax নিয়ে না ভেবে যেন লজিকে মন দিতে পারো।

**ধাপ ২ - মূল দক্ষতা (Core) - ~৮-১০ সপ্তাহ**
- Section 09-13 (sorting, searching, tree, heap, graph)।
- LeetCode **Medium** - টপিক ধরে ধরে (আগে array/string, পরে tree, graph, DP)।
- প্রতিটা প্যাটার্ন ([section 16](16-problem-solving-techniques.md)) থেকে ৫-১০টা সমস্যা।
- লক্ষ্য: Medium সমস্যা ৩০-৪০ মিনিটে সমাধান।

**ধাপ ৩ - উন্নত (Advanced) - চলমান**
- Section 14-15 (Trie, Segment Tree, DSU, ইত্যাদি) দরকারমতো।
- LeetCode **Hard** ধীরে ধীরে; Codeforces contest।
- Mock interview (বন্ধু/pramp/সময় ধরে নিজে)।
- লক্ষ্য: অচেনা সমস্যাও কাঠামো মেনে ভাঙা।

**ব্রেকডাউন - অভ্যাসের নিয়ম**
- **প্রতিদিন ১-২টা** সমস্যা > সপ্তাহে একদিন ১৪টা। ধারাবাহিকতাই আসল।
- একটা সমস্যায় **৩০-৪০ মিনিট** আটকে থাকলে solution পড়ো - কিন্তু পড়ে বুঝে **নিজে আবার কোড করো**।
- সমাধান করা সমস্যা **কয়েকদিন পর আবার** করো (spaced repetition)।
- প্রতিটা সমস্যার প্যাটার্ন + শেখা টুকে রাখো (Second Brain/নোট)।

> **Animation Spec: Journey Track**
> - **দৃশ্য:** তিন ধাপের একটা পথ (green -> yellow -> red), মাইলফলকসহ; ব্যবহারকারীর অগ্রগতি চিহ্ন এগোয়।
> - **ইনপুট:** সাপ্তাহিক সমাধান-সংখ্যা, difficulty মিশ্রণ।
> - **ধাপ:** লক্ষ্য পূরণে মাইলফলক আনলক; পিছিয়ে থাকলে ইঙ্গিত।
> - **নিয়ন্ত্রণ:** সময়সীমা, দৈনিক লক্ষ্য।
> - **লক্ষ্য:** বড় পথকে ছোট, অর্জনযোগ্য ধাপে ভাঙা।

**অনুশীলন**
- নিজের জন্য একটা ৪-সপ্তাহের ধাপ-১ প্ল্যান লিখো (সপ্তাহে কয়টা, কোন টপিক)।

## 17.5: সাধারণ ভুল ও শেষ পরামর্শ

**কী শিখব**
- যে ভুলগুলো অগ্রগতি থামায়, সেগুলো এড়ানো

**ধারণা**

**করবে না:**
- শুধু solution পড়ে "বুঝে গেছি" ভেবে এগিয়ে যাওয়া - নিজে কোড না করলে শেখা হয় না।
- প্রথম দিনেই Hard ধরা - হতাশা আসে; ধাপে ধাপে ওঠো।
- একসাথে সব টপিক - একটা টপিক মোটামুটি শেষ করে পরেরটায় যাও।
- complexity উপেক্ষা - প্রতিটা সমাধানের পর Time/Space ভাবো।
- ধারাবাহিকতা ভাঙা - গতির চেয়ে নিয়মিততা বড়।

**করবে:**
- brute force দিয়ে শুরু, তারপর অপ্টিমাইজ - সবসময়।
- হাতে (কাগজে) উদাহরণ চালাও কোড লেখার আগে।
- সমাধান করা সমস্যা + প্যাটার্ন নোট করে রাখো, রিভিশন দাও।
- কমিউনিটিতে থাকো (discuss ট্যাব, বন্ধুরা) - অন্যের সমাধান থেকেও শেখা যায়।
- থামলে চলবে না - প্রতিদিন একটু।

**ব্রেকডাউন**
DSA দৌড় নয়, ম্যারাথন। ৩ মাস নিয়মিত করলে বেশিরভাগ Medium সমস্যা তোমার আয়ত্তে আসবে - আর তখন interview অনেক সহজ লাগবে।

> **Animation Spec: Consistency vs Cramming**
> - **দৃশ্য:** দুই লেখচিত্র - একটা প্রতিদিন সামান্য (steady up), আরেকটা মাঝে মাঝে গাদা (spiky, দ্রুত ভুলে যাওয়া)।
> - **ইনপুট:** দৈনিক বনাম গুচ্ছ অনুশীলন।
> - **ধাপ:** সময়ের সাথে "ধরে রাখা জ্ঞান" রেখা আঁকা - steady রেখা উপরে থাকে।
> - **নিয়ন্ত্রণ:** সময়সীমা, দৈনিক পরিমাণ।
> - **লক্ষ্য:** কেন নিয়মিততা > একদিনের গাদা পড়া।

**অনুশীলন**
- আজ থেকে একটা সাধারণ ট্র্যাকার শুরু করো: তারিখ, সমস্যা, প্যাটার্ন, এক লাইন শেখা।
