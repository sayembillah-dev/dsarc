## কী শিখব

- শেষ node আবার প্রথম node-কেই দেখায়, এমন বৃত্তাকার লিস্ট

## ধারণা

Round-robin খেলা দেখেছ? সারির শেষ জনের পর আবার প্রথম জনের পালা, কেউ বাদ পড়ে না। Circular Linked List ঠিক সেরকম।

সাধারণ list-এ শেষ node-এর next থাকে `null`, মানে "এখানেই থাম"। Circular-এ শেষ node-এর next আবার **head**-কেই দেখায়। ফলে যত খুশি ঘোরা যায়, থামার জায়গা নেই। এই কারণেই round-robin scheduling বা buffer-এ এটা খুব কাজে লাগে। তবে সাবধানতা একটাই: traversal-এ থামার শর্ত না দিলে loop চিরকাল ঘুরবেই।

```
[10] -> [20] -> [30] --.
 ^                     |
 '---------------------'
```

## কোড উদাহরণ

```js
class Node {
  constructor(value) { this.value = value; this.next = null; }
}

class CircularList {
  constructor() { this.head = null; }

  append(value) {
    const node = new Node(value);
    if (!this.head) { this.head = node; node.next = node; return; } // নিজেকেই দেখায়
    let c = this.head;
    while (c.next !== this.head) c = c.next; // শেষ node খুঁজি
    c.next = node;
    node.next = this.head;                    // বৃত্ত সম্পূর্ণ
  }

  // এক পাক ঘুরে ছাপাই (শর্ত না দিলে infinite loop!)
  printOnce() {
    if (!this.head) return;
    let c = this.head, out = [];
    do { out.push(c.value); c = c.next; } while (c !== this.head);
    console.log(out.join(" -> ") + " -> (back to head)");
  }
}

const cll = new CircularList();
cll.append(10); cll.append(20); cll.append(30);
cll.printOnce(); // 10 -> 20 -> 30 -> (back to head)
```

## কোড ব্রেকডাউন

- একটাই node থাকলে সে নিজেকেই next হিসেবে দেখায়।
- traversal-এর শর্ত হলো `c !== this.head`। এটা ভুললে infinite loop, আর বের হওয়া যাবে না।
- `do...while` নিয়েছি যাতে প্রথম node-টা অন্তত একবার তো ছাপেই।

## Complexity

- append O(n), traversal O(n)।
