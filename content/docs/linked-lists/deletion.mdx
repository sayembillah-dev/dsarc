## কী শিখব

- pointer ঘুরিয়ে node বাদ দেওয়া

## ধারণা

ধরো, কয়েকজন হাত ধরে একটা শৃঙ্খল বানিয়েছে। এবার মাঝের একজনকে সরাতে হবে। কী করবে? তার আগের হাতটা সরাসরি পরের জনটাকে ধরিয়ে দেবে। মাঝের জন বাইপাস, আর সে শৃঙ্খলে নেই।

Deletion-ও ঠিক এই কাজটাই করে। মুছতে চাওয়া node-এর **আগের** node-এর `next` ঘুরিয়ে **পরের** node-এ জুড়ে দিলেই কাজ শেষ। মাঝের node বাইপাস হয়ে যায়, ফলে শৃঙ্খলে আর থাকে না।

```
মুছি 20:  [10|•] -> [20|•] -> [30]
পরে:      [10|•] ----------> [30]
```

## কোড উদাহরণ

```js
class Node {
  constructor(value) { this.value = value; this.next = null; }
}

class LinkedList {
  constructor() { this.head = null; this.size = 0; }

  append(value) {
    const node = new Node(value);
    if (!this.head) { this.head = node; this.size++; return; }
    let current = this.head;
    while (current.next) current = current.next;
    current.next = node;
    this.size++;
  }

  // value ধারণকারী প্রথম node মুছে ফেলা
  remove(value) {
    if (!this.head) return;
    if (this.head.value === value) {        // head-ই মুছতে হলে
      this.head = this.head.next;
      this.size--; return;
    }
    let current = this.head;
    while (current.next && current.next.value !== value) {
      current = current.next;               // আগের node খুঁজি
    }
    if (current.next) {                      // পেলে বাইপাস করি
      current.next = current.next.next;
      this.size--;
    }
  }

  print() {
    const parts = [];
    let current = this.head;
    while (current) { parts.push(current.value); current = current.next; }
    console.log(parts.join(" -> ") + " -> null");
  }
}

const list = new LinkedList();
list.append(10); list.append(20); list.append(30);
list.print();     // 10 -> 20 -> 30 -> null
list.remove(20);  // মাঝের node বাইপাস
list.print();     // 10 -> 30 -> null
list.remove(10);  // head মুছলে
list.print();     // 30 -> null
```

## কোড ব্রেকডাউন

- head-টাই মুছতে হলে: `head = head.next`, ব্যাস।
- মাঝের node মুছতে হলে: আগের node-এর `next`-এ বসে যায় মুছে যাওয়া node-এর `next`।
- বাদ পড়া node-কে আর কেউ চেনে না, তাই garbage collector নিজেই পরিষ্কার করে দেয়।

## Complexity

- খুঁজে বের করা O(n), pointer বদলানো O(1)।
