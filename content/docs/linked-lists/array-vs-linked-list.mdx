## কী শিখব

- সঠিক কাঠামো বাছাই

## ধারণা

| দিক | Array | Linked List |
|-----|-------|-------------|
| Index access | **O(1)** | O(n) |
| শুরুতে insert/delete | O(n) | **O(1)** |
| Memory | কম, ধারাবাহিক | বেশি (pointer) |
| Cache-friendly | হ্যাঁ | না |
| আকার | সাধারণত fixed-ভিত্তিক | সহজে বাড়ে |

**নিয়ম:** বেশি **random access** লাগলে Array; বেশি **শুরুতে বা মাঝে insert-delete** লাগলে Linked List।

## কোড উদাহরণ

```js
// Array-এ শুরুতে insert: সবাইকে সরাতে হয়, O(n)
const arr = [2, 3, 4];
arr.unshift(1);
console.log(arr); // [1, 2, 3, 4]

// Linked List-এ শুরুতে insert: শুধু pointer বদল, O(1)
const head = { value: 2, next: { value: 3, next: { value: 4, next: null } } };
const newHead = { value: 1, next: head }; // এক ধাপেই শেষ
console.log(newHead.next.value); // 2, আগের শৃঙ্খল অটুট

// Array-এ index access সরাসরি, O(1)
console.log(arr[2]); // 3
```

## কোড ব্রেকডাউন

- `unshift` শুরুতে বসাতে গিয়ে সব উপাদান সরায়, তাই O(n)।
- linked list-এ নতুন node-এর `next`-কে পুরনো `head` বানালেই insert শেষ, তাই O(1)।
- তবে linked list-এ তৃতীয় উপাদান পেতে head থেকে হেঁটে যেতে হয়, তাই access O(n); array-তে `arr[2]` সরাসরি, O(1)।

## Complexity

- random access-এ array O(1) কিন্তু linked list O(n); শুরুতে insert/delete-এ linked list O(1) কিন্তু array O(n)।
