## কী শিখব

- node আর pointer দিয়ে linked list কীভাবে বানানো হয়

## ধারণা

ধরো, তুমি একটা treasure hunt খেলছ। প্রথম clue-তে শুধু লেখা আছে পরের clue কোথায় লুকানো। সেখানে গেলে আবার পরেরটার ঠিকানা। পুরো খেলাটা এভাবেই এগোয়, কেউ আগে থেকে পুরো তালিকা হাতে পায় না।

Linked List-ও ঠিক এমন। এখানে প্রতিটা ঘরের নাম **node**। প্রতিটা node দুটো জিনিস ধরে রাখে: (১) নিজের **data**, (২) পরের node-এর ঠিকানা, অর্থাৎ **next pointer**। মেমরিতে node গুলো যেখানে-সেখানে ছড়িয়ে থাকতে পারে, দোষ নেই। pointer-এর টান ধরে একটার পর একটা খুঁজে পাওয়া যায়, এটাই আসল।

```
[10|•] -> [20|•] -> [30|null]
 head
```

এই গঠনের সুবিধা হলো, শুরুতে কিছু ঢোকানো বা বাদ দেওয়া খুব সস্তা, O(1)। কিন্তু দামও আছে। "পঞ্চমটা কী?" জানতে চাইলে head থেকে একে একে হেঁটে যেতে হয়, O(n)। Array-এর মতো index দিয়ে সরাসরি লাফানো যায় না।

## কোড উদাহরণ

```js
class Node {
  constructor(value) {
    this.value = value;   // ডেটা
    this.next = null;     // পরের node-এর দিকে তীর
  }
}

// হাতে জোড়া লাগাই: 10 -> 20 -> 30
const a = new Node(10);
const b = new Node(20);
const c = new Node(30);
a.next = b;
b.next = c;

console.log(a.value);           // 10
console.log(a.next.value);      // 20
console.log(a.next.next.value); // 30
```

## কোড ব্রেকডাউন

- `Node` মানে দুটো জিনিস একসাথে: data আর next।
- `a.next = b` লিখলেই a থেকে b-র দিকে তীর টানা পড়ল।
- শেষ node-এর `next` থাকে `null`, মানে "এর পরে আর কেউ নেই"।

## Complexity

- শুরুতে insert/delete O(1), কিন্তু index দিয়ে সরাসরি access O(n)।
