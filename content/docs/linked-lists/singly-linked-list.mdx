## কী শিখব

- একটা সত্যি চলমান singly linked list class বানানো
- prepend কেন O(1) আর append কেন O(n), pointer ঘুরিয়ে দেখে
- প্রতিটা অপারেশনের ভেতরে একই traversal ছক ফিরে ফিরে আসে
- খালি লিস্ট, এক node-এর লিস্ট, এই edge case গুলো সামলানো

## ধারণা

রশির প্রথম প্রান্তটা ধরে রাখলে পুরো রশিই তোমার হাতে, তাই না? Linked list-এও তাই। শুধু প্রথম node-টা, অর্থাৎ `head`, ধরে রাখলেই পুরো লিস্টে পৌঁছে যাওয়া যায়। এটা আগের পেজে দেখেছ: [Linked List কী](./what-is-linked-list.mdx)।

এখন প্রশ্ন হলো, রোজকার কাজে লাগানোর মতো কাঠামো কেমন হবে? হাতে হাতে node জোড়া লাগানো তো চলে না। দরকার একটা class, যার ভেতরে `head` লুকানো থাকবে, আর তুমি বাইরে থেকে শুধু বলবে "এই মানটা ঢোকাও", "এই মানটা আছে কিনা বলো"। চারটা জরুরি কাজ যোগ করব: `prepend` (শুরুতে ঢোকানো), `append` (শেষে ঢোকানো), `find` (মান খোঁজা) আর `print`।

একটা জিনিস আগেই বলে রাখি, কারণ এটাই এই পেজের আসল শিক্ষা: **prepend O(1), append O(n)**। কেন? prepend-এ নতুন node শুরুতেই বসে যায়, কাউকে সরতে হয় না। কিন্তু append-এ শেষ node-টা কে, সেটা জানা নেই, তাই head থেকে হেঁটে শেষে যেতে হয়। একই লিস্ট, এক অপারেশনে এক ধাপ, অন্যটায় পুরো হাঁটা।

## কোড উদাহরণ

```js
class Node {
  constructor(value) { this.value = value; this.next = null; }
}

class LinkedList {
  constructor() { this.head = null; this.size = 0; }

  // শুরুতে যোগ, O(1)
  prepend(value) {
    const node = new Node(value);
    node.next = this.head;   // ধাপ ১: নতুন node পুরনো head-কে দেখায়
    this.head = node;        // ধাপ ২: নতুন node-ই এখন head
    this.size++;
  }

  // শেষে যোগ, O(n) (শেষ node খুঁজতে হয়)
  append(value) {
    const node = new Node(value);
    if (!this.head) { this.head = node; this.size++; return; } // খালি লিস্ট
    let current = this.head;
    while (current.next) current = current.next; // শেষ node-এ দাঁড়াই
    current.next = node;
    this.size++;
  }

  // মান খোঁজা, O(n)
  find(value) {
    let current = this.head;
    while (current) {
      if (current.value === value) return current;
      current = current.next;
    }
    return null;
  }

  print() {
    const parts = [];
    let current = this.head;
    while (current) { parts.push(current.value); current = current.next; }
    console.log(parts.join(" -> ") + " -> null");
  }
}

const list = new LinkedList();
list.append(10); list.append(20); list.prepend(5);
list.print();               // 5 -> 10 -> 20 -> null
console.log(list.find(20)); // Node { value: 20, ... }
console.log(list.size);     // 3
```

## কোড ব্রেকডাউন: লাইনে লাইনে

1. `constructor`-এ `head = null` আর `size = 0`। নতুন লিস্ট মানে খালি লিস্ট, প্রথম node-ই নেই।
2. `prepend`-এ আগে নতুন node বানাই। তারপর **আগে** `node.next = this.head`, **তারপর** `this.head = node`। এই ক্রমটা পাল্টালেই বিপদ, নিচে ভুল ১-এ দেখব।
3. `append`-এ প্রথম চেকই খালি লিস্ট কিনা। `head` null হলে নতুন node-ই head হয়ে যায়, হাঁটার কিছুই নেই।
4. `while (current.next) current = current.next;` লক্ষ করো, শর্তটা `current` নয়, `current.next`। কারণ আমাদের শেষ node-এ **দাঁড়াতে** হবে, শেষকে পেরিয়ে null-এ গেলে তো আর ফিরে আসা যায় না।
5. শেষ node-এ দাঁড়িয়ে `current.next = node`, ব্যাস, জোড়া লাগল।
6. `find`-এ শর্ত `while (current)`, কারণ শেষ node-টাও চেক করতে হবে। মিললেই সাথে সাথে return, মানে ভাগ্য ভালো হলে আধা লিস্টেই কাজ শেষ হতে পারে।
7. `print`-এ array-তে জমা করে শেষে একসাথে ছাপি, আলাদা আলাদা console.log-এর ঝামেলা নেই।
8. প্রতিটা insert-এ `size++` ভুললে `size` আর আসল node সংখ্যা মিলবে না। ছোট্ট জিনিস, বড় সমস্যা।

## Dry run: prepend আর append, ধাপে ধাপে

ধরো, লিস্ট এখন `10 -> 20 -> null`, head 10-কে দেখায়।

**`prepend(5)` চালাই:**

| ধাপ | লাইন | কী ঘটল | লিস্টের অবস্থা |
|-----|------|---------|----------------|
| 1 | `const node = new Node(5)` | নতুন node তৈরি, next = null | `10 -> 20` আর আলাদা ভাসছে `[5\|null]` |
| 2 | `node.next = this.head` | 5-এর তীর 10-এর দিকে | `[5\|•] -> 10 -> 20` |
| 3 | `this.head = node` | head লেবেল 5-এ উঠে এলো | head -> `5 -> 10 -> 20 -> null` |

মোট দুটো pointer বদল। n যাই হোক, এই দাম একই থাকে। এজন্যই O(1)।

**এবার `append(30)` চালাই (লিস্ট এখন `5 -> 10 -> 20`):**

| ধাপ | current কোথায় | current.next | কী করি |
|-----|----------------|--------------|--------|
| 1 | 5 | আছে (10) | এগিয়ে যাই |
| 2 | 10 | আছে (20) | এগিয়ে যাই |
| 3 | 20 | null, লুপ থামে | `current.next = node`, 30 জুড়ে গেল |

n টা node থাকলে n-1 ধাপ হাঁটা, তারপর একটা pointer বদল। এজন্যই O(n)। ভাবো তো, যদি `tail` নামে শেষ node-টাও ধরে রাখতাম? তাহলে append-ও O(1) হতো। সেই আইডিয়াটা [doubly linked list](./doubly-linked-list.mdx)-এ ফিরে আসবে।

## Complexity: কোথায় কত দাম

| কাজ | Cost | কেন |
|-----|------|-----|
| prepend | O(1) | দুটো pointer বদল, লিস্টের দৈর্ঘ্যের উপর নির্ভর করে না |
| append | O(n) | শেষ node খুঁজতে পুরো লিস্ট হাঁটা (tail pointer থাকলে O(1) করা যায়) |
| find | O(n) | worst case-এ শেষ node পর্যন্ত দেখতে হয় |
| print | O(n) | প্রতিটা node-এ একবার করে যেতেই হয় |
| Space | O(n) | n টা node, প্রতিটায় value + next |

তুলনা করো array-এর সাথে। Array-তে [শুরুতে ঢোকাতে](../arrays-strings/array-operations.mdx) সবাইকে এক ঘর সরাতে হয়, O(n)। এখানে prepend সেই কাজটাই O(1)-এ করে দিচ্ছে। এটাই linked list-এর জেতার জায়গা।

## সাধারণ ভুল আর edge case

1. **prepend-এ ক্রম পাল্টে দেওয়া।** আগে `this.head = node` বসিয়ে দিলে পুরনো head-এর ঠিকানা হারিয়ে যায়, তারপর `node.next = this.head` লিখলে node নিজেকেই দেখায়। পুরো পুরনো লিস্ট উধাও। সোনার নিয়ম: আগে তীর টানো, তারপর লেবেল সরাও।
2. **append-এ খালি লিস্টের কেস ভুলে যাওয়া।** `head` null অবস্থায় `current.next` পড়তে গেলেই TypeError। তাই প্রথম লাইনেই `if (!this.head)` চেক।
3. **find-এ `while (current.next)` লেখা।** এতে শেষ node-টা চেকই হয় না। খোঁজার জায়গায় সবসময় `while (current)`, দাঁড়ানোর জায়গায় (append-এর মতো) `while (current.next)`।
4. **`size` আপডেট করা ভুলে যাওয়া।** insert/delete-এর পর size না বাড়ালে বা না কমালে পরে সেই size-এর উপর ভরসা করে লেখা সব লজিক ভুল ফল দেবে।
5. **লুপে `current = current.next` না লেখা।** এগিয়ে যাওয়ার লাইন ভুলে গেলে `current` প্রথম node-এই আটকে থাকে, প্রোগ্রাম infinite loop-এ। প্রতিটা while লুপ লিখে প্রথম কাজ: এগোনোর লাইনটা আছে তো?

## অনুশীলন

1. **সহজ:** একটা খালি লিস্টে তিনবার `prepend` করো: 30, 20, 10। তারপর print। কী অর্ডারে সাজালো, কেন এমন হলো ভেবে বলো। *Hint: প্রতিবার নতুনটা সামনে ঢুকছে।*
2. **সহজ:** `getLast()` মেথড লেখো, যেটা শেষ node-এর value দেয়; খালি লিস্টে `null` দেয়। *Hint: append-এর হাঁটার ছকটাই লাগবে, শুধু শেষে value ফেরত দাও।*
3. **মাঝারি:** `insertAt(index, value)` মেথড লেখো। *Hint: index 0 হলে সরাসরি prepend ডাকো। নাহলে index-1 পর্যন্ত হেঁটে গিয়ে সেখানে তীর দুটো বদলাও: `node.next = current.next`, তারপর `current.next = node`। index বড় হলে কিছুই করো না।*
4. **মাঝারি:** লিস্টটা in-place reverse করো, মানে `1 -> 2 -> 3` থেকে `3 -> 2 -> 1` বানাও, নতুন লিস্ট ছাড়া। *Hint: তিনটা pointer লাগবে: `prev`, `current`, `next`। প্রতি ধাপে `current.next` কে `prev`-এর দিকে ঘুরিয়ে দাও, তারপর তিনজনকে এক ধাপ এগাও। ইন্টারভিউর সুপারহিট প্রশ্ন এটা।*
5. **কঠিন:** লিস্টে cycle আছে কিনা বের করো, মানে কোনো node-এর next কি আবার আগের কোনো node-কে দেখাচ্ছে? *Hint: `slow` এক ধাপ, `fast` দুই ধাপ করে চালাও। cycle থাকলে fast কোনো না কোনো সময় slow-কে ধরে ফেলবেই। থাকলে দুজনের দেখা হলেই true, fast null পেলে false।*

## সারসংক্ষেপ

- একটা ব্যবহারযোগ্য লিস্ট মানে `head` আর `size` লুকানো একটা class, বাইরে থেকে শুধু মেথড ডাকা।
- prepend O(1), কারণ শুধু দুটো pointer বদলায়; append O(n), কারণ শেষ পর্যন্ত হেঁটে যেতে হয়।
- আগে তীর টানো, তারপর লেবেল সরাও, এই ক্রম ভুললেই লিস্ট উধাও।
- খালি লিস্ট আর এক node-এর লিস্ট, এই দুটো edge case সবসময় আলাদা ভেবো।
