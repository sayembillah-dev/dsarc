## কী শিখব

- graph কোডে কীভাবে রাখব

## ধারণা

graph-টা মাথায় পরিষ্কার। কিন্তু কোডে রাখবে কীভাবে? দুটো প্রধান উপায় আছে:

- **Adjacency List:** প্রতিটা vertex-এর পাশে তার প্রতিবেশীদের লিস্ট রাখো (`Map` দিয়ে)। edge কম থাকলে (sparse graph) এটাই দক্ষ, জায়গা লাগে O(V + E)।
- **Adjacency Matrix:** একটা V×V গ্রিড বানাও। `matrix[i][j] = 1` মানে i থেকে j-তে edge আছে। edge আছে কিনা চেক করা O(1), কিন্তু জায়গা লাগে O(V²)। তাই dense graph হলে ভালো, নইলে অপচয়।

বাস্তবে বেশিরভাগ সমস্যায় তুমি **adjacency list**-ই ব্যবহার করবে।

## কোড উদাহরণ

```js
class Graph {
  constructor() { this.adj = new Map(); }

  addVertex(v) { if (!this.adj.has(v)) this.adj.set(v, []); }

  addEdge(u, v) {                 // undirected
    this.addVertex(u); this.addVertex(v);
    this.adj.get(u).push(v);
    this.adj.get(v).push(u);      // directed হলে এই লাইন বাদ
  }

  neighbors(v) { return this.adj.get(v) || []; }
}

const g = new Graph();
g.addEdge("A", "B"); g.addEdge("A", "C");
g.addEdge("B", "D"); g.addEdge("C", "D");
console.log(g.neighbors("A")); // ['B','C']
```

## কোড ব্রেকডাউন

- `Map`-এর প্রতিটা entry-তে একটা vertex আর তার প্রতিবেশীদের array। যা লাগে, সরাসরি হাতে পাবে।
- undirected graph-এ edge দুই দিকেই যোগ করছি: A জানে B-কে, B-ও জানে A-কে। directed হলে দ্বিতীয় লাইনটা বাদ, শুধু এক দিক।

## Complexity

- list: space O(V + E); matrix: space O(V²)।
