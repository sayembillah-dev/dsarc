## কী শিখব

- vertex, edge, directed/undirected, weighted

## ধারণা

ভাবো তো তোমার Facebook-এর বন্ধুদের কথা। প্রত্যেক মানুষকে একটা গোল বিন্দু ধরো, আর দুইজন বন্ধু হলে তাদের মাঝে একটা লাইন টানো। এই বিন্দুগুলোই **vertex** (node), লাইনগুলোই **edge**, আর পুরো জিনিসটা মিলিয়ে একটা **graph**। চলো এবার ধরনগুলো দেখি:

- **Undirected:** edge দুই দিকেই চলে। Facebook-এর বন্ধুত্বের মতো: তুমি কারো বন্ধু মানে সেও তোমার বন্ধু।
- **Directed (digraph):** edge একমুখী। Twitter-এ follow করার মতো: তুমি কাউকে follow করলেই যে সে তোমাকে follow করবে, এমন নিয়ম নেই (A -> B মানে B -> A নয়)।
- **Weighted:** edge-এর সাথে একটা সংখ্যা জড়ানো, যেমন দুই শহরের দূরত্ব বা রাস্তার খরচ।
- **Cycle:** একটা vertex থেকে বেরিয়ে ঘুরপথে আবার সেখানেই ফিরে আসা যায়।
- **Connected:** যেকোনো vertex থেকে বাকি সব vertex-এ পৌঁছানো যায়।

```
Undirected:  A - B        Directed:  A -> B
             |   |                    ^    |
             |   |                    |    v
             C - D                    C <- D
```

## কোড উদাহরণ

```js
// vertices: A,B,C,D ; edges: A-B, A-C, B-D, C-D
const vertices = ["A", "B", "C", "D"];
const edges = [["A", "B"], ["A", "C"], ["B", "D"], ["C", "D"]];
console.log(vertices.length, edges.length); // 4 4 (4 vertex, 4 edge)
```

## কোড ব্রেকডাউন

- Tree-ও আসলে একটা graph, শুধু cycle নেই আর সবকিছু connected। n টা node থাকলে edge হবে ঠিক n-1 টা।
- কিন্তু সাধারণ graph-এ cycle থাকতেই পারে। তাই traversal-এর সময় কোন node দেখে ফেলেছি, সেটা ট্র্যাক করা (visited) আবশ্যক। নইলে একই জায়গায় ঘুরতেই থাকবে।

<Callout type="warn" title="সতর্কতা: visited ছাড়া traversal করো না">
Graph-এ cycle থাকলে visited ট্র্যাক না করলে traversal infinite loop-এ আটকে যাবে।
</Callout>

## Complexity

- এই পাতাটা পরিভাষার, তাই আলাদা algorithmic complexity নেই। পরের পাতাগুলোর traversal-এর খরচ vertex আর edge-এর ওপর নির্ভর করে, যেমন O(V + E)।
