## কী শিখব

- সঠিক DSA বাছাই কেন এত বড় পার্থক্য গড়ে

## ধারণা

ধরো, তোমার অ্যাপে ১০ লাখ ইউজার। কেউ লগইন করলেই তার ডেটা খুঁজে বের করতে হবে। এখানেই আসল জিনিস:

- ভুল কাঠামো বেছে নিলে অ্যাপ হ্যাং হয়ে যাবে।
- সঠিক কাঠামো নিলে একই কাজ হাজার গুণ দ্রুত হবে।

সহজ কথায়, একই কাজ ভালো উপায়েও করা যায়, খারাপ উপায়েও। DSA শেখায় কোনটা **efficient**, আর কীভাবে সেটা বাছবে। আর চাকরির interview-তে? DSA প্রায় বাধ্যতামূলক।

## কোড উদাহরণ

একটা নাটকীয় উদাহরণ দেখো, খোঁজা:

```js
// ১) Array-তে খোঁজা (একটা একটা করে), ধীর
function findInArray(arr, target) {
  for (const x of arr) if (x === target) return true;
  return false;                       // worst case: পুরো array, O(n)
}

// ২) Set-এ খোঁজা, বিদ্যুৎগতি
const set = new Set([1, 2, 3, /* ...10 লাখ... */]);
console.log(set.has(999999));         // গড়ে O(1)
```

## কোড ব্রেকডাউন

- ১০ লাখ উপাদানের array-তে খুঁজলে worst case-এ ১০ লাখ তুলনা লাগতে পারে।
- একই কাজ Set-এ প্রায় সাথে সাথে। শুধু **কাঠামো বদলে** এত বড় পার্থক্য!

## Complexity

- Array-তে খোঁজা: worst case O(n), প্রতিটা উপাদান দেখতে হতে পারে।
- Set-এ খোঁজা: গড়ে O(1), প্রায় সাথে সাথে।
