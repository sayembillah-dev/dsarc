## কী শিখব

- যেকোনো সমস্যা ভাঙার একটা ঠিকঠাক পদ্ধতি

## ধারণা

নতুন সমস্যা দেখলেই মাথা খালি হয়ে যায়? স্বাভাবিক। কিন্তু ব্যাপারটা হলো, DSA মুখস্থের জিনিস না, **চিন্তার জিনিস**। আর চিন্তারও একটা রাস্তা আছে। প্রতিটা সমস্যায় এই ৫ ধাপে এগো:

1. **বুঝো (Understand):** input কী, output কী, constraint কী?
2. **উদাহরণ (Examples):** ছোট ইনপুট নিয়ে হাতে সমাধান করো।
3. **পরিকল্পনা (Plan):** pseudo code-এ ধাপ লিখে ফেলো।
4. **বাস্তবায়ন (Code):** এবার JavaScript-এ রূপ দাও।
5. **যাচাই (Test & Optimize):** edge case টেস্ট করো, আর দ্রুত করা যায় কিনা ভাবো।

## কোড উদাহরণ

চলো এই পদ্ধতিটা প্রয়োগ করি, "array-তে duplicate আছে কিনা":

```js
// ধাপ ৩-৪: পরিকল্পনা ও কোড
function hasDuplicate(arr) {
  const seen = new Set();          // যা দেখেছি জমা রাখি
  for (const x of arr) {
    if (seen.has(x)) return true;  // আগে দেখেছি, অর্থাৎ duplicate
    seen.add(x);
  }
  return false;                    // কোনো duplicate নেই
}

// ধাপ ৫: টেস্ট
console.log(hasDuplicate([1, 2, 3, 2])); // true
console.log(hasDuplicate([1, 2, 3]));    // false
```

## কোড ব্রেকডাউন

- naive উপায় হতো nested loop (O(n²))।
- Set ব্যবহার করায় নেমে এলো O(n)-তে। সঠিক DSA বাছাইয়ের সুফলই এটা।
- edge case: খালি array, সব একই মান, এগুলো টেস্ট করা জরুরি।

## Complexity

- naive (nested loop) উপায়: O(n²) time।
- Set ব্যবহার করা উপায়: O(n) time, O(n) space (seen set-এ সব মান জমা হতে পারে)।
