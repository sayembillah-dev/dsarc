## কী শিখব

- যেকোনো সমস্যা ভাঙার একটা ঠিকঠাক পদ্ধতি

## ধারণা

নতুন সমস্যা দেখলেই মাথা খালি হয়ে যায়? স্বাভাবিক। কিন্তু ব্যাপারটা হলো, DSA মুখস্থের জিনিস না, **চিন্তার জিনিস**। আর চিন্তারও একটা রাস্তা আছে। প্রতিটা সমস্যায় এই ৫ ধাপে এগো:

1. **বুঝো (Understand):** input কী, output কী, constraint কী?
2. **উদাহরণ (Examples):** ছোট ইনপুট নিয়ে হাতে সমাধান করো।
3. **পরিকল্পনা (Plan):** pseudo code-এ ধাপ লিখে ফেলো।
4. **বাস্তবায়ন (Code):** এবার JavaScript-এ রূপ দাও।
5. **যাচাই (Test & Optimize):** edge case টেস্ট করো, আর দ্রুত করা যায় কিনা ভাবো।

## কোড উদাহরণ

চলো এই পদ্ধতিটা প্রয়োগ করি, "array-তে duplicate আছে কিনা":

```js
// ধাপ ৩-৪: পরিকল্পনা ও কোড
function hasDuplicate(arr) {
  const seen = new Set();          // যা দেখেছি জমা রাখি
  for (const x of arr) {
    if (seen.has(x)) return true;  // আগে দেখেছি, অর্থাৎ duplicate
    seen.add(x);
  }
  return false;                    // কোনো duplicate নেই
}

// ধাপ ৫: টেস্ট
console.log(hasDuplicate([1, 2, 3, 2])); // true
console.log(hasDuplicate([1, 2, 3]));    // false
```

## কোড ব্রেকডাউন

- naive উপায় হতো nested loop (O(n²))।
- Set ব্যবহার করায় নেমে এলো O(n)-তে। সঠিক DSA বাছাইয়ের সুফলই এটা।
- edge case: খালি array, সব একই মান, এগুলো টেস্ট করা জরুরি।

## Complexity

- naive (nested loop) উপায়: O(n²) time।
- Set ব্যবহার করা উপায়: O(n) time, O(n) space (seen set-এ সব মান জমা হতে পারে)।

## আরেকটা উদাহরণ: FizzBuzz দিয়ে পুরো পদ্ধতি

Interview-র সবচেয়ে বিখ্যাত warmup সমস্যাটা দিয়ে ৫ ধাপটা আরেকবার চালাও। নিয়ম: ১ থেকে n পর্যন্ত ছাপাও, তবে ৩-এর গুণিতক হলে "Fizz", ৫-এর হলে "Buzz", দুটোরই গুণিতক হলে "FizzBuzz"।

১. **বুঝো:** input একটা সংখ্যা n, output নিয়ম মেনে সাজানো তালিকা।
২. **উদাহরণ:** n = 15 হলে হাতের হিসাব: 1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz। 15-এ প্রথমবার দুটো শর্ত একসাথে মিলল, তাই "FizzBuzz"।
৩. **পরিকল্পনা:** প্রতিটা সংখ্যায় আগে দেখো দুটোরই গুণিতক (১৫) কিনা, না হলে ৩-এর, না হলে ৫-এর, কিছুই না হলে সংখ্যাটাই বসাও।
৪. **বাস্তবায়ন:**

```js
function fizzBuzz(n) {
  const out = [];
  for (let i = 1; i <= n; i++) {
    if (i % 15 === 0) out.push("FizzBuzz"); // বিশেষ শর্ত আগে
    else if (i % 3 === 0) out.push("Fizz");
    else if (i % 5 === 0) out.push("Buzz");
    else out.push(i);
  }
  return out;
}
console.log(fizzBuzz(15).join(", "));
// 1, 2, Fizz, 4, Buzz, Fizz, 7, 8, Fizz, Buzz, 11, Fizz, 13, 14, FizzBuzz
```

৫. **যাচাই:** edge case গুনে দেখো: n = 1 হলে শুধু [1], n = 0 হলে খালি তালিকা। সময় O(n), জায়গা O(n) (output রাখতে)।

এই সমস্যার আসল শিক্ষাটা শর্তের **ক্রমে**। `% 3`-এর শর্তটা আগে বসালে 15 "Fizz"-এই আটকে যাবে, "FizzBuzz" জন্মই নেবে না। তাই নিয়ম: **বিশেষ শর্ত আগে, সাধারণ শর্ত পরে।** আরেকটা সুষ্ঠু উপায়ও আছে, যেখানে ক্রমের দুশ্চিন্তাই নেই: প্রতি সংখ্যায় একটা খালি string নাও, ৩-এর গুণিতক হলে "Fizz" জোড়া, ৫-এর হলে "Buzz" জোড়া; দুটোই মিললে নিজে নিজেই "FizzBuzz" হয়ে যায়, আর string খালি থাকলে সংখ্যাটাই বসে যায়।
