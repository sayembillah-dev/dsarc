## কী শিখব

- কোড দেখে Big-O বের করার নিয়ম

## ধারণা

Interview-তে code দেখিয়ে জিজ্ঞেস করল, "এটার Big-O কত?" ঘাবড়ানোর কিছু নেই। মাত্র ৩টা নিয়ম মনে রাখলেই চলবে:

1. **ধ্রুবক বাদ দাও:** O(2n) মানেই O(n), O(500) মানেই O(1)
2. **সবচেয়ে বড় term-টাই রাখো:** O(n² + n) মানে O(n²)
3. **Loop গোনো:**
   - একটা loop মানে O(n)
   - loop-এর ভেতর আরেকটা loop মানে O(n²)
   - প্রতিবার অর্ধেক হয়ে গেলে O(log n)

## কোড উদাহরণ

```js
// উদাহরণ ১: দুটো আলাদা loop, অর্থাৎ O(n + n) = O(n)
function example1(arr) {
  for (const x of arr) console.log(x);   // O(n)
  for (const x of arr) console.log(x*2); // O(n)
}                                        // মোট O(n)

// উদাহরণ ২: নেস্টেড loop, অর্থাৎ O(n²)
function example2(arr) {
  for (const a of arr)
    for (const b of arr)
      console.log(a, b);
}

// উদাহরণ ৩: প্রতিবার অর্ধেক, অর্থাৎ O(log n)
function example3(n) {
  while (n > 1) n = Math.floor(n / 2);
}

example1([1, 2, 3]);
example2([1, 2]);
example3(16);
```

## কোড ব্রেকডাউন

- example1: দুটো O(n) মিলে O(2n), ধ্রুবক বাদ দিলে থাকে **O(n)**।
- example2: প্রতিটা element-এর জন্য পুরো array ঘুরতে হচ্ছে, তাই **O(n²)**।
- example3: n থেকে n/2, তারপর n/4 ... এভাবে অর্ধেক হতে হতে শেষ, **O(log n)**।
