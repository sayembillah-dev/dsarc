## কী শিখব

- তিনটা notation-এর পার্থক্য

## ধারণা

ধরো, তুমি একটা array-তে কোনো সংখ্যা খুঁজছো। ভাগ্য দারুণ হলে প্রথম ঘরেই পেয়ে যাবে। ভাগ্য খারাপ হলে শেষ ঘর পর্যন্ত খুঁজতেই হবে। আর গড়পড়তা থাকে মাঝখানের কোথাও।

এই তিনটা পরিস্থিতি আলাদা করে বলার জন্যই তিনটা notation:

| Notation | নাম | বোঝায় | সাধারণ ভাষায় |
|----------|-----|--------|----------------|
| **O (Big-O)** | Upper bound | worst case | "সর্বোচ্চ এত খারাপ হতে পারে" |
| **Ω (Omega)** | Lower bound | best case | "সর্বনিম্ন এত ভালো হতে পারে" |
| **θ (Theta)** | Tight bound | average/উভয় সমান | "মোটামুটি এতটাই" |

**উদাহরণ: Linear Search**

- **best case (Ω):** target প্রথম ঘরেই পাওয়া গেল, Ω(1)
- **worst case (O):** target নেই, বা একদম শেষে, O(n)
- **θ:** best আর worst একই লেভেলের হলে তখন θ ব্যবহার হয়

## কোড উদাহরণ

```js
function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i; // ভাগ্য ভালো হলে প্রথমেই, Ω(1)
  }
  return -1;                          // না পেলে পুরোটা, O(n)
}

console.log(linearSearch([4, 7, 1, 9], 1)); // 2
console.log(linearSearch([4, 7, 1, 9], 5)); // -1
```

## কোড ব্রেকডাউন

- বাস্তবে আমরা প্রায় সবসময় **Big-O (worst case)** নিয়েই কথা বলি, কারণ সবচেয়ে খারাপ পরিস্থিতিটা আগে থেকে জেনে রাখা নিরাপদ।
- আর θ তখনই বলা যায় যখন best আর worst একই, যেমন এমন code যেটা সবসময় পুরো array-টা loop করে।
