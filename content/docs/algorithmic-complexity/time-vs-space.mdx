## কী শিখব

- সময় বনাম মেমরি, দুই ধরনের খরচ

## ধারণা

ধরো, একটা array-তে duplicate আছে কি না বের করতে হবে। তুমি দুইভাবে লিখতে পারো: একদম কম মেমরিতে, কিন্তু একটু ধীরে। অথবা একটু বাড়তি মেমরি নিয়ে, অনেক দ্রুত।

এই দুই ধরনের খরচেরই আলাদা নাম আছে:

- **Time Complexity**: code চালাতে কত ধাপ/অপারেশন লাগে (গতির খরচ)
- **Space Complexity**: চলার সময় কত অতিরিক্ত মেমরি লাগে (জায়গার খরচ)

এখানেই আসল জিনিস: দুটোর মধ্যে প্রায়ই **trade-off** থাকে। বেশি মেমরি খরচ করে গতি বাড়ানো যায়, যেমন cache বা Set ব্যবহার করে। নিচের code-টা দেখলেই পরিষ্কার হবে।

## কোড উদাহরণ

```js
// কম space, কিন্তু নেস্টেড loop, তাই বেশি time (O(n²))
function hasDupSlow(arr) {
  for (let i = 0; i < arr.length; i++)
    for (let j = i + 1; j < arr.length; j++)
      if (arr[i] === arr[j]) return true;
  return false;              // Space: O(1), Time: O(n²)
}

// বেশি space (Set), কিন্তু কম time (O(n))
function hasDupFast(arr) {
  const seen = new Set();    // অতিরিক্ত মেমরি
  for (const x of arr) {
    if (seen.has(x)) return true;
    seen.add(x);
  }
  return false;              // Space: O(n), Time: O(n)
}

console.log(hasDupSlow([1, 2, 3, 2])); // true
console.log(hasDupFast([1, 2, 3, 2])); // true
```

## কোড ব্রেকডাউন

- প্রথমটা মেমরি বাঁচায়, কিন্তু ধীর।
- দ্বিতীয়টা Set রাখে বলে মেমরি বেশি খায়, কিন্তু অনেক দ্রুত। এটাই **time-space trade-off**।
