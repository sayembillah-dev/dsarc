গত section-এ Graph শিখলে। এবার চলো কয়েকটা **বিশেষায়িত কাঠামো** দেখি, যেগুলো দিয়ে নির্দিষ্ট কিছু সমস্যা অবিশ্বাস্য দ্রুততায় ফোড়া যায়: autocomplete, range query, dynamic connectivity, string matching। competitive programming হোক বা বড় সিস্টেম, সব জায়গায় এদের ভূমিকা বিশাল। আগের section-এ Kruskal চালাতে গিয়ে Union-Find কাজে লেগেছিল, মনে আছে তো? এখানে সেটাই ভেঙে ফেলে দেখব।

**Section Roadmap:** Trie, Segment Tree, Fenwick Tree (BIT), Disjoint Set (Union-Find), Suffix Trees & Arrays।

## এই Chapter-এ যা যা আছে

1. [Trie (Prefix Tree)](./trie.mdx): prefix ধরে চোখের পলকে শব্দ খোঁজা আর autocomplete
2. [Segment Tree](./segment-tree.mdx): range query আর update, দুটোই O(log n)
3. [Fenwick Tree (BIT)](./fenwick-tree.mdx): কম কোডে prefix sum আর update O(log n)
4. [Disjoint Set (Union-Find)](./disjoint-set.mdx): গোষ্ঠী মেলানো আর connectivity চেক, প্রায় O(1)
5. [Suffix Trees & Suffix Arrays](./suffix-arrays.mdx): সব suffix গুছিয়ে রেখে দ্রুত pattern matching

## সারাংশ

সহজ কথায়, এই section হলো পাঁচটা হাতিয়ারের গল্প। Trie মানে prefix tree, autocomplete চলে O(L)-এ। Segment Tree দিয়ে range query ও update, দুটোই O(log n)। Fenwick বা BIT হলো হালকা prefix-sum মেশিন, O(log n)। Union-Find দিয়ে dynamic grouping প্রায় O(1), path compression আর rank-এর জোরে। আর Suffix Array বা Tree হলো string pattern matching-এর শক্তিশালী হাতিয়ার।
