আগের section-এ Graph শিখেছ; এবার কয়েকটা **বিশেষায়িত কাঠামো**, যেগুলো নির্দিষ্ট ধরনের সমস্যা অসাধারণ দক্ষতায় সমাধান করে: autocomplete, range query, dynamic connectivity, string matching। competitive programming ও বড় সিস্টেমে এদের ভূমিকা বিশাল। আগের section-এর Kruskal-এ Union-Find কাজে লেগেছিল, এখানে সেটাই বিস্তারিত শিখবে।

**Section Roadmap:** Trie, Segment Tree, Fenwick Tree (BIT), Disjoint Set (Union-Find), Suffix Trees & Arrays।

## এই Chapter-এ যা যা আছে

1. [Trie (Prefix Tree)](./trie): prefix-ভিত্তিক দ্রুত শব্দ খোঁজা ও autocomplete
2. [Segment Tree](./segment-tree): range query ও update দুটোই O(log n)
3. [Fenwick Tree (BIT)](./fenwick-tree): কম কোডে prefix sum ও update O(log n)
4. [Disjoint Set (Union-Find)](./disjoint-set): গোষ্ঠী মেলানো ও connectivity চেক প্রায় O(1)
5. [Suffix Trees & Suffix Arrays](./suffix-arrays): সব suffix গুছিয়ে দ্রুত pattern matching

## সারাংশ

Trie অর্থাৎ prefix tree, autocomplete O(L)। Segment Tree অর্থাৎ range query ও update O(log n)। Fenwick/BIT অর্থাৎ হালকা prefix-sum O(log n)। Union-Find অর্থাৎ dynamic grouping প্রায় O(1) (path compression ও rank)। Suffix Array/Tree অর্থাৎ string pattern matching-এর শক্তিশালী হাতিয়ার।
