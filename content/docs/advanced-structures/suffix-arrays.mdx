## কী শিখব

- string-এর সব suffix গুছিয়ে দ্রুত pattern matching

## ধারণা

"banana"-র মধ্যে "nan" আছে কিনা, সেটা খোঁজা সহজ। কিন্তু ভাবো তো, লাখ লাখ অক্ষরের লেখার মধ্যে বারবার খুঁজতে হবে, আবার জিজ্ঞেস করা হবে "যে অংশটা দুইবার এসেছে, সবচেয়ে বড়টা কোনটা?" এমন প্রশ্নের উত্তরের জন্য একটা সুন্দর কৌশল আছে: string-টার সব **suffix** (শেষের দিকের অংশগুলো) নিয়ে কাজ করা।

- **Suffix Array:** সব suffix-কে বর্ণানুক্রমে সাজাও, রেখে দাও শুধু শুরুর index-গুলো। সহজ, memory কম লাগে, আর binary search দিয়ে pattern খোঁজা O(m log n)।
- **Suffix Tree:** সব suffix-কে ঢুকিয়ে দাও একটা compressed trie-তে। খোঁজা চলে O(m)-এ, কিন্তু বানানো জটিল, memory-ও অনেক খায়।

বাস্তবে বেশিরভাগ সময় **suffix array**-ই ব্যবহার হয়। সরল বটে, আবার যথেষ্ট দ্রুতও।

## কোড উদাহরণ

নিচে শেখার জন্য সরল suffix array।

```js
function buildSuffixArray(s) {
  const suffixes = [];
  for (let i = 0; i < s.length; i++) {
    suffixes.push({ index: i, suffix: s.slice(i) }); // O(n²), শেখার version
  }
  suffixes.sort((a, b) => a.suffix < b.suffix ? -1 : 1); // বর্ণানুক্রমে
  return suffixes.map(x => x.index);
}

// suffix array + binary search দিয়ে substring আছে কিনা
function contains(s, pattern) {
  const sa = buildSuffixArray(s);
  let lo = 0, hi = sa.length - 1;
  while (lo <= hi) {
    const mid = (lo + hi) >> 1;
    const suf = s.slice(sa[mid], sa[mid] + pattern.length);
    if (suf === pattern) return true;
    if (suf < pattern) lo = mid + 1; else hi = mid - 1;
  }
  return false;
}

console.log(buildSuffixArray("banana")); // suffix-দের sorted index
console.log(contains("banana", "nan"));  // true
console.log(contains("banana", "xyz"));  // false
```

## কোড ব্রেকডাউন

- সব suffix sort করে রাখলে একই prefix-ওয়ালা suffix-গুলো পাশাপাশি চলে আসে, তাই binary search দিয়েই pattern পাওয়া যায়।
- এইটা শেখার সরল version, O(n² log n)। বাস্তবে O(n log n), এমনকি O(n)-এ build করার algorithm আছে, সেগুলো advanced খাতায় পড়ে।
- Suffix tree আরও ক্ষমতাশালী ঠিকই, কিন্তু implement করা কঠিন। তাই সাধারণত suffix array-তেই কাজ চালানো হয়।

## Complexity

- সরল build O(n² log n); খোঁজা O(m log n)। (উন্নত build O(n log n)।)
