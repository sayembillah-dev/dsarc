## কী শিখব

- গোষ্ঠী (set) দ্রুত মেলানো আর "একই গোষ্ঠীতে কিনা" চেক

## ধারণা

ধরো, ক্লাসের সবাইকে কয়েকটা দলে ভাগ করা, আর প্রতি মুহূর্তে দুজনকে ধরে জিজ্ঞেস করতে হচ্ছে, "তোরা কি একই দলে?" মাঝে মাঝে আবার দুটো দল এক হয়ে যাচ্ছে। এটাই **Union-Find**-এর খেলা। অনেকগুলো উপাদান থাকে disjoint (অ-ছেদী) গোষ্ঠীতে, আর হাতে থাকে দুটো অপারেশন:

- **find(x):** x আসলে কোন গোষ্ঠীর, মানে তার representative বা root কে
- **union(a, b):** দুটো গোষ্ঠী জোড়া লাগিয়ে এক করে দাও

এখানেই আসল জিনিস। দুটো ছোট্ট কৌশল, **path compression** আর **union by rank/size**, এদের জোড়ে প্রতিটা অপারেশন প্রায় O(1) হয়ে যায় (ঠিক বললে α(n), কিন্তু ব্যবহারে ধ্রুবকের মতোই)। Kruskal MST (section 13), cycle detection, connectivity, সব জায়গায় Union-Find অপরিহার্য।

## কোড উদাহরণ

নিচের উদাহরণে দুটো অপ্টিমাইজেশনই আছে।

```js
class DSU {
  constructor(n) {
    this.parent = Array.from({ length: n }, (_, i) => i);
    this.rank = new Array(n).fill(0);
  }
  find(x) {
    if (this.parent[x] !== x) this.parent[x] = this.find(this.parent[x]); // path compression
    return this.parent[x];
  }
  union(a, b) {
    const ra = this.find(a), rb = this.find(b);
    if (ra === rb) return false;              // ইতিমধ্যে একই গোষ্ঠী
    if (this.rank[ra] < this.rank[rb]) this.parent[ra] = rb;   // union by rank
    else if (this.rank[ra] > this.rank[rb]) this.parent[rb] = ra;
    else { this.parent[rb] = ra; this.rank[ra]++; }
    return true;
  }
  connected(a, b) { return this.find(a) === this.find(b); }
}

const dsu = new DSU(5);
dsu.union(0, 1); dsu.union(1, 2);
console.log(dsu.connected(0, 2)); // true  (0-1-2 এক গোষ্ঠী)
console.log(dsu.connected(0, 3)); // false
```

## কোড ব্রেকডাউন

- **path compression:** find চলার সময় পথের প্রতিটা node-কে সরাসরি root-এর সাথে জুড়ে দিই। পরের find-টা তখন এক লাফেই শেষ।
- **union by rank:** ছোট গাছটাকে বড় গাছের নিচে ঢুকিয়ে দিই, ফলে গাছটা লম্বা না হয়ে চ্যাপ্টাই থাকে।
- `union` যদি false ফেরায়, তার মানে দুই প্রান্ত আগে থেকেই একই গোষ্ঠীতে। Kruskal-এ এটাই cycle-এর সংকেত ছিল, মনে আছে?

## Complexity

- প্রতি অপারেশন প্রায় O(α(n)) ≈ O(1)।
