## কী শিখব

- range query (যেমন range sum/min) আর update, দুটোই O(log n)

## ধারণা

ধরো, একটা array আছে আর তুমি জিজ্ঞেস করলে, "index 2 থেকে 7 পর্যন্ত যোগফল কত?" সাদামাটা উপায়ে পুরো range-টা ঘুরে যোগ করতে হয়, O(n)। এবার ভাবো, মাঝে মাঝে একটা করে element বদলে যাচ্ছে, তাহলে তো প্রতিবার নতুন করে হিসাব। বিরক্তিকর, তাই না?

**Segment Tree** এই ঝামেলার আসল সমাধান। array-টাকে recursively অর্ধেক অর্ধেক করে ভাগ করো, প্রতিটা অংশের সারাংশ (sum/min/max) জমিয়ে রাখো একটা node-এ। ফলে query হোক বা update, দুটোই চলে **O(log n)**-এ। নিচের উদাহরণটা range sum-এর।

```text
             [0-3]:সব যোগ
            /          \
        [0-1]          [2-3]
        /   \          /   \
      [0]   [1]      [2]   [3]
```

## কোড উদাহরণ

```js
class SegmentTree {
  constructor(arr) {
    this.n = arr.length;
    this.tree = new Array(2 * this.n).fill(0);
    for (let i = 0; i < this.n; i++) this.tree[this.n + i] = arr[i]; // leaves
    for (let i = this.n - 1; i > 0; i--)                              // internal
      this.tree[i] = this.tree[2 * i] + this.tree[2 * i + 1];
  }

  update(index, value) {
    let i = index + this.n;
    this.tree[i] = value;
    while (i > 1) { i = i >> 1; this.tree[i] = this.tree[2*i] + this.tree[2*i+1]; }
  }

  query(left, right) {                 // [left, right)  যোগফল
    let sum = 0, l = left + this.n, r = right + this.n;
    while (l < r) {
      if (l & 1) sum += this.tree[l++];
      if (r & 1) sum += this.tree[--r];
      l >>= 1; r >>= 1;
    }
    return sum;
  }
}

const st = new SegmentTree([1, 2, 3, 4, 5]);
console.log(st.query(1, 4)); // 2+3+4 = 9
st.update(2, 10);            // index 2-এ 10
console.log(st.query(1, 4)); // 2+10+4 = 16
```

## কোড ব্রেকডাউন

- tree-এর নিচের অর্ধেক হলো leaf, সেখানেই বসে মূল array-টা; উপরের node-গুলো তাদের যোগফল ধরে রাখে।
- update করলে শুধু ওই পথ ধরে উপরে উঠে সারাংশ ঠিক করে দিলেই চলে, O(log n)।
- query-তেও পুরো range ঘোরার দরকার নেই, ঠিকঠাক কয়েকটা node-এর সারাংশ মিলিয়ে নিলেই উত্তর, O(log n)।
- sum-এর বদলে `Math.min` বা `Math.max` বসালেই তৈরি হয়ে যাবে range-min বা range-max tree।

## Complexity

- build O(n); query/update O(log n)।
