## কী শিখব

- Level-order মানে কী, আর DFS থেকে এটা কোথায় আলাদা
- Queue দিয়ে পুরো dry run: কে ঢোকে, কে বের হয়
- `levelSize` কৌশল: কোনটা কোন স্তরের, আলাদা করা
- কেন tree-এর BFS-প্রশ্নের ৮০% এই এক ছাঁচে চলে
- Complexity আর ফাঁদগুলো

## ধারণা

[DFS](./binary-tree-traversal.mdx) যেমন এক শাখা ধরে গভীরে নেমেই যায়, **level-order** ঠিক উল্টোটা: আগে root, তারপর ওর child-দের পুরো স্তর, তারপর তাদের child-দের স্তর, সবসময় বাম থেকে ডানে। ঠিক যেন গাছের উপর দিয়ে একটা স্ক্যান লাইন নিচে নামছে।

নাম থেকেই বোঝা যাচ্ছে এটা আসলে কী: গাছের জগতে **BFS**। আর BFS মানে [Queue](../queues/queue-fifo.mdx), যে আগে ঢুকেছে সে আগে visit হবে। মনে করো সেই এক লাইনের ম্যাজিক: **stack মানে গভীরে (DFS), queue মানে পাশাপাশি (BFS)**।

## পরীক্ষার গাছ

```text
        1          ← level 0
       / \
      2   3        ← level 1
     / \
    4   5          ← level 2
```

## Dry run: queue-এর অবস্থা ধাপে ধাপে

| ধাপ | বের হলো | তার child ঢুকল | queue (বামে front) | স্তর শেষে result |
|-----|---------|------------------|--------------------|--------------------|
| শুরু | - | root ঢুকল | `[1]` | `[]` |
| 1 | 1 | 2, 3 | `[2, 3]` | `[[1]]` |
| 2 | 2 | 4, 5 | `[3, 4, 5]` | - |
| 3 | 3 | - | `[4, 5]` | `[[1], [2, 3]]` |
| 4 | 4 | - | `[5]` | - |
| 5 | 5 | - | `[]` | `[[1], [2, 3], [4, 5]]` |

দুটো জিনিস চোখে পড়ো। এক, কে বের হচ্ছে আর কে ঢুকছে, তারা দুই স্তরের: ধাপ ২-তে 2 বের হচ্ছে, কিন্তু ঢুকছে 4 আর 5, পরের স্তরের। দুই, queue সবসময় **সামনে থেকে খালি, পেছনে ভরে**, FIFO ঠিকঠাক চলছে।

## সমস্যা: স্তর আলাদা করবে কীভাবে?

শুধু ঘোরা হলে ক্রম `1, 2, 3, 4, 5`, ঠিকই। কিন্তু সমস্যাগুলো চায় স্তরভিত্তিক উত্তর: "প্রতি স্তরে কে কে", "কোন স্তরে সর্বোচ্চ যোগফল", "গাছের height কত"। Queue-তে তো সব গুলিয়ে আছে, বলবে কীভাবে 2 আর 3 আলাদা স্তরের?

চালাকি: **প্রতি স্তর শুরুর আগে queue-এর তৎকালীন আকার মনে রাখো**। ওই সংখ্যকটাই এই স্তরের, বাকিগুলো পরের স্তরের, যতই ঢুকুক।

## কোড: নিজে বানাও levelOrder

```js
function levelOrder(root) {
  if (!root) return [];

  const result = [];
  const queue = [root];

  while (queue.length > 0) {
    const levelSize = queue.length;    // এই স্তরে ঠিক এতগুলো
    const level = [];

    for (let i = 0; i < levelSize; i++) {
      const node = queue.shift();      // সামনেরটা বের
      level.push(node.value);

      if (node.left) queue.push(node.left);    // পরের স্তর পেছনে জমে
      if (node.right) queue.push(node.right);
    }

    result.push(level);
  }

  return result;
}

// গাছ: উপরেরটাই
const r = new TreeNode(1);
r.left = new TreeNode(2);  r.right = new TreeNode(3);
r.left.left = new TreeNode(4);  r.left.right = new TreeNode(5);

console.log(levelOrder(r)); // [[1], [2, 3], [4, 5]]
```

## কোড ব্রেকডাউন: লাইনে লাইনে

1. `if (!root) return []` : খালি গাছে খালি উত্তর। এই চেক না থাকলে queue-এ null ঢুকে প্রথম লুপেই crash।
2. `const queue = [root]` : শুরুতে লাইনে একজন, root।
3. `const levelSize = queue.length` : **লুপের ভেতরে, for-এর আগে** ধরতে হবে। এই এক লাইনেই স্তর আলাদা হয়। for শুরুর পর queue বদলায়, child-রা ঢোকে, কিন্তু আমরা ঠিক levelSize-টাই বের করি।
4. `queue.shift()` : সামনের জন বের হলো। (সতর্কতা নিচে, মূল প্রসঙ্গে।)
5. child আগে null চেক, তারপর push : null ঢুকালে পরে `node.value` পড়তে গিয়ে বিস্ফোরণ।
6. `result.push(level)` : স্তর শেষে পুরো সারিটা ফলে জমা।

## Complexity

| দিক | খরচ | কেন |
|-----|------|-----|
| Time | O(n) | প্রতি node একবার ঢোকে, একবার বের হয় |
| Space | O(w) | queue-এ একসাথে থাকে সবচেয়ে চওড়া স্তরটা; পূর্ণ গাছে শেষ স্তরে n/2 পর্যন্ত, মানে O(n) |

DFS-এর সঙ্গে তুলনা: DFS-এ space O(h) (গভীরতা), BFS-এ O(w) (প্রস্থ)। চওড়া অগভীর গাছে BFS-এর queue মোটা হয়, লম্বা হেলানো গাছে DFS-এর stack লম্বা হয়। কোনটা নিরাপদ, গাছের আকৃতি দেখে ঠিক হয়।

## এই ছাঁচে চলা প্রশ্নগুলো

Level-order ছাঁচ একটু বদলালেই খুলে যায়:

- **Height বের করা:** প্রতি স্তরে একটা counter বাড়াও, যেতে যেতে।
- **Zigzag traversal:** জোড় স্তরে `level` উল্টে দাও (বা deque দিয়ে)।
- **স্তরভিত্তিক সর্বোচ্চ/যোগফল:** for-এর ভেতরে aggregate চালাও, [Traversal](../arrays/traversal.mdx)-এর চ্যাম্পিয়ন প্যাটার্ন।
- **Right side view:** প্রতি স্তরের শেষ উপাদানটাই নাও।

পরে [Graph BFS](../graphs/bfs.mdx)-এ গেলে দেখবে, একই কঙ্কাল, শুধু graph-এ visited-সেট যোগ হয়, কারণ সেখানে cycle থাকে।

## সাধারণ ভুল আর edge case

**১. `levelSize` না ধরে `queue.length` দিয়ে for চালানো।**
for চলতে চলতে queue-এ child ঢুকে length বাড়ে, স্তরের সীমা গুলে যায়, সব এক স্তরে গুলিয়ে যায়। `levelSize` আগে ধরো, পরে loop।

**২. `shift()`-এর O(n) খরচ ভুলে যাওয়া।**
[Queue](../queues/queue-fifo.mdx)-এর সেই পুরনো ফাঁদ: array-র `shift()` প্রতিবার সবাইকে সরায়। ছোট গাছে না বুঝলেও বড় গাছে BFS O(n²) হয়ে যায়। বাস্তবে pointer-ভিত্তিক queue নাও, বা index দিয়ে এগোও (`queue[i++]`), বাড়তি খরচ শূন্য।

**৩. null child চেক না করে push।**
Null ঢুকে পরে `node.left` পড়তে গিয়ে TypeError। `if (node.left)` চেক দুই লাইনে, কিন্তু না করলে পুরো traversal ভেঙে যায়।

**৪. খালি গাছ ভুলে যাওয়া।**
`root = null`-এ সরাসরি `[]` ফেরত দাও। না দিলে `queue = [null]` দিয়ে শুরু, প্রথমেই crash।

**৫. BFS-এর জায়গায় recursion জোর করা।**
Level-order recursion দিয়ে লেখা যায় (depth দিয়ে গুছিয়ে), কিন্তু জটিল আর অস্বাভাবিক। স্তরভিত্তিক চাইলে queue-ই স্বাভাবিক অস্ত্র; recursion রাখো গভীরতার কাজে।

## অনুশীলন

- **সহজ ১:** এই গাছে level-order লিখো আর queue-এর dry run বানাও: root 10, বামে 5 (বামে 2), ডানে 20 (ডানে 25)।
- **সহজ ২:** Height বের করো level-order দিয়ে, recursion ছাড়া। (হিন্ট: প্রতি স্তর শেষে counter।)
- **মাঝারি ১:** Zigzag level-order লেখো: বিজোড় স্তর বাম থেকে ডানে, জোড় স্তর উল্টো। (হিন্ট: `levelSize` জানাই আছে; জোড় স্তরে `level.reverse()` দিলেই হয়, অথবা দিক-ভেরিয়েবল দিয়ে push-এর দিক পাল্টাও।)
- **মাঝারি ২:** প্রতি স্তরের গড় বের করো (LeetCode 637)। কোন লাইনে কী যোগ হলো, মূল ছাঁচ থেকে পার্থক্য এক লাইনে।
- **কঠিন:** Right side view (LeetCode 199): ডান দিক থেকে গাছ দেখলে যেসব node দেখা যায়। দুই রাস্তা ভাবো: (ক) level-order-এর প্রতি স্তরের শেষটা, (খ) DFS দিয়ে ডানে আগে ঢুকে প্রথম দেখা প্রতি depth-এর node। কোনটা কোন দিকে এগিয়ে?

## সারসংক্ষেপ

- Level-order = tree-র জগতে BFS: স্তরে স্তরে, বাম থেকে ডানে, চলে queue দিয়ে।
- `levelSize = queue.length` লুপের আগে ধরলে স্তর আলাদা হয়, এই এক লাইনেই সব ছাঁচ।
- Time O(n), space O(সবচেয়ে চওড়া স্তর); হেলানো গাছে BFS সাশ্রয়ী, চওড়া গাছে মেহনতি।
- `shift()`-এর O(n) মাথায় রাখো, বড় কাজে pointer-queue।
- Height, zigzag, স্তর-গড়, side view: সবই এই এক ছাঁচের রূপ।
