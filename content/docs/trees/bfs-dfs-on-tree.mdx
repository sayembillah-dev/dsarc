## কী শিখব

- দুই traversal কৌশল এক নজরে

## ধারণা

আগের দুই পাতায় যা করলে, তারই নামকরণ এই পাতায়:

- **DFS** (pre/in/post) আগে গভীরে ঢোকে। চলে recursion বা **stack** দিয়ে।
- **BFS** (level-order) স্তরে স্তরে এগোয়। চলে **queue** দিয়ে।

ব্যাপারটা হলো, পরে graph (section 13) পড়লেও এই একই দুটো ধারণা লাগবে। tree আসলে graph-এরই বিশেষ রূপ, শুধু cycle নেই।

## কোড উদাহরণ

DFS-টা এবার recursion ছাড়া, হাতে stack দিয়ে:

```js
class TreeNode {
  constructor(value) {
    this.value = value;
    this.left = null;
    this.right = null;
  }
}

function dfsIterative(root) {
  if (!root) return [];
  const stack = [root], out = [];
  while (stack.length) {
    const node = stack.pop();       // উপরেরটা নিই (LIFO, অর্থাৎ গভীরে আগে)
    out.push(node.value);
    if (node.right) stack.push(node.right); // ডান আগে push (বাঁ আগে বের হবে)
    if (node.left) stack.push(node.left);
  }
  return out;
}

const r = new TreeNode(1);
r.left = new TreeNode(2); r.right = new TreeNode(3);
r.left.left = new TreeNode(4); r.left.right = new TreeNode(5);
console.log(dfsIterative(r)); // [1,2,4,5,3] (pre-order)
```

## কোড ব্রেকডাউন

- recursion-এর call stack-ই আসলে DFS-এর stack। এখানে শুধু সেটা হাতে বানিয়ে করলাম।
- এক লাইনে মনে রাখো: stack মানে DFS, queue মানে BFS।

## Complexity

- DFS, BFS দুটোই O(n) time। space যথাক্রমে O(h) (stack) আর O(n) (queue), আগের পাতাগুলোর হিসাবই।
