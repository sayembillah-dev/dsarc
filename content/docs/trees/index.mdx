**Section Roadmap:** পরিভাষা, Binary Tree Traversal (Pre/In/Post), Level-Order (BFS), BST, AVL (balanced), B-Tree (intro), BFS/DFS on tree।

## সারাংশ

Tree অর্থাৎ শ্রেণিবদ্ধ কাঠামো (root/leaf/height)। DFS: pre/in/post (recursion/stack), in-order BST-তে sorted দেয়। BFS: level-order (queue)। BST গড়ে O(log n) কিন্তু skew হলে O(n); AVL rotation দিয়ে সবসময় O(log n)। B-Tree বহু-key, database/disk-এর জন্য। stack মানে DFS, queue মানে BFS।
