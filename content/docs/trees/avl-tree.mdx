## কী শিখব

- rotation দিয়ে গাছ ভারসাম্যে রাখা, যাতে worst case কখনোই না আসে

## ধারণা

ধরো, BST-তে 1, 2, 3, 4, 5 ক্রমে insert করলে। প্রতিটা নতুন মান আগেরটার ডানেই বসতে থাকবে, আর গাছটা হয়ে যাবে লম্বা এক দণ্ড, প্রায় linked list। তখন search করতে O(n) লাগবে, BST-র সব সুবিধা জলে।

এখানেই আসল জিনিস। **AVL Tree** কিন্তু হেলে পড়তে দেয় না। প্রতিটা insert/delete-এর পর ও নিজে চেক করে নেয়, কোনো node-এর বাঁ আর ডান subtree-র height-এর পার্থক্য যেন সর্বোচ্চ ১ থাকে। এই পার্থক্যের নাম **balance factor**। পার্থক্য বাড়িয়ে দিলে **rotation** দিয়ে ঘুরিয়ে সোজা করে ফেলে। ফলে height সবসময় নিয়ন্ত্রণে থাকে, আর search/insert সবসময় O(log n)।

ভারসাম্যহীনতা চার রকম হতে পারে, প্রতিটার নিজের ফিক্স আছে:

- LL: ডানে rotate (right rotation)
- RR: বাঁয়ে rotate (left rotation)
- LR: আগে বাঁয়ে, তারপর ডানে
- RL: আগে ডানে, তারপর বাঁয়ে

## কোড উদাহরণ

rotation-এর মূল অংশ:

```js
function height(node) { return node ? node.height : 0; }
function balanceFactor(node) { return node ? height(node.left) - height(node.right) : 0; }
function update(node) { node.height = 1 + Math.max(height(node.left), height(node.right)); }

// right rotation (LL ঠিক করে)
function rotateRight(y) {
  const x = y.left;
  y.left = x.right;      // x-এর ডান subtree y-এর বাঁয়ে
  x.right = y;           // y এখন x-এর ডানে
  update(y); update(x);
  return x;             // নতুন root
}
// left rotation (RR ঠিক করে)
function rotateLeft(x) {
  const y = x.right;
  x.right = y.left;
  y.left = x;
  update(x); update(y);
  return y;
}
// insert-এর পর balance:
function rebalance(node) {
  update(node);
  const bf = balanceFactor(node);
  if (bf > 1 && balanceFactor(node.left) >= 0) return rotateRight(node);        // LL
  if (bf > 1 && balanceFactor(node.left) < 0) { node.left = rotateLeft(node.left); return rotateRight(node); }  // LR
  if (bf < -1 && balanceFactor(node.right) <= 0) return rotateLeft(node);       // RR
  if (bf < -1 && balanceFactor(node.right) > 0) { node.right = rotateRight(node.right); return rotateLeft(node); } // RL
  return node;
}
```

## কোড ব্রেকডাউন

- প্রতিটা node নিজের height মনে রাখে। balance factor মানে বাঁ height বিয়োগ ডান height।
- এই মান ১-এর বেশি বা -১-এর কম হলেই rotation। শুধু pointer গুলো ঘোরে, মান বা BST-র নিয়ম কিছুই নষ্ট হয় না।
- rotation আসলে কয়েকটা pointer বদলানো, মানে O(1) কাজ।

## Complexity

- insert, search, delete, তিনটাই সবসময় O(log n) নিশ্চিত। skewed হওয়ার ভয় নেই।
