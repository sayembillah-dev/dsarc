## কী শিখব

- root, node, child, leaf, height, মোটামুটি সব পরিভাষা

## ধারণা

তোমার ফোনের ফোল্ডারের কথা ভাবো। একটা ফোল্ডারের ভিতরে আবার ফোল্ডার, তার ভিতরে আবার ফোল্ডার বা ফাইল। উপর থেকে নিচে, একটা শ্রেণিবদ্ধ (hierarchical) বিন্যাস। **Tree** হুবহু এমনই একটা কাঠামো, শুধু উল্টো গাছের মতো আঁকা হয়: **root** থাকে একদম উপরে, **leaf** গুলো নিচে।

পরিভাষাগুলো একবার চিনে নাও, পুরো section জুড়ে লাগবে:

- **Root:** সবার উপরের node, গাছের শুরু
- **Parent / Child:** উপর-নিচের সম্পর্ক
- **Leaf:** যার কোনো চাইল্ড নেই
- **Edge:** দুই node-এর সংযোগরেখা
- **Height:** root থেকে সবচেয়ে দূরের leaf পর্যন্ত ক'টা edge
- **Depth:** কোনো node root থেকে কত নিচে
- **Subtree:** কোনো node আর তার নিচের সবাই মিলে

```
        A          <- root (depth 0)
       / \
      B   C        <- depth 1
     / \
    D   E          <- leaf (depth 2)
```

## কোড উদাহরণ

binary tree-র node-টা দেখতে কেমন:

```js
class TreeNode {
  constructor(value) {
    this.value = value;
    this.left = null;    // বাঁ চাইল্ড
    this.right = null;   // ডান চাইল্ড
  }
}
const root = new TreeNode("A");
root.left = new TreeNode("B");
root.right = new TreeNode("C");
console.log(root.value, root.left.value, root.right.value); // A B C
console.log(root.left.left); // null (B-এর কোনো চাইল্ড নেই)
```

## কোড ব্রেকডাউন

- এটা **binary tree**, মানে প্রতিটা node-এর সর্বোচ্চ ২টা চাইল্ড (`left`, `right`)।
- `null` মানে সেদিকে কোনো চাইল্ড নেই।

## Complexity

- একটা node তৈরি করতে O(1)। এই পাতায় শুধু গঠন; ঘোরাঘুরি পরের পাতাগুলোয়।
