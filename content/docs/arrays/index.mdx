ভাবো তো, তুমি একটা সিনেমা হলের টিকেট লাইনে দাঁড়িয়ে আছ। সবাই একটার পর একটা, মাঝে কোনো ফাঁক নেই। এখন কেউ জিজ্ঞেস করল, "তিন নম্বরে কে দাঁড়িয়ে আছ?" তুমি গোনা শুরু করবে না, এক নজরেই বলে দেবে। Array ঠিক এমনই কাজ করে। এই ছোট্ট ধারণার উপরেই দাঁড়িয়ে আছে DSA-র প্রায় পুরো জগৎ, তাই চলো এটাকে আগে পকেটে পুরি।

**Section Roadmap:** Array কী, memory-তে কীভাবে থাকে, অপারেশনের খরচ, traversal প্যাটার্ন, আর 2D grid।

## সারাংশ

সহজ কথায়, Array হলো ধারাবাহিক index-ভিত্তিক লিস্ট: access O(1), কিন্তু শুরুতে বা মাঝে insert/delete O(n)। 2D array মানে গ্রিড, পুরোটা ঘুরলে O(m·n)। আর two-pointer, single-pass প্যাটার্নের গোড়াপত্তনও এখানেই।

**পরবর্তী:** [Strings](/docs/strings), যেখানে এই একই লাইনে বসবে character-রা, শুধু একটা ভারী নিয়ম যোগ হবে: একবার লিখলে আর বদলানো যায় না।
