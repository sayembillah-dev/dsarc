Recursion (পুনরাবৃত্ত, অর্থাৎ নিজেকে ডাকা) হলো এমন একটা ধারণা যা প্রথমে কঠিন লাগে, কিন্তু একবার বুঝলে Tree, Graph, Sorting, Dynamic Programming, সব সহজ হয়ে যায়। তাই এটা আগে শিখছি।

**Section Roadmap:** ধারণা, Call Stack, ক্লাসিক উদাহরণ, Recursion vs Iteration, Memoization (intro)।

## এই Chapter-এ যা যা আছে

1. [Recursion কী](./recursion-intro): একটা function নিজেকে ডাকা মানে কী, base case ও recursive case
2. [Call Stack বোঝা](./call-stack): recursion মেমরিতে কীভাবে চলে, factorial দিয়ে stack বোঝা
3. [ক্লাসিক Recursion উদাহরণ](./recursion-examples): sum, reverse, fibonacci, প্রচলিত recursion
4. [Recursion vs Iteration](./recursion-vs-iteration): কখন recursion, কখন loop
5. [Memoization](./memoization): আগে হিসাব করা ফলাফল জমিয়ে recursion দ্রুত করা, DP-র বীজ

## সারাংশ

Recursion অর্থাৎ base case + ছোট সমস্যায় নিজেকে ডাকা; call stack-এর উপর চলে। ক্লাসিক: factorial, sum, reverse, fibonacci। Iteration কম memory নেয়; recursion tree/graph-এ পরিষ্কার। Memoization দিয়ে O(2ⁿ) থেকে O(n), DP-র সূচনা।
