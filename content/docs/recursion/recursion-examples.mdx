## কী শিখব

- sum, reverse, fibonacci, ক্লাসিক কয়টা recursion

## ধারণা

ভাবো তো, তোমাকে পুরো টেবিলটা মুছতে বলা হলো। তুমি প্রথম প্লেটটা মুছলে, তারপর "বাকি টেবিলটা মোছার" কাজটা আবার নিজেরই হাতে তুলে দিলে, শেষে টেবিল ফাঁকা। অনেক সমস্যাই আসলে এমন, "বড় সমস্যা = ছোট সমস্যা + একটু কাজ"। এই চোখে সমস্যাগুলোকে দেখতে পারলেই recursion দিয়ে লিখে ফেলা যায়।

চলো, তিনটা ক্লাসিক উদাহরণ দেখি।

## কোড উদাহরণ

```js
// ১) array যোগফল
function sum(arr, i = 0) {
  if (i === arr.length) return 0;      // base
  return arr[i] + sum(arr, i + 1);     // প্রথমটা + বাকির যোগফল
}
console.log(sum([1, 2, 3, 4])); // 10

// ২) string উল্টানো
function reverse(str) {
  if (str.length <= 1) return str;                 // base
  return reverse(str.slice(1)) + str[0];           // বাকিটা উল্টে + প্রথম অক্ষর
}
console.log(reverse("hello")); // "olleh"

// ৩) Fibonacci (naive, শিক্ষার জন্য)
function fib(n) {
  if (n < 2) return n;                 // base: fib(0)=0, fib(1)=1
  return fib(n - 1) + fib(n - 2);      // আগের দুই সংখ্যার যোগ
}
console.log(fib(7)); // 13
```

## কোড ব্রেকডাউন

- তিনটার ভেতরেই একই ছাপ: একটা base case, আর "ছোট সমস্যায় নিজেকে ডাকা"।
- `fib`-এর naive version-টা **O(2ⁿ)**, কারণ একই মান বারবার হিসাব হয়। এটা ঠিক করার ব্যাপারটা Memoization পাতায় দেখব।

## Complexity

- sum/reverse O(n); naive fib O(2ⁿ)।
