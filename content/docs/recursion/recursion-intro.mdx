## কী শিখব

- একটা function নিজেকে ডাকা মানে আসলে কী

## ধারণা

ভাবো তো, দুটো আয়না মুখোমুখি রেখে মাঝে দাঁড়ালে কী হয়? একটা প্রতিফলনের ভেতরে আরেকটা ছোট প্রতিফলন, তার ভেতরে আরও ছোট, চলতেই থাকে। আরেকটা উদাহরণ হলো রুশ পুতুল (matryoshka), খুললে ভেতরে একটা ছোট পুতুল, সেটা খুললে আরও ছোট, শেষে সবচেয়ে ছোটটা আর খোলে না।

Recursion ঠিক এই ব্যাপারটাই। একটা function নিজের ভেতরেই নিজেকে ডাকে, তবে প্রতিবার একটু **ছোট সমস্যা** নিয়ে, যতক্ষণ না সমস্যাটা এত ছোট হয় যে সরাসরি উত্তরটা জানা। এই যে থামার জায়গা, এটাই **base case**।

**দুটো অংশ সবসময় লাগবে:**

1. **Base case:** কখন থামবে (না থাকলে infinite)
2. **Recursive case:** ছোট সমস্যায় নিজেকে ডাকা

## কোড উদাহরণ

```js
// countdown উদাহরণ
function countdown(n) {
  if (n === 0) {              // base case: থামার শর্ত
    console.log("শেষ!");
    return;
  }
  console.log(n);
  countdown(n - 1);          // recursive case: ছোট সমস্যা
}

countdown(3); // 3, 2, 1, শেষ!
```

## কোড ব্রেকডাউন

- `if (n === 0) return` এটাই base case, এখানে এসে থামবে। এটা না থাকলে function থামারই কথা না, শেষে stack overflow।
- `countdown(n - 1)` দিয়ে প্রতিবার সমস্যাটা এক ধাপ ছোট করছি।
- এখানেই আসল জিনিস, প্রতিটা recursion-এ সমস্যা যে সত্যিই base case-এর দিকে এগোচ্ছে, সেটা নিশ্চিত করতেই হবে।

## Complexity

- এখানে O(n)।

## Animation Spec

> **Animation Spec: Nested Dolls**
>
> - **দৃশ্য:** n থেকে শুরু করে ভেতরে ভেতরে ছোট box (প্রতিটা call)।
> - **ইনপুট:** n।
> - **ধাপ:** প্রতিটা call ভেতরে নতুন box খোলে; base case-এ পৌঁছালে ভেতর থেকে বাইরে return হতে হতে box বন্ধ হয়।
> - **লক্ষ্য:** "নিচে নামা, base, ফিরে আসা" চক্র।
