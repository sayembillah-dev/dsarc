## কী শিখব

- গণিত, তুলনা আর লজিক অপারেটর

## ধারণা

ধরো, দোকানে হিসাব করছ। দাম যোগ করলে, ফেরত বের করলে, শেষে ভাবলে, "বাজেটের মধ্যে থাকলেই কেবল কিনব"। এই যোগ, তুলনা আর শর্তের কাজগুলোই প্রোগ্রামে করে **operator**।

- **Arithmetic:** `+ - * / %` (`%` = ভাগশেষ/modulo)
- **Comparison:** `=== !== > < >= <=` (ফলাফল boolean)
- **Logical:** `&&` (AND), `||` (OR), `!` (NOT)

<Callout type="warn" title="সবসময় === ব্যবহার করো">
`===` টাইপসহ মিলিয়ে দেখে (strict), তাই ভুল কম হয়। `==` ব্যবহার করবে না।
</Callout>

## কোড উদাহরণ

```js
console.log(10 + 3);   // 13
console.log(10 % 3);   // 1  (10 ÷ 3-এর ভাগশেষ)
console.log(10 === 10);// true
console.log(5 > 3 && 2 < 1); // false (AND: দুটোই true হতে হবে)
console.log(5 > 3 || 2 < 1); // true  (OR: একটা true হলেই চলে)
console.log(!true);    // false (NOT: উল্টে দেয়)
```

## কোড ব্রেকডাউন

- `%` (modulo): জোড়/বিজোড় বের করতে দারুণ লাগে। `n % 2 === 0` মানেই জোড়।
- `&&`: দুই দিকই true হলে true।
- `||`: যেকোনো একদিক true হলেই true।
