## ধারণা

ধরো, তুমি রান্না শিখছো। রান্নার নিয়ম তো একটাই, গ্যাসের চুলায় শেখো বা ইলেকট্রিক চুলায়, ফল একই। Data Structure আর Algorithm-ও ঠিক এরকম *ধারণা* (concept)। যেকোনো ভাষায় শেখা যায়: C++, Java, Python, JavaScript। roadmap-এর ছবিতেও অনেক ভাষার অপশন দেখা যায়। আমরা বেছে নিয়েছি **JavaScript**। কারণটা সোজা:

- **শেখা সহজ:** syntax সরল, দ্রুত শুরু করা যায়
- **ইনস্টল ছাড়াই চলে:** ব্রাউজারের console খুললেই টেস্ট শুরু
- **web development-এ সরাসরি লাগে:** বাংলাদেশে চাকরির বাজারে চাহিদা বেশি
- **আমাদের ভবিষ্যৎ interactive web app-ও JavaScript-এই বানাব**

## কোড উদাহরণ

```js
// তোমার প্রথম প্রোগ্রাম
console.log("আসসালামু আলাইকুম, DSA শুরু করছি!");
```

## কোড ব্রেকডাউন

- `console.log(...)`: স্ক্রিনে (console-এ) কিছু ছাপায়। এটাই হবে তোমার সবচেয়ে বড় বন্ধু, কোড কী করছে সেটা দেখতে গেলে।
- `"..."`: double quote-এর ভেতরে যা থাকে সেটা **string** (লেখা/টেক্সট)।

## Complexity

প্রযোজ্য নয়, এটা তো শুধু ভাষার সঙ্গে পরিচয়।

> **Animation Spec: Code থেকে Output**
>
> - **দৃশ্য:** বাঁয়ে code editor, ডানে console output প্যানেল।
> - **ইনপুট:** ইউজার `console.log()`-এর ভেতরের text এডিট করতে পারবে।
> - **ধাপ:** "Run" চাপলে code লাইন highlight হয়ে ডান পাশে output টাইপরাইটার-স্টাইলে দেখা যাবে।
> - **লক্ষ্য:** code লিখলে output আসে, এই cause-effect বোঝা।

## অনুশীলন

- নিজের নাম console-এ ছাপাও।
- দুটো আলাদা `console.log` লিখে দেখো ক্রম বজায় থাকে কিনা।
