## কী শিখব

- প্রতিবার সবচেয়ে ছোটটা খুঁজে সামনে বসানো

## ধারণা

ধরো, টেবিলে একগাদা কয়েন ছড়িয়ে আছে, তোমাকে ছোট থেকে বড় সাজাতে হবে। তুমি কী করবে? পুরো গাদা ঘেঁটে সবচেয়ে ছোট কয়েনটা তুলে একদম বাঁয়ে রাখবে। তারপর বাকিগুলোর মধ্যে আবার সবচেয়ে ছোটটা খুঁজে তার পাশে বসাবে। এভাবেই চলবে শেষ পর্যন্ত।

Selection Sort-ও এই কায়দাতেই চলে। বাকি অংশ থেকে সবচেয়ে ছোট উপাদানটা খুঁজে, সেটাকে সঠিক জায়গায় (সামনে) একবার swap করে দেয়। তাই এখানে swap-এর সংখ্যা কম, যদিও তুলনা অনেক লাগে।

## কোড উদাহরণ

```js
function swap(arr, i, j) { [arr[i], arr[j]] = [arr[j], arr[i]]; }

function selectionSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    let minIndex = i;
    for (let j = i + 1; j < n; j++) {
      if (arr[j] < arr[minIndex]) minIndex = j;  // ছোটতম খুঁজি
    }
    if (minIndex !== i) swap(arr, i, minIndex);  // একবার swap
  }
  return arr;
}
console.log(selectionSort([64, 25, 12, 22, 11])); // [11,12,22,25,64]
```

## কোড ব্রেকডাউন

- বাইরের loop ঠিক করে এখন কোন জায়গাটা পূরণ হচ্ছে।
- ভেতরের loop বাকিগুলোর মধ্যে ছোটতম খুঁজে minIndex-এ রাখে।
- প্রতি pass-এ মাত্র একটা swap। তাই swap ব্যয়বহুল এমন জায়গায় এটা ভালো কাজে লাগে।

## Complexity

- সব ক্ষেত্রে O(n²); space O(1); unstable।
