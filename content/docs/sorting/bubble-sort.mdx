## কী শিখব

- পাশাপাশি তুলনা করে বড়টা ধীরে ধীরে শেষে ঠেলা

## ধারণা

ভাবো তো, ক্লাসের বাচ্চারা এলোমেলো লাইনে দাঁড়িয়ে আছে, তোমাকে উচ্চতা অনুযায়ী সাজাতে হবে। তুমি লাইনের শুরু থেকে পাশাপাশি দুজনকে তুলনা করতে করতে এগোলে: সামনেরটা লম্বা হলে দুজনের জায়গা বদল করে দিলে। একবার শেষ পর্যন্ত হেঁটে আসতেই সবচেয়ে লম্বা ছেলেটা একদম পেছনে চলে গেছে।

Bubble Sort ঠিক এটাই করে। পাশাপাশি দুটো উপাদান তুলনা করে, বাঁ-টা বড় হলে swap। প্রতিটা pass-এ সবচেয়ে বড় উপাদানটা পানির বুদবুদের মতো ভেসে ভেসে শেষে চলে যায়। শেখার জন্য দারুণ, কিন্তু ধীর।

## কোড উদাহরণ

```js
function swap(arr, i, j) { [arr[i], arr[j]] = [arr[j], arr[i]]; }

function bubbleSort(arr) {
  const n = arr.length;
  for (let i = 0; i < n - 1; i++) {
    let swapped = false;
    for (let j = 0; j < n - 1 - i; j++) {   // -i: শেষেরগুলো ইতিমধ্যে sorted
      if (arr[j] > arr[j + 1]) {
        swap(arr, j, j + 1);
        swapped = true;
      }
    }
    if (!swapped) break;                     // কোনো swap নেই অর্থাৎ sorted, থামি
  }
  return arr;
}
console.log(bubbleSort([5, 1, 4, 2, 8])); // [1,2,4,5,8]
```

## কোড ব্রেকডাউন

- ভেতরের loop-টা পাশাপাশি প্রতিটা জোড়া তুলনা করে, দরকার হলে swap করে।
- `swapped` flag-টা একটা চালাকি: কোনো pass-এ একটাও swap না হলে বুঝে নেবে array ইতিমধ্যে sorted, আর তখনই থেমে যাবে। এই কারণেই best case O(n)।
- `n-1-i` মানে প্রতি pass-এ শেষের অংশটা আর দেখা হয় না, কারণ ওখানকারগুলো নিশ্চিত sorted।

## Complexity

- worst/avg O(n²); best O(n); space O(1); stable।

## অনুশীলন

- `swapped` flag ছাড়া আর সহ, দুটো version-ই চালাও, best case-এ পার্থক্য নিজেই দেখো।
