## কী শিখব

- তাস সাজানোর মতো, একটা একটা করে সঠিক জায়গায় বসানো

## ধারণা

তাস খেলার কথা ভাবো। হাতে একটা একটা করে নতুন কার্ড আসছে, আর তুমি প্রতিবার সেটাকে হাতের sorted কার্ডগুলোর মধ্যে ঠিক জায়গায় ঢুকিয়ে দিচ্ছ। Insertion Sort হুবহু এটাই করে: প্রতিটা নতুন উপাদানকে বাঁ দিকের sorted অংশে সঠিক জায়গায় বসিয়ে দেয়। আর ডেটা যদি প্রায়-sorted হয়, তাহলে এটা ভয়ংকর দ্রুত (best case O(n))।

## কোড উদাহরণ

```js
function insertionSort(arr) {
  for (let i = 1; i < arr.length; i++) {
    const key = arr[i];          // যাকে বসাতে হবে
    let j = i - 1;
    while (j >= 0 && arr[j] > key) {
      arr[j + 1] = arr[j];       // বড়গুলো ডানে সরাই
      j--;
    }
    arr[j + 1] = key;            // সঠিক জায়গায় বসাই
  }
  return arr;
}
console.log(insertionSort([5, 2, 4, 6, 1, 3])); // [1,2,3,4,5,6]
```

## কোড ব্রেকডাউন

- বাঁ দিকটা সবসময় sorted থাকে। প্রতিবার ডান থেকে একটা key তুলে সেই sorted অংশে ঢোকানো হয়।
- `while` loop-টা বড়গুলোকে ডানে ঠেলে key-এর জন্য জায়গা বানিয়ে দেয়।
- ডেটা প্রায়-sorted হলে while প্রায় চলেই না, তাই তখন সময় লাগে O(n)।

## Complexity

- worst/avg O(n²); best O(n); space O(1); stable।
