সাজানো (sorting) DSA-র সবচেয়ে শেখনীয় বিষয়, কারণ একই সমস্যার অনেক সমাধান, প্রতিটার complexity আলাদা। এখানে ছবির ৬টা algorithm-ই শিখব।

**Section Roadmap:** কেন sorting, Bubble, Selection, Insertion, Merge, Quick, Heap, তুলনা টেবিল।

সব জায়গায় লাগবে এমন সাধারণ swap হেল্পার:

```js
function swap(arr, i, j) { [arr[i], arr[j]] = [arr[j], arr[i]]; }
```

## এই Chapter-এ যা যা আছে

1. [কেন Sorting শিখব ও কী কী বিবেচ্য](./why-sorting.mdx): stability, in-place, comparison-ভিত্তিক ধারণা, JS built-in `sort`
2. [Bubble Sort](./bubble-sort.mdx): পাশাপাশি তুলনা করে বড়টা ধীরে ধীরে শেষে ঠেলা
3. [Selection Sort](./selection-sort.mdx): প্রতিবার সবচেয়ে ছোটটা খুঁজে সামনে বসানো
4. [Insertion Sort](./insertion-sort.mdx): তাস সাজানোর মতো একটা একটা করে সঠিক জায়গায় বসানো
5. [Merge Sort](./merge-sort.mdx): ভাগ করো, সাজাও, মেলাও, O(n log n)
6. [Quick Sort](./quick-sort.mdx): pivot বেছে ভাগ করা, বাস্তবে দ্রুততম গড়ে
7. [Heap Sort](./heap-sort.mdx): heap দিয়ে সাজানো, O(n log n) ও in-place
8. [সব Sort-এর তুলনা](./sorting-comparison.mdx): complexity টেবিল ও কোনটা কখন

## সারাংশ

O(n²): Bubble, Selection, Insertion (সহজ, শেখার জন্য)। O(n log n): Merge (stable, O(n) space), Quick (গড়ে দ্রুত, worst O(n²)), Heap (in-place, নিশ্চিত O(n log n))। স্থিতিশীলতা ও space অনুযায়ী বাছাই।
