## কী শিখব

- linked list-এ express lane বসিয়ে O(log n) search কীভাবে সম্ভব

## ধারণা

ভাবো তো লোকাল আর এক্সপ্রেস ট্রেনের ব্যাপারটা। লোকাল ট্রেন সব স্টেশনে থামে, এক্সপ্রেস অনেকগুলো স্টেশন লাফ দিয়ে চলে যায়। দূরে যেতে হলে তুমি আগে এক্সপ্রেসে ওঠো, গন্তব্য কাছাকাছি এলে লোকালে নেমে যাও। **Skip List** sorted linked list-এ ঠিক এই কায়দা করে।

sorted linked list-এ search মানে একটা একটা করে হাঁটা, O(n)। Skip List তার উপর কয়েকটা অতিরিক্ত স্তর (express lane) বসিয়ে দেয়। উপরের স্তরে কম node, ওরা দূর দূর লাফায়; নিচের স্তরে সব node। খোঁজার সময় উপর দিয়ে দ্রুত এগোও, দরকারমতো নিচে নামো। ফলে গড়ে **O(log n)**। আর সবচেয়ে মজার ব্যাপার: কোন node কত উপরে উঠবে, সেটা ঠিক হয় coin-flip টাইপ randomness দিয়ে। rotation-এর কোনো ঝামেলা নেই, তবু balanced tree-র কাছাকাছি পৌঁছে যায়।

```text
L2:  1 --------> 9 --------> 25
L1:  1 ----> 6 -> 9 ----> 17 -> 25
L0:  1 -> 6 -> 9 -> 12 -> 17 -> 20 -> 25   (সব node)
```

## কোড উদাহরণ

```js
class SkipNode {
  constructor(value, level) {
    this.value = value;
    this.next = new Array(level + 1).fill(null); // প্রতি স্তরে next
  }
}

// search: সবচেয়ে উপরের স্তর থেকে শুরু;
//   পরের node ছোট হলে সামনে এগোও (express),
//   নাহলে এক স্তর নিচে নামো; নামতে নামতে target পাও।
function search(head, target, maxLevel) {
  let node = head;
  for (let level = maxLevel; level >= 0; level--) {
    while (node.next[level] && node.next[level].value < target) {
      node = node.next[level];   // এই স্তরে সামনে এগোই
    }                            // পরেরটা বড়, তাই নিচে নামি
  }
  node = node.next[0];
  return node !== null && node.value === target;
}

// উপরের diagram-এর list-টা বানাই (প্রতিটা node-এর স্তর হাতে ঠিক করা)
function buildList(values, levels) {
  const nodes = values.map((v, i) => new SkipNode(v, levels[i]));
  for (let i = 0; i < nodes.length - 1; i++) {
    for (let l = 0; l <= levels[i]; l++) {
      let j = i + 1;
      while (levels[j] < l) j++;      // এই স্তরে পরের node খোঁজা
      nodes[i].next[l] = nodes[j];
    }
  }
  return nodes[0];
}

const values = [1, 6, 9, 12, 17, 20, 25];
const levels = [2, 1, 2, 0, 1, 0, 2];  // কে কত স্তর পর্যন্ত ওঠে
const head = buildList(values, levels);
console.log(search(head, 17, 2));     // true
console.log(search(head, 15, 2));     // false
```

## কোড ব্রেকডাউন

- উপরের স্তর মানে দূরপাল্লার লাফ, নিচের স্তর মানে লোকাল।
- `search` প্রতি স্তরে যতদূর সম্ভব এগিয়ে যায়; পরের node বড় দেখলেই এক স্তর নেমে আসে।
- নতুন node-এর স্তর ঠিক হয় coin-flip (random) দিয়ে, তাই গড়ে ভারসাম্য থেকেই যায়।
- Redis-এর sorted set (ZSET) আসলে skip list দিয়েই বানানো।

## Complexity

- গড়ে search/insert/delete O(log n); space O(n)।
