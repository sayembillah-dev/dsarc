## কী শিখব

- database ও file system-এর মূল index কাঠামো

## ধারণা

2-3 Tree-কে সাধারণীকরণ করলেই **B-Tree** (section 11.6-এ পরিচয় হয়েছে): প্রতিটা node-এ **অনেক key ও অনেক চাইল্ড** (order m)। উদ্দেশ্য: গাছ যতটা সম্ভব **কম গভীর** রাখা, কারণ disk থেকে প্রতিটা node পড়া ব্যয়বহুল; কম height মানে কম disk read।

**B+ Tree** (বাস্তবে database index যা ব্যবহার করে) হলো B-Tree-র উন্নত রূপ:

- **সব actual data শুধু leaf-এ** থাকে (internal node শুধু "রাস্তা দেখানোর" key)
- **সব leaf একটা linked list-এ জোড়া**, তাই range query (`WHERE age BETWEEN 20 AND 30`) খুব দ্রুত (এক leaf থেকে পরের leaf-এ হাঁটা)

```text
B+ Tree:
            [30 | 60]              (internal: শুধু guide)
           /    |    \
     [10 20]->[30 40 50]->[60 70]  (leaf: actual data, পরস্পর linked)
```

## কোড উদাহরণ

```js
// ছোট্ট B+ Tree মডেল: internal node শুধু guide, leaf-এ data ও leaf-লিঙ্ক
class LeafNode {
  constructor(keys) { this.keys = keys; this.next = null; }
}

class BPlusTree {
  constructor() {
    this.guides = [30, 60];          // internal node-এর guide key
    this.leaves = [
      new LeafNode([10, 20]),
      new LeafNode([30, 40, 50]),
      new LeafNode([60, 70]),
    ];
    for (let i = 0; i < this.leaves.length - 1; i++) {
      this.leaves[i].next = this.leaves[i + 1];   // leaf গুলো linked
    }
  }

  _findLeaf(key) {                   // guide দিয়ে নামা (বাস্তবে O(log n))
    let i = 0;
    while (i < this.guides.length && key >= this.guides[i]) i++;
    return this.leaves[i];
  }

  rangeQuery(lo, hi) {               // SQL: WHERE age BETWEEN lo AND hi
    const result = [];
    let leaf = this._findLeaf(lo);   // lo-এর leaf খোঁজা O(log n)
    while (leaf) {                   // leaf-linked-list ধরে hi পর্যন্ত হাঁটা
      for (const k of leaf.keys) {
        if (k > hi) return result;
        if (k >= lo) result.push(k);
      }
      leaf = leaf.next;
    }
    return result;
  }
}

const tree = new BPlusTree();
// SELECT * FROM users WHERE age BETWEEN 25 AND 40;
console.log(tree.rangeQuery(25, 40));   // [ 30, 40 ]
console.log(tree.rangeQuery(10, 70));   // [ 10, 20, 30, 40, 50, 60, 70 ]
```

## কোড ব্রেকডাউন

- `_findLeaf` guide key দিয়ে সঠিক leaf-এ নামে; বাস্তব B+ Tree-এ এটাই O(log n) অংশ।
- `rangeQuery` 25-এর leaf খুঁজে (O(log n)), তারপর leaf-linked-list ধরে 40 পর্যন্ত sequential পড়ে; খুবই দক্ষ range scan।
- বড় fan-out (অনেক চাইল্ড): লাখো row-এও height মাত্র ৩-৪, তাই ৩-৪ disk read-এ যেকোনো row।
- B+ Tree-এর linked leaf sorted scan ও range query সহজ করে; এজন্য MySQL (InnoDB), PostgreSQL সবই B+ Tree index ব্যবহার করে।

## Complexity

- search/insert/delete O(log n); disk-access-এ বিশাল সুবিধা।
