## কী শিখব

- যে multi-way search tree কখনো হেলে পড়ে না, সে কীভাবে সম্ভব

## ধারণা

ভাবো তো, sorted ডেটা (১, ২, ৩, ৪...) একটা সাধারণ binary search tree-তে ঢোকালে কী হয়। গাছটা একপাশে হেলে লম্বা লাঠি হয়ে যায়, search আর O(log n) থাকে না। AVL এই সমস্যা মেটে rotation দিয়ে। 2-3 Tree মেটে একদম অন্য কায়দায়: node-কে একটু বেশি key ধরতে দাও, ভরে গেলে **ভেঙে ফেলো (split)**, দরকারে আবার **জোড়া লাগাও (merge)**।

নিয়মটা সরল। প্রতিটা internal node দুই রকমের একটা হবেই:

- **2-node:** ১টা key, ২টা চাইল্ড
- **3-node:** ২টা key, ৩টা চাইল্ড

আর সবচেয়ে গুরুত্বপূর্ণ শর্ত: **সব leaf সবসময় একই স্তরে থাকে।** গাছ হেলে যাওয়ার সুযোগই নেই, তাই উচ্চতা guaranteed O(log n)। লক্ষ্য AVL-এর মতোই, শুধু পথটা আলাদা। আর মজার কথা, এটাই B-Tree-র (পরের পাতায় বিস্তারিত) সবচেয়ে সরল রূপ।

```text
2-node:  [10]        3-node:  [10 | 20]
        /    \               /    |    \
     <10     >10          <10  10-20  >20
```

## কোড উদাহরণ

```js
class TwoThreeNode {
  constructor() {
    this.keys = [];       // 1 বা 2 টা key (sorted)
    this.children = [];   // 2 বা 3 টা চাইল্ড
  }
  isLeaf() { return this.children.length === 0; }
  is3Node() { return this.keys.length === 2; }
}

class TwoThreeTree {
  constructor() { this.root = null; }

  insert(key) {
    if (!this.root) {
      this.root = new TwoThreeNode();
      this.root.keys.push(key);
      return;
    }
    const split = this._insert(this.root, key);
    if (split) {
      // root split: নতুন root, height সবার জন্য সমানভাবে বাড়ে
      const newRoot = new TwoThreeNode();
      newRoot.keys = [split.mid];
      newRoot.children = [this.root, split.right];
      this.root = newRoot;
    }
  }

  _insert(node, key) {
    if (node.isLeaf()) {
      node.keys.push(key);
      node.keys.sort((a, b) => a - b);
      return node.keys.length === 3 ? this._split(node) : null;
    }
    let i = 0;
    while (i < node.keys.length && key > node.keys[i]) i++;
    const split = this._insert(node.children[i], key);
    if (!split) return null;
    // child split হলে মাঝের key এই node-এ ওঠে
    node.keys.splice(i, 0, split.mid);
    node.children.splice(i + 1, 0, split.right);
    return node.keys.length === 3 ? this._split(node) : null;
  }

  _split(node) {                  // 3-key node ভাঙা: মাঝের key parent-এ ওঠে
    const right = new TwoThreeNode();
    const mid = node.keys[1];
    right.keys = [node.keys[2]];
    node.keys = [node.keys[0]];
    if (!node.isLeaf()) right.children = node.children.splice(2, 2);
    return { mid, right };
  }

  height() {
    let h = 0, node = this.root;
    while (node) { h++; node = node.children[0]; }
    return h;
  }
}

const tree = new TwoThreeTree();
for (const k of [10, 20, 30, 40, 50, 60, 70]) tree.insert(k);
console.log("root keys:", tree.root.keys);  // root keys: [ 40 ]
console.log("height:", tree.height());      // height: 3 (সব leaf একই স্তরে)
```

## কোড ব্রেকডাউন

- insert হলে আগে সঠিক leaf খুঁজে key বসায়। node-এ ৩টা key জমে গেলেই **split**: মাঝের key-টা parent-এ উঠে যায়।
- split উপরের দিকে ছড়াতে পারে। root-ও split হলে height বাড়ে, কিন্তু সবার জন্য সমানভাবে।
- `is3Node()` দিয়ে বোঝা যায় node-এ ২টা key (মানে ৩টা চাইল্ড) আছে কি না।
- গাছ কখনো একপাশে হেলে যায় না, তাই worst case-ও চোখ বন্ধ করে O(log n) বলতে পারো।

## Complexity

- search/insert/delete: O(log n), guaranteed।
