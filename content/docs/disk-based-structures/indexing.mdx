## কী শিখব

- database এত দ্রুত খুঁজে পায় কীভাবে, আর indexing-এর দুই ঘরানায় কোনটা কখন

## ধারণা

ভাবো তো, লাখ লাখ row-এর টেবিলে `WHERE id = 42` লিখলেই মুহূর্তে উত্তর চলে আসে। database কি প্রতিবার পুরো টেবিল খাঁজে? না। ওর কাছে বইয়ের পেছনের index-এর মতো একটা আলাদা কাঠামো থাকে, যেটা দেখে সোজা সঠিক জায়গায় পৌঁছে যায়। এই কাঠামোটাই **Index**। ব্যাপারটা হলো, index মূলত দুই ঘরানার হয়।

**১) Linear / Hash-based Indexing**

- key থেকে সরাসরি জায়গা বের করে, ঠিক hash table-এর মতো
- **equality query**-তে ওস্তাদ: `WHERE id = 42` মানেই O(1)
- কিন্তু **range query** দিলেই অসহায়: `WHERE id > 42`? hash-এ তো কোনো ক্রমই নেই

**২) Tree-based Indexing (B/B+ Tree)**

- key গুলো থাকে sorted কাঠামোতে
- equality-ও পারে, **range-ও** পারে: `WHERE age BETWEEN 20 AND 30` আর কোনো ব্যাপারই না
- এই বহুমুখিতার জন্যই প্রায় সব database-এর default index tree-based, ঠিক করে বললে B+ Tree

## কোড উদাহরণ

```js
// একই ডেটার উপর দুই ঘরনের index
const users = [
  { id: 42, name: "Ana", age: 25 },
  { id: 7, name: "Rafi", age: 30 },
  { id: 99, name: "Mim", age: 35 },
  { id: 13, name: "Raju", age: 22 },
];

// Hash index আদর্শ: SELECT * FROM users WHERE id = 42;   (equality, O(1))
const hashIndex = new Map(users.map(u => [u.id, u]));
console.log(hashIndex.get(42));   // { id: 42, name: 'Ana', age: 25 }

// B+ Tree index আদর্শ: sorted, তাই range ও sort দুটোই পারে
const ageIndex = [...users].sort((a, b) => a.age - b.age);
const nameIndex = [...users].sort((a, b) => a.name.localeCompare(b.name));

// SELECT * FROM users WHERE age BETWEEN 20 AND 30;   (range)
console.log(ageIndex.filter(u => u.age >= 20 && u.age <= 30).map(u => u.name));
// [ 'Raju', 'Ana', 'Rafi' ]

// SELECT * FROM users ORDER BY name;   (sorted scan)
console.log(nameIndex.map(u => u.name));   // [ 'Ana', 'Mim', 'Rafi', 'Raju' ]
```

## কোড ব্রেকডাউন

- Hash: equality-তে সবচেয়ে দ্রুত, কিন্তু ক্রম বা range কিছুই জানে না।
- Tree (B+): equality-তে একটু ধীর, কিন্তু range, sort, prefix সব পারে। তাই অনেক বেশি বহুমুখী।
- বাস্তবে DBA-রা query-প্যাটার্ন দেখেই ঠিক করে কোন column-এ কোন ধরনের index বসাবে।

## Complexity

- Hash: equality O(1)। Tree: O(log n), কিন্তু range চালাতে পারে।
