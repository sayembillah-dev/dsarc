নতুন কোনো জায়গায় ঢুকলে প্রথমেই যেটা জানা দরকার, সেটা হলো নিয়মকানুন। এই পেজে ঠিক সেটাই বলেছি। প্রতিটা টপিক কীভাবে সাজানো, কোডগুলো কেমন দেখাবে, আর Animation Spec নামের লেখাগুলো দিয়ে আসলে কী করতে হবে। পাঁচ মিনিট দাও। তারপর পুরো কোর্সজুড়ে ওই একই ছাঁচ পাবে, আর কিছু নতুন করে শিখতে হবে না।

## ১. একটা টপিক খুললে কী কী পাবে

প্রতিটা টপিক ঠিক ৭টা অংশে ভাগ করা। সব জায়গায় একই কাঠামো, তাই দু-একটা টপিক পড়লেই হাত পাকিয়ে যাবে।

| ক্রম | অংশ | কী থাকে |
|---:|------|---------|
| ১ | **কী শিখব** | টপিকটা শেষে তুমি কী কী পারবে, এক লাইনে লক্ষ্য |
| ২ | **ধারণা** | সহজ ভাষায় ব্যাখ্যা, সাথে চেনা জিনিসের উদাহরণ |
| ৩ | **কোড উদাহরণ** | কপি করে এমনিই চালানো যায়, এমন JavaScript |
| ৪ | **কোড ব্রেকডাউন** | কোন লাইনে কী হচ্ছে, ধরে ধরে বোঝানো |
| ৫ | **Complexity** | Time ও Space complexity, Big-O-তে |
| ৬ | **Animation Spec** | এই টপিকের visualizer-টা কেমন হবে |
| ৭ | **অনুশীলন** | নিজে সমাধান করার মতো প্র্যাকটিস সমস্যা |

## ২. কোড দেখতে কেমন হবে

সব কোড একই ছাঁচে লেখা। কারণটা সহজ, তুমি যেন টপিকে টপিকে স্টাইল নিয়ে না ভাবো, শুধু লজিক নিয়ে ভাবো।

- **ভাষা:** আধুনিক JavaScript (ES2020+)। `const`/`let`, arrow function, `class`, `Map`, `Set` — এগুলোই চোখে পড়বে।
- **কমেন্ট:** বাংলা আর English মিশিয়ে। টেকনিক্যাল টার্ম English-এই থাকবে, ব্যাখ্যাটা বাংলায়।
- **ভেরিয়েবলের নাম:** English-এ, আর নাম দেখলেই বুঝতে পারবে এটা কীসের। `i` বা `temp` না; `index`, `current` টাইপ।
- **রান করা যাবে:** কপি করে সরাসরি চালাতে পারবে। মাঝখান থেকে কিছু বাদ পড়া থাকবে না।

<Callout type="warn" title="var কখনোই না">
`var` পুরনো, আর নিয়ে ঝামেলাও বেশি (function scope, hoisting-এর গোলমাল)। সবসময় `const` লিখো। মান বদলানো লাগলে তখনই শুধু `let`।
</Callout>

একই কাজ, একবার খারাপ স্টাইলে, একবার ভালো স্টাইলে:

```js
// খারাপ: var, অর্থহীন নাম
function f(a) {
  var t = 0;
  for (var i = 0; i < a.length; i++) {
    t = t + a[i];
  }
  return t;
}
```

```js
// ভালো: const/let, অর্থপূর্ণ নাম, for...of loop
// একটা array-এর সব সংখ্যার যোগফল বের করি
function sum(numbers) {
  let total = 0;                    // যোগফল জমা রাখার box
  for (const n of numbers) {        // প্রতিটা সংখ্যার উপর loop
    total += n;                     // total-এর সাথে যোগ করি
  }
  return total;
}

console.log(sum([1, 2, 3, 4])); // 10
```

## ৩. Animation Spec দিয়ে কী করবে?

প্রতিটা টপিকে একসময় একটা **interactive visualizer** বসবে। তুমি ইনপুট পাল্টে পাল্টে দেখতে পারবে অ্যালগরিদমটা ভেতরে ভেতরে ঠিক কী করছে। ওটা বানানোর আগে থেকেই প্রতিটা সাবসেকশনে তার পুরো বর্ণনা লেখা আছে, ৫টা নির্দিষ্ট অংশে:

| অংশ | কী বলা থাকে |
|------|-------------|
| **দৃশ্য (Visual)** | স্ক্রিনে কী উঠবে: বার, নোড, তীর, গ্রিড |
| **ইনপুট (Configurable Inputs)** | কী কী পাল্টাতে পারবে: array-এর মান, target সংখ্যা, node সংখ্যা, speed |
| **ধাপ (Animation Steps)** | কোন ফ্রেমে কী ঘটবে, কোন এলিমেন্ট কোন রঙ ধরবে |
| **নিয়ন্ত্রণ (Controls)** | Play / Pause / Step-forward / Step-back / Reset / Speed |
| **লক্ষ্য (What to observe)** | অ্যানিমেশন দেখে আসলে কীটা বুঝতে হবে |

### রঙ মানেই তো কথা

সব visualizer-এ রঙের মানে একই থাকবে। একবার শিখলে নতুন টপিকে গিয়ে আবার শিখতে হবে না।

| অবস্থা | রঙ | কালার কোড | মানে |
|--------|-----|-----------|------|
| Default | ধূসর-নীল | `#64748b` | সাধারণ এলিমেন্ট |
| Comparing | হলুদ | `#eab308` | এখন তুলনা চলছে |
| Active/Pointer | কমলা | `#f97316` | বর্তমান pointer/index |
| Swapping | লাল | `#ef4444` | জায়গা বদল হচ্ছে |
| Sorted/Done | সবুজ | `#22c55e` | চূড়ান্ত/সম্পন্ন |
| Visited | বেগুনি | `#a855f7` | আগে দেখা হয়েছে (graph/tree) |

### একটা নমুনা দেখে নাও

চ্যাপ্টারগুলোতে spec ঠিক এমন করে লেখা থাকবে:

> **Animation Spec: Linear Search**
>
> - **দৃশ্য:** একসারি box, প্রতিটাতে একটা সংখ্যা, উপরে target।
> - **ইনপুট:** array-এর মান (editable), target সংখ্যা।
> - **ধাপ:** বাম থেকে ডানে একটা কমলা pointer এগোবে। যে box-এ থামবে, সেটা হলুদ হবে (comparing)। মিলে গেলে সবুজ। না মিললে ধূসর করে সামনে এগিয়ে যাবে।
> - **নিয়ন্ত্রণ:** Play/Pause, Step, Speed, Reset।
> - **লক্ষ্য:** worst case-এ কেন পুরো array ঘেঁটে দেখতে হয়, সেটা শুধু মাথায় না, চোখে অনুভব করা। তখন O(n) মানে কী, গা দিয়ে টের পাবে।

## ৪. Complexity নোটেশন (প্রয়োজনে ফিরে ফিরে দেখো)

| নোটেশন | নাম | উদাহরণ | n = ১০০০ হলে প্রায় |
|--------|-----|--------|--------------------|
| O(1) | Constant | array index access | ১ ধাপ |
| O(log n) | Logarithmic | binary search | ১০ ধাপ |
| O(n) | Linear | একবার loop | ১ হাজার ধাপ |
| O(n log n) | Linearithmic | merge/quick sort | ১০ হাজার ধাপ |
| O(n²) | Quadratic | nested loop | ১০ লাখ ধাপ |
| O(2ⁿ) | Exponential | naive recursion | গণনার বাইরে |
| O(n!) | Factorial | permutation | ভাবনার বাইরে |

<Callout type="info">
এই টেবিলটা এখন শুধু চেনার জন্য। প্রতিটা নোটেশন আসে কোথা থেকে, নিজে কীভাবে বের করবে, সব বিস্তারিত পড়বে [Algorithmic Complexity](/docs/algorithmic-complexity) চ্যাপ্টারে।
</Callout>

## ৫. কীভাবে পড়লে সবচেয়ে ভালো লাগবে

1. **ধারাবাহিক যাও।** Section 01 থেকে শুরু করো, লাফ দিও না। প্রতিটা section আগেরটার ঘাড়ে চেপে দাঁড়িয়ে আছে।
2. **কোড নিজে টাইপ করো।** চোখে পড়লে মনে হবে সব বুঝে ফেলেছো, কিন্তু হাতে বসবে না।
3. **Animation Spec-টা মাথায় আঁকো।** ভিজ্যুয়ালাইজ করার চেষ্টা করো। পরে আসল visualizer এলে নিজের কল্পনার সাথে মিলিয়ে দেখো।
4. **অনুশীলন এড়িয়ো না।** আগে নিজে চেষ্টা করো। আটকে গেলে টপিকটা আবার পড়ো, তারপর আবার চেষ্টা।
5. **পিছিয়ে যাওয়াটা ব্যর্থতা না।** আটকে গেলে আগের section-এ ফিরে যাও। DSA শেখায় এটা প্রক্রিয়ারই অংশ।
