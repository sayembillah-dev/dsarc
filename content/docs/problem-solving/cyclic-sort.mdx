## কী শিখব

- 1..n রেঞ্জের সংখ্যা নিজের ঘরে বসিয়ে sort করা

## ধারণা

ধরো, একটা array-তে ঠিক 1 থেকে n পর্যন্ত (বা 0 থেকে n-1) সংখ্যা আছে, শুধু এলোমেলো অবস্থায়। এবার মজার কৌশলটা দেখো: প্রতিটা সংখ্যাকে তুলে তার **নিজের index-এ** (value - 1) swap করে পাঠিয়ে দাও। কোনো তুলনাই লাগে না, in-place, আর O(n)-এ কাজ শেষ। সবাই নিজের ঘরে বসে গেলে এক pass ঘুরে দেখো: যে ঘরে মিল নেই সেটাই missing, যে সংখ্যা দুইবার বসতে চায় সেটাই duplicate। এই ধরনের সমস্যায় cyclic sort-ই সেরা বন্ধু।

## কোড উদাহরণ

```js
// সাজানো + missing খোঁজা
function cyclicSort(nums) {
  let i = 0;
  const n = nums.length;
  while (i < n) {
    const correct = nums[i] - 1;             // এই সংখ্যার সঠিক ঘর
    if (nums[i] >= 1 && nums[i] <= n && nums[i] !== nums[correct]) {
      [nums[i], nums[correct]] = [nums[correct], nums[i]]; // ঘরে পাঠাই
    } else {
      i++;                                    // ঠিক আছে (বা রেঞ্জের বাইরে), পরের ঘরে
    }
  }
  return nums;
}
console.log(cyclicSort([3, 1, 5, 4, 2])); // [1,2,3,4,5]

// প্রয়োগ: missing সংখ্যা - sort-এর পর যে ঘরে মিল নেই
function findMissing(nums) {
  cyclicSort(nums);
  for (let i = 0; i < nums.length; i++) if (nums[i] !== i + 1) return i + 1;
  return nums.length + 1;
}
console.log(findMissing([4, 1, 2])); // 3
```

## কোড ব্রেকডাউন

- প্রতিটা swap অন্তত একটা সংখ্যাকে সঠিক ঘরে বসায়, তাই swap সর্বোচ্চ n-1 বার।
- রেঞ্জের বাইরের মান (যেমন missing-সমস্যায় n+1) পেলে ওটাকে যথাস্থানে রেখে এগিয়ে যাই, নাহলে infinite loop-এ পড়বো।
- sort-এর পর এক pass: যে index-এ `nums[i] !== i+1`, সেটাই উত্তরের ইঙ্গিত।

## Complexity

- O(n) time, O(1) space।
