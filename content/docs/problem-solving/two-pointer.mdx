## কী শিখব

- দুটো pointer দিয়ে O(n²) কাজ O(n)-এ নামানো

## ধারণা

ধরো, sorted একটা array থেকে এমন দুটো সংখ্যা খুঁজতে হবে যাদের যোগফল target। সব জোড়া মেলালে O(n²)। কিন্তু একটা pointer বাঁ প্রান্তে, আরেকটা ডান প্রান্তে রেখে দুজনকে কাছাকাছি আনলে? একটাই pass, O(n)। এইটাই **two pointer**: sorted array বা string-এ দুটো pointer (বেশিরভাগ সময় দুই প্রান্ত থেকে, কখনো একই দিকে) একসাথে সরিয়ে nested-loop-এর কাজ এক pass-এ শেষ করা। "জোড়া খোঁজা", palindrome, sorted-এ pair-sum, সব এতে। array sorted না থাকলে আগে [Sorting](../sorting/index.mdx) chapter-এর কোনো sort চালিয়ে নাও।

## কোড উদাহরণ

```js
// sorted array-তে target যোগফলের জোড়া - O(n)
function pairSum(sorted, target) {
  let left = 0, right = sorted.length - 1;
  while (left < right) {
    const sum = sorted[left] + sorted[right];
    if (sum === target) return [left, right];
    else if (sum < target) left++;    // ছোট -> বাঁ pointer ডানে (বড় মান দরকার)
    else right--;                     // বড় -> ডান pointer বাঁয়ে (ছোট মান দরকার)
  }
  return [];
}
console.log(pairSum([1, 3, 4, 6, 8, 11], 10)); // [2, 3]  (4+6=10)
```

## কোড ব্রেকডাউন

- array sorted, তাই sum ছোট হলে বড় মান দরকার, left++; বড় হলে right--।
- প্রতিটা pointer সর্বোচ্চ একবার পুরো array পার হয় -> O(n)।

## Complexity

- O(n) (sorted হলে); নাহলে sort O(n log n)।
