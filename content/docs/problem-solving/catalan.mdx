## কী শিখব

- Catalan ধারা কোথায় কোথায় মাথা তোলে: valid বন্ধনী, BST গোনা, বহুভুজ ত্রিভুজায়ন
- Recurrence: C(n) = C(0)·C(n-1) + C(1)·C(n-2) + ... + C(n-1)·C(0) - প্রথম জোড়া বন্ধনীর অবস্থান দিয়ে ভাঙা
- Closed form: C(n) = binom(2n, n) / (n + 1) - আর সেই ভাগটা কেন
- DP-তে O(n²), ফর্মুলায় O(n); বড় n-এ BigInt
- কোন "গোনার" সমস্যা Catalan, কোনটা নয় - চেনার উপায়

## ধারণা

মায়ের হিসাব খাতা। প্রতিটা এন্ট্রি দুই রকমের: জমা (১ টাকা এলো), খরচ (১ টাকা গেলো)। একটাই কঠিন নিয়ম - **খাতার ব্যালেন্স কখনো minus-এ নামা যাবে না**; আগে জমা না পড়লে খরচই হবে কীভাবে। মাস শেষে জমা-খরচ মিলিয়ে ব্যালেন্স শূন্য। nটা জমা আর nটা খরচের এন্ট্রি মোট কতভাবে সাজানো যায়?

n = 3 নিয়ে গুনে দেখি। জমাকে `(` আর খরচকে `)` লিখলেই ব্যাপারটা চেনা হয়ে যায় - valid বন্ধনীর স্ট্রিং:

```
((()))    (()())    (())()    ()(())    ()()()
```

মোট **৫টা**। n = 0 হলে ১টা (খালি খাতা), n = 1 হলে ১টা, n = 2 হলে ২টা, n = 3 হলে ৫টা, n = 4 হলে ১৪টা। ধারাটা: **1, 1, 2, 5, 14, 42, 132, ...** - এদের নাম **Catalan numbers**।

রহস্য হলো, একদম আলাদা দেখতে সমস্যায়ও ঠিক এই ধারাটা ফিরে ফিরে আসে। nটা distinct key দিয়ে কয়টা আলাদা আকৃতির BST বানানো যায়? Catalan। (n + 2)-বাহু বিশিষ্ট বহুভুজকে কর্ণ টেনে কয়ভাবে ত্রিভুজে ভাগা যায়? Catalan (Euler নিজে এইটা নিয়ে মাথা ঘামিয়েছিলেন)। গ্রিডে নিচে না নেমে কর্ণের ওপর দিয়ে কয়টা পথ? Catalan-ই।

## ধাপে ধাপে dry run

Recurrence-টা বন্ধনী দিয়েই বোঝা যায়। প্রথম `(`-এর জোড়া-সঙ্গী `)` কোথায় বসবে, ধরে নাও। তার **ভেতরে** যদি i জোড়া বন্ধনী থাকে, **বাইরে** থাকে n - 1 - i জোড়া। ভেতরটা নিজেই একটা ছোট valid স্ট্রিং (C(i) উপায়ে), বাইরেটাও তাই (C(n - 1 - i) উপায়ে)। i-কে 0 থেকে n - 1 পর্যন্ত ঘোরালেই:

**C(n) = Σ C(i) · C(n - 1 - i)**, যেখানে i = 0 .. n - 1, আর C(0) = 1।

| n | ভাঙনের যোগফল | হিসাব | C(n) |
|---|----------------|--------|------|
| 0 | - | খালি স্ট্রিং একটাই | 1 |
| 1 | C(0)·C(0) | 1 | 1 |
| 2 | C(0)·C(1) + C(1)·C(0) | 1 + 1 | 2 |
| 3 | C(0)·C(2) + C(1)·C(1) + C(2)·C(0) | 2 + 1 + 2 | 5 |
| 4 | C(0)·C(3) + C(1)·C(2) + C(2)·C(1) + C(3)·C(0) | 5 + 2 + 2 + 5 | 14 |
| 5 | পরের পাঁচটা পদ | 14 + 5 + 4 + 5 + 14 | 42 |

C(3)-এর সারিটা পড়ো: ভেতরে 0 জোড়া বাইরে 2 জোড়া → C(0)·C(2) = 2 (এগুলো `()(...)`-আকৃতির), ভেতরে 1 বাইরে 1 → 1 (`(...)...()`-আকৃতির), ভেতরে 2 বাইরে 0 → 2 (`((...))`-আকৃতির)। মোট 5 - উপরে গোনা পাঁচটা স্ট্রিংয়ের সাথে হুবহু মিল।

এবার এক লাইনের রাজপথ: closed form। nটা `(` আর nটা `)` মোট binom(2n, n) উপায়ে বসানো যায়। এর মধ্যে যেগুলো কোথাও ব্যালেন্স minus-এ নামায়, সেগুলো ঠিক binom(2n, n - 1)-টা (একটা চমৎকার reflection যুক্তি আছে, ফলটাই রাখি)। বিয়োগ করলে:

**C(n) = binom(2n, n) / (n + 1)**

চেক করো: binom(6, 3) = 20, ভাগ 4 → 5। মিলে গেল!

## কোড

```js
// পদ্ধতি ১: recurrence-এর সোজা DP, O(n²)
function catalanDP(n) {
  const C = new Array(n + 1).fill(0);
  C[0] = 1; // খালি স্ট্রিং একটাই - এই 1 না থাকলে সব শূন্য হয়ে যায়
  for (let k = 1; k <= n; k++) {
    let sum = 0;
    for (let i = 0; i < k; i++) {
      sum += C[i] * C[k - 1 - i]; // ভেতরে i জোড়া, বাইরে k - 1 - i জোড়া
    }
    C[k] = sum;
  }
  return C[n];
}

// পদ্ধতি ২: closed form, O(n) - binom(2n, n) ধাপে ধাপে বানাই, overflow কমাতে
function catalanFormula(n) {
  let b = 1; // i ধাপ শেষে b = binom(n + i, i) - প্রতি ধাপেই পূর্ণসংখ্যা থাকে
  for (let i = 1; i <= n; i++) {
    b = (b * (n + i)) / i;
  }
  return b / (n + 1);
}

console.assert(catalanDP(0) === 1 && catalanFormula(0) === 1, "C(0) = 1");
const expected = [1, 1, 2, 5, 14, 42, 132]; // C(0..6)
for (let n = 0; n <= 6; n++) {
  console.assert(catalanDP(n) === expected[n], `DP C(${n})`);
  console.assert(catalanFormula(n) === expected[n], `formula C(${n})`);
}
console.assert(catalanDP(10) === 16796, "C(10)");
console.assert(catalanFormula(10) === 16796, "C(10) formula");
for (let n = 0; n <= 25; n++) {
  console.assert(catalanDP(n) === catalanFormula(n), `দুই পদ্ধতির মিল C(${n})`);
}
console.log("সব assert পাস!");
```

## কোড ব্রেকডাউন, লাইনে লাইনে

**catalanDP:**

- `C[0] = 1` - সবচেয়ে গুরুত্বপূর্ণ লাইন। খালি স্ট্রিং / খালি গাছ ঠিক একটাই বৈধ; এটা 0 ধরলে recurrence-এর প্রতিটা পদ শূন্য হয়ে গোটা ধারা ধ্বসে যাবে।
- ভেতরের loop-টা হুবহু dry run-এর সারি: i জোড়া ভেতরে, k - 1 - i জোড়া বাইরে, সব i-এর যোগফল।
- স্টেট ছোট থেকে বড় ভরছি, তাই C[i] আর C[k - 1 - i] যখন দরকার তখন তৈরিই - [Dynamic Programming](./dynamic-programming.mdx) পাতার "টেবিল ভরার ক্রম" শর্ত।

**catalanFormula:**

- `b = (b * (n + i)) / i` - i-তম ধাপ শেষে b = binom(n + i, i)। সবসময় পূর্ণসংখ্যা থাকে, তাই আগে (2n)! পুরো গুনে পরে ভাগ করার overflow-বিপদ নেই।
- শেষে `b / (n + 1)` - এই ভাগ ভুলে গেলে binom(2n, n)-ই ফেরত আসবে, Catalan-এর (n + 1) গুণ বড় মান।
- সংখ্যা-সীমা: JS double-এ মাঝপথের binom(2n, n) n = 28 পর্যন্ত নিরাপদ, C(n) নিজে n = 30 পর্যন্ত। এর বেশি লাগলে নিচের BigInt ভ্যারিয়েন্ট।

## ভ্যারিয়েন্ট

- **BigInt সংস্করণ:**

```js
function catalanBig(n) {
  let b = 1n;
  const N = BigInt(n);
  for (let i = 1n; i <= N; i++) b = (b * (N + i)) / i;
  return b / (N + 1n);
}
console.assert(catalanBig(40).toString() === "2622127042276492108820", "BigInt C(40)");
```

- **BST গোনা:** nটা distinct key-এর কয়টা আকৃতির BST? root-এর বামে iটা, ডানে n - 1 - iটা node - হুবহু Catalan recurrence, তাই উত্তর C(n)। এটাই LeetCode 96।
- **স্ট্রিংগুলো আসলেই চাইলে:** সংখ্যা নয়, তালিকা - [Backtracking](./backtracking.mdx) দিয়ে প্রতি খালি ঘরে `(` বা `)` বসাও, শুধু ব্যালেন্স minus-এ নামলে নয় আর `)`-এর সংখ্যা `(` ছাড়ালে নয়। মোট বেরোবে C(n)টা - LeetCode 22।
- **বহুভুজ ত্রিভুজায়ন:** (n + 2)-বাহু বহুভুজে অপ্রতিচ্ছেদী কর্ণ টেনে ত্রিভুজে ভাগ - C(n) উপায়। Euler-এর ক্লাসিক।
- **Dyck path:** গ্রিডের কর্ণের নিচে না নেমে (0, 0) থেকে (n, n) - জমা-খরচের খাতাটাই আঁকা হয়ে গেল।

## Complexity

| পদ্ধতি | Time | Space |
|---------|------|-------|
| DP (recurrence) | O(n²) | O(n) |
| Closed form | O(n) | O(1) |
| সব বৈধ স্ট্রিং তৈরি (backtracking) | O(n · C(n)) আউটপুট | O(n) গভীরতা |

C(n) নিজেই দ্রুত বাড়ে - asymptotically প্রায় 4^n / (n^1.5 · √π)। অর্থাৎ স্ট্রিংগুলো ছাপানোর কাজ ইনপুট যেমনই হোক exponential; গোনার কাজই DP/ফর্মুলায় সস্তা।

## সাধারণ ভুল আর edge case

**১. C(0)-কে 0 ভাবা।**
"খালি স্ট্রিং কোনো স্ট্রিং-ই নয়" ভাবলে ভুল। গণনায় খালি বৈধ আয়োজন একটাই - এই 1-এর ওপর দাঁড়িয়ে পুরো recurrence।

**২. ভাঙনের index উল্টে যাওয়া।**
ভেতরে i জোড়া মানে বাইরে **n - 1 - i** জোড়া (প্রথম জোড়া বন্ধনী নিজে এক জোড়া খেয়ে ফেলেছে)। ভুলে C(n - i) লিখলে পুরো যোগফল গোলমাল।

**৩. আগে (2n)! পুরো গুনে ফেলা।**
ফ্যাক্টরিয়েল আগে বানিয়ে পরে ভাগ করলে মামুড়ি n-এই double ছাড়িয়ে যায়। ধাপে গুণ-ভাগ (প্রতি ধাপে পূর্ণসংখ্যা) রাখো, নয়তো BigInt।

**৪. শেষে (n + 1) দিয়ে ভাগ ভোলা।**
binom(2n, n) হলো **সব** বিন্যাস - ব্যালেন্স minus-এ নামা অবৈধগুলোও গোনা আছে। বৈধগুলো তার ঠিক 1/(n + 1) অংশ।

**৫. যেকোনো গোনার সমস্যাকে Catalan ভাবা।**
শর্ত মিলিয়ে দেখো: "কখনো minus নয়" বা "nested ভাঙন" কাঠামো আছে তবেই Catalan। যেমন n জোড়া বন্ধনীর **সব** স্ট্রিং (বৈধ হোক বা না) = 2^(2n) - ওটা Catalan নয়।

## অনুশীলন

- **সহজ ১:** হাতে C(6) বের করো recurrence দিয়ে। উত্তর মিলাও: 42 + 14 + 10 + 10 + 14 + 42 = **132**।
- **সহজ ২:** n = 3-এর পাঁচটা স্ট্রিংয়ের প্রতিটায় ব্যালেন্স trace লিখো (প্রতি `(`-এ +1, `)`-এ -1) আর দেখাও কোনোটাই কখনো minus-এ যায় নি।
- **মাঝারি ১:** Unique Binary Search Trees (LeetCode 96) - এক লাইনে Catalan, কিন্তু আগে নিজে recurrence-টা গাছ দিয়ে বের করার চেষ্টা করো।
- **মাঝারি ২:** Generate Parentheses (LeetCode 22)। হিন্ট: backtracking; প্রতি ধাপে `(` বসাতে পারো যতক্ষণ n-এর কম, `)` বসাতে পারো যতক্ষণ ব্যালেন্স ধনাত্মক। শেষে তালিকার length-টা C(n)-এর সাথে মিলাও।
- **কঠিন:** Handshakes That Don't Cross (LeetCode 1259) - গোল টেবিলে 2n জন, কেউর হাত কারো হাত ক্রস করবে না। হিন্ট: ১ নম্বর লোকটা কার সাথে হাত মেলাল, সেই জোড়া টেবিলকে দুই ভাগে ভাগ করে - চেনা recurrence-ই ফিরে এল।

## সারসংক্ষেপ

- Catalan ধারা 1, 1, 2, 5, 14, 42, ... - valid বন্ধনী, BST-আকৃতি, বহুভুজ ত্রিভুজায়ন, Dyck path - একই গণনা, একই ধারা।
- Recurrence: C(n) = Σ C(i)·C(n - 1 - i), ভিত্তি C(0) = 1; DP-তে O(n²)।
- Closed form: C(n) = binom(2n, n) / (n + 1) - O(n)-এ, ভাগটা ভুলো না।
- double-এর নিরাপদ সীমা: ফর্মুলার মাঝপথ n = 28, C(n) নিজে n = 30; বড় হলে BigInt।
- চেনার চাবিকাঠি: "কখনো minus নয়" ব্যালেন্স, অথবা "ভেতরে i, বাইরে n - 1 - i" nested ভাঙন।
- গোনার বদলে তালিকা চাইলে [Backtracking](./backtracking.mdx); টেবিল-চিন্তাটা [Dynamic Programming](./dynamic-programming.mdx)-ই; binom-এর অঙ্কগুলো [Number Theory](./number-theory.mdx) পাতার টুল দিয়ে।
