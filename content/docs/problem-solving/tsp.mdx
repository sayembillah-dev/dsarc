## কী শিখব

- TSP সমস্যাটা কী: প্রতিটা শহর ঠিক একবার, শেষে শুরুতে ফেরা, মোট খরচ সর্বনিম্ন
- Brute force: n! টা permutation - কেন ২০ শহরেই সৌরজগতের বয়স পেরিয়ে যায়
- Held-Karp DP: dp[bitmask][pos] স্টেট, O(n² · 2^n) সময়ে exact উত্তর
- bitmask দিয়ে "কোন কোন শহর ঘোরা হয়েছে" মনে রাখার কৌশল
- NP-hard মানে কী, আর 2^n কেন n!-এর চেয়ে দুর্দান্ত ডিল

## ধারণা

মিঠাই ডেলিভারির চাকরি করো। সকালে গোডাউন (শহর 0) থেকে বেরিয়ে ৩টা ঠিকানায় ডেলিভারি দিয়ে আবার গোডাউনে ফিরতে হবে। প্রতিটা ঠিকানা ঠিক একবার, তেল-সময় বাঁচাতে মোট দূরত্ব কমাতে হবে। শহরে শহরের দূরত্বের তালিকা হাতে আছে:

| | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| **0** | 0 | 10 | 15 | 20 |
| **1** | 10 | 0 | 35 | 25 |
| **2** | 15 | 35 | 0 | 30 |
| **3** | 20 | 25 | 30 | 0 |

শুরু শহর 0-এ ঠিক থাকলে বাকি ৩টার বিন্যাস মাত্র 3! = 6। সবগুলো গুনে ফেলি:

| রুট | খরচের যোগফল | মোট |
|------|-------------|-----|
| 0 → 1 → 2 → 3 → 0 | 10 + 35 + 30 + 20 | 95 |
| 0 → 1 → 3 → 2 → 0 | 10 + 25 + 30 + 15 | **80** |
| 0 → 2 → 1 → 3 → 0 | 15 + 35 + 25 + 20 | 95 |
| 0 → 2 → 3 → 1 → 0 | 15 + 30 + 25 + 10 | **80** |
| 0 → 3 → 1 → 2 → 0 | 20 + 25 + 35 + 15 | 95 |
| 0 → 3 → 2 → 1 → 0 | 20 + 30 + 35 + 10 | 95 |

সেরা 80, আর দুটো রুটে টাই - খেয়াল করো, ওরা একে অপরের হুবহু উল্টোদিক। ৪ শহরে জিনিষটা সহজ। কিন্তু ১৫টা শহর হলে? বিন্যাস 14! ≈ ৮৭ বিলিয়ন। ২০ শহরে 19! ≈ 10^17 - প্রতি সেকেন্ডে বিলিয়নটা গুনলেও বছর লেগে যাবে। এটাই brute force-এর দেয়াল।

কিন্তু একটা জিনিস লক্ষ করো: তুমি 0 → 1 → 2 পেরিয়ে এসেছো, তারপর যতই 3 আর 4 ঘোরো - "1 আর 2 ঘোরা শেষ, এখন 2-তে দাঁড়িয়ে আছি" এই অবস্থার পরের সেরা খরচটা বারবার একই হিসাব হচ্ছে। Overlapping subproblem - মানে [Dynamic Programming](./dynamic-programming.mdx)। শুধু স্টেটটা বানাতে হবে চমৎকারভাবে।

স্টেটের প্রথম অংশ সহজ: এখন কোন শহরে আছি। কঠিন অংশ: কোন কোন শহর **আগেই ঘোরা হয়েছে** - সেটা না জানলে একই শহরে দুইবার ঢুকে যাবে। আর সেট-জিনিস মনে রাখার সবচেয়ে সস্তা উপায়? একটা পূর্ণসংখ্যার bit-গুলো: i-তম bit জ্বলে থাকলে i-তম শহর ঘোরা। এই ট্রিকটা [Bit Manipulation](./bit-manipulation.mdx) পাতার সবচেয়ে রোমাঞ্চকর প্রয়োগ।

## ধাপে ধাপে dry run

স্টেট: **dp[mask][pos]** = mask-এ যেসব শহরের bit জ্বলে আছে সেগুলো ঘোরা হয়েছে, এখন pos-এ দাঁড়িয়ে; **বাকি সব শহর ঘুরে শহর 0-এ ফিরতে** কমপক্ষে কত খরচ। mask লিখছি ৪-bit বাইনারিতে, ডানদিকের bit শহর 0।

উত্তর বের হয় নিচ থেকে ওপরে। সবচেয়ে নিচে base: সব শহর ঘোরা (mask = 1111), তখন শুধু বাড়ি ফেরার খরচ:

| mask | pos | অবস্থা | হিসাব | dp |
|------|-----|--------|--------|----|
| 1111 | 1 | সব ঘোরা, 1-এ; শুধু ফেরা | dist[1][0] | 10 |
| 1111 | 2 | সব ঘোরা, 2-এ | dist[2][0] | 15 |
| 1111 | 3 | সব ঘোরা, 3-এ | dist[3][0] | 20 |
| 0111 | 1 | 0,1,2 ঘোরা; বাকি শুধু 3 | 25 + dp[1111][3] = 25 + 20 | 45 |
| 0111 | 2 | 0,1,2 ঘোরা; বাকি শুধু 3 | 30 + 20 | 50 |
| 1011 | 1 | 0,1,3 ঘোরা; বাকি শুধু 2 | 35 + 15 | 50 |
| 1011 | 3 | 0,1,3 ঘোরা; বাকি শুধু 2 | 30 + 15 | 45 |
| 1101 | 2 | 0,2,3 ঘোরা; বাকি শুধু 1 | 35 + 10 | 45 |
| 1101 | 3 | 0,2,3 ঘোরা; বাকি শুধু 1 | 25 + 10 | 35 |
| 0011 | 1 | 0,1 ঘোরা; বাকি 2,3 | min(35 + 50, 25 + 45) = min(85, 70) | 70 |
| 0101 | 2 | 0,2 ঘোরা; বাকি 1,3 | min(35 + 50, 30 + 35) = min(85, 65) | 65 |
| 1001 | 3 | 0,3 ঘোরা; বাকি 1,2 | min(25 + 50, 30 + 45) = min(75, 75) | 75 |
| 0001 | 0 | শুরু: শুধু 0 ঘোরা | min(10 + 70, 15 + 65, 20 + 75) | **80** |

শেষ ঘরটা পড়ো: 0 থেকে 1-এ গেলে 10 + 70 = 80, 2-তে গেলে 15 + 65 = 80, 3-তে গেলে 95। প্রথম ধাপেই দুটো সেরা পছন্দ - সেই টাই-টা আবার ধরা পড়ল। মোট স্টেট কত? 2^4 × 4 = 64-টা সম্ভব, recursion-এ প্রয়োজন পড়েছে মাত্র 13-টার। সেই বারবার-একই-হিসাবের অপচয়টাই বন্ধ হলো।

## কোড

```js
// Held-Karp: top-down memo দিয়ে - dry run-এর হুবহু অনুবাদ
function tsp(dist) {
  const n = dist.length;
  const FULL = (1 << n) - 1; // nটা bit-ই জ্বলে থাকলে সব শহর ঘোরা
  const memo = Array.from({ length: 1 << n }, () => new Array(n).fill(-1));

  function solve(mask, pos) {
    if (mask === FULL) return dist[pos][0]; // সব ঘোরা শেষ, বাড়ি ফিরো
    if (memo[mask][pos] !== -1) return memo[mask][pos];
    let best = Infinity;
    for (let city = 0; city < n; city++) {
      if ((mask & (1 << city)) === 0) { // city এখনো ঘোরা হয়নি
        const cost = dist[pos][city] + solve(mask | (1 << city), city);
        if (cost < best) best = cost;
      }
    }
    memo[mask][pos] = best;
    return best;
  }
  return solve(1, 0); // শহর 0 থেকে শুরু, তাই 0-তম bit আগে থেকেই জ্বলে আছে
}

// বেসলাইন: brute force - শুরু 0 ঠিক রেখে বাকিদের সব permutation
function tspBrute(dist) {
  const n = dist.length;
  const rest = [];
  for (let i = 1; i < n; i++) rest.push(i);
  let best = Infinity;
  (function permute(arr, l) {
    if (l === arr.length) {
      let cost = 0, prev = 0;
      for (const c of arr) { cost += dist[prev][c]; prev = c; }
      cost += dist[prev][0]; // ফিরে আসা
      if (cost < best) best = cost;
      return;
    }
    for (let i = l; i < arr.length; i++) {
      [arr[l], arr[i]] = [arr[i], arr[l]];
      permute(arr, l + 1);
      [arr[l], arr[i]] = [arr[i], arr[l]];
    }
  })(rest, 0);
  return best;
}

const dist = [
  [0, 10, 15, 20],
  [10, 0, 35, 25],
  [15, 35, 0, 30],
  [20, 25, 30, 0],
];
console.assert(tsp(dist) === 80, "dry run DP");
console.assert(tspBrute(dist) === 80, "dry run brute");
console.assert(tsp([[0]]) === 0, "এক শহর - উত্তর 0, তাই === দিয়ে চেক");
console.assert(tsp([[0, 5], [7, 0]]) === 12, "দুই শহর, asymmetric: 5 যাওয়া + 7 ফেরা");
console.assert(tsp([[0, 4, 1, 3], [4, 0, 2, 1], [1, 2, 0, 5], [3, 1, 5, 0]]) === 7, "অনুশীলনের matrix");
console.log("সব assert পাস!");
```

## কোড ব্রেকডাউন, লাইনে লাইনে

**tsp (Held-Karp):**

- `FULL = (1 << n) - 1` - nটা শহর হলে ডানদিকের nটা bit জ্বলে থাকা সংখ্যা; n = 4 হলে 15, বাইনারিতে 1111। mask এইটার সমান হলেই বুঝবে ঘোরা শেষ।
- `memo` এর সাইজ 2^n × n - প্রতিটা bit-বিন্যাসের জন্য nটা সম্ভাব্য অবস্থান। `-1` মানে এখনো হিসাব হয়নি (খরচ কখনো -1 হয় না)।
- `if (mask === FULL) return dist[pos][0];` - base case। বাকি শহর নেই, শুধু ফেরার খরচ। এই `dist[pos][0]`-টা ভুলে 0 ফেরত দিলে পুরো ট্যুরের ফেরার ভাড়াই বাদ পড়ে যাবে - সবচেয়ে কমন ভুল।
- `(mask & (1 << city)) === 0` - city-তম bit নিভা আছে কিনা; নিভা থাকলেই city প্রার্থী।
- `mask | (1 << city)` - ওই bit জ্বালিয়ে নতুন mask; "city ঘোরা হলো" মার্ক করার এক-লাইনের উপায়।
- `solve(1, 0)` - শুরুতে শুধু শহর 0 ঘোরা, তাই mask = 1 (বাইনারি ...0001)। 0 দিলে শহর 0 আবার "অঘোরা" ভেবে ভুল রুট আসবে।
- টাই ভাঙা হচ্ছে না: সেরা দুটো রুট (0 → 1 → 3 → 2 → 0 আর তার উল্টোটা) সমান 80 দেয়, আমরা শুধু খরচটা নিচ্ছি।

**tspBrute:**

- শুরু শহর 0 আটকে রেখে বাকি n - 1টার permutation - এতে প্রতিটা রুট তার উল্টোটাসহ দুইবার গোনা হয়, কিন্তু মিনিমামে কিছু আসে যায় না, আর কাজ অর্ধেকে নামে।
- Heap-এর permutation ট্রিক (swap-ফিরে-swap) - [Backtracking](./backtracking.mdx) পাতার পরিচিত ছাঁচ।

## ভ্যারিয়েন্ট

- **আসল রুটটা চাইলে:** প্রতিটা স্টেটে `parent[mask][pos]`-এ মনে রাখো কোন city-তে যাওয়া সেরা ছিল; শেষে solve(1, 0)-এর parent থেকে ধাপে ধাপে হেঁটে রুট বানাও, তারপর 0 যোগ করে ফেরত (অনুশীলনে)।
- **Nearest-neighbor heuristic:** প্রতি ধাপে সবচেয়ে কাছের অঘোরা শহরে যাও - O(n²), কিন্তু exact নয়। এই matrix-টা দেখো: [[0,3,15,3,3],[3,0,17,8,3],[15,17,0,5,11],[3,8,5,0,3],[3,3,11,3,0]]। Heuristic দেয় 0 → 1 → 4 → 3 → 2 → 0 = 3 + 3 + 3 + 5 + 15 = 29, অথচ optimal 0 → 3 → 2 → 4 → 1 → 0 = 25। শুরুর লোভি বাছাই শেষে 15-এর লম্বা লাফে শাস্তি দিয়ে দিল।
- **Approximation:** দূরত্ব triangle inequality মানলে (সরাসরি পথ কোনোদিন কুঁড়েমি পথের চেয়ে লম্বা নয়) MST-র preorder walk সবসময় 2 × optimal-এর মধ্যে থাকে।
- **dist matrix আগে বানাতে হলে:** যদি সরাসরি দূরত্ব না থেকে শহরের গ্রাফ থাকে, আগে [Floyd-Warshall](../graphs/floyd-warshall.mdx) দিয়ে all-pairs shortest path বের করো, তারপর TSP।
- **Bitmask DP অন্যত্র:** একই "সেট মনে রাখি bit-এ" ছাঁচ LC 847 (Shortest Path Visiting All Nodes), LC 943 (Shortest Superstring)-এও - এই পাতার কোড প্রায় হুবহু বসে যায়।

## Complexity

| বাস্তবায়ন | Time | Space |
|------------|------|-------|
| Brute force | O(n · n!) | O(n) stack |
| Held-Karp DP | O(n² · 2^n) | O(n · 2^n) |
| Nearest-neighbor (approx) | O(n²) | O(n) |

স্টেট 2^n × n, প্রতি স্টেটে nটা প্রার্থী পরীক্ষা - তাই n² · 2^n। গোনার অনুভূতি:

| n | n! | n² · 2^n |
|---|-----|-----------|
| 10 | ~৩৬ লাখ | ~১০^৫ |
| 15 | ~১.৩ × ১০^১২ | ~৭ × ১০^৬ |
| 20 | ~২.৪ × ১০^১৮ | ~৪ × ১০^৮ |
| 25 | ~১.৬ × ১০^২৫ | ~২ × ১০^১০ |

২০ শহরে brute force অসম্ভব, কিন্তু DP মুহূর্তে। তারপরও DP exponential - TSP **NP-hard**, মানে exact উত্তরের কোনো polynomial অ্যালগরিদম এখনো কারো জানা নেই (হয়তো নেই-ই)। 2^n-টাই exact-এর সেরা সাধারণ পথ; বড় n-এ approximation বা heuristic-এ যেতে হয়।

## সাধারণ ভুল আর edge case

**১. Base case-এ 0 ফেরত করা।**
সব শহর ঘোরা শেষে খরচ শূন্য নয় - শেষ শহর থেকে শহর 0-এ ফেরার ভাড়া `dist[pos][0]`। এটা ভুললে উত্তর প্রতিবার কম আসবে, আর রুটের আসল খরচই ধরা পড়বে না।

**২. শুরুতে mask-এ শহর 0 মার্ক করা ভোলা।**
`solve(1, 0)` ডাকতে হবে, `solve(0, 0)` নয়। নইলে শহর 0 "অঘোরা" থেকে গিয়ে মাঝপথে আবার সেখানে ঢুকে পড়বে।

**৩. Symmetric ধরে নেওয়া।**
কোডে কোথাও `dist[a][b]` আর `dist[b][a]` এক ধরা হয়নি - একমুখী সড়ক থাকলে (যাওয়া 5, ফেরা 7) কোড তাও ঠিকঠাক চলে, উপরের assert-টাই প্রমাণ। তবে রুট আর তার উল্টোটা তখন সমান দামের নাও হতে পারে।

**৪. n বাড়িয়ে bit-সীমা ছাড়ানো।**
JS-এ bitwise অপারেশন 32-bit signed-এ - n প্রায় 30-এর কাছাকাছি গেলে bit-ব্যবহার ভেঙে পড়ে। কিন্তু তার অনেক আগেই 2^n টেবিল মেমরি শেষ করে দেবে; বাস্তবে n বড় হলে approximation-এ যাও।

**৫. DP-কে "polynomial" ভেবে বসা।**
2^n, n!-এর চেয়ে অসম্ভব ভালো, কিন্তু exponential-ই। n = 30 পেরোলে এই কোডও হাল ছেড়ে দেয় - তখন nearest-neighbor, 2-opt, approximation জিনিসগুলোর পালা।

## অনুশীলন

- **সহজ ১:** হাতে সব রুট গুনো: dist = [[0,4,1,3],[4,0,2,1],[1,2,0,5],[3,1,5,0]]। উত্তর মিলাও: সেরা 7 (0 → 2 → 1 → 3 → 0 = 1 + 2 + 1 + 3, অথবা উল্টোটা)।
- **সহজ ২:** `parent[mask][pos]` যোগ করে আসল রুটটা ফেরত দাও। হিন্ট: প্রতিবার `best` আপডেট হলে parent-এ city লিখো; শেষে solve(1, 0)-এর parent অনুসরণ করে city-গুলো তুলো, সামনে 0 বসাও, শেষে 0 দিয়ে বন্ধ করো।
- **মাঝারি ১:** Shortest Path Visiting All Nodes (LeetCode 847)। হিন্ট: সেখানে শহর দুইবার যাওয়া চলে, তাই BFS-এর ভেতরে bitmask; কিন্তু (mask, pos) স্টেটটা হুবহু আজকেরটা।
- **মাঝারি ২:** tsp-এ একটা counter যোগ করে দেখো ঠিক কতটা স্টেট হিসাব হলো; তারপর n = 10, 15, 20 দিয়ে DP আর brute force-এর আসল সময় মাপো - Complexity-এর টেবিলের সাথে মিলাও।
- **কঠিন:** Find the Shortest Superstring (LeetCode 943)। হিন্ট: প্রতি জোড়া স্ট্রিং-এর overlap দিয়ে "দূরত্ব" matrix বানাও (বেশি overlap = কম খরচ), তারপর তার ওপর আজকের bitmask DP।

## সারসংক্ষেপ

- TSP: প্রতিটা শহর একবার, শেষে ফেরা, খরচ মিনিমাম। Brute force n! - ২০ শহরেই অসম্ভব।
- Held-Karp: dp[mask][pos] = mask-এর শহরগুলো ঘোরা, pos-এ দাঁড়িয়ে; বাকি ঘুরে 0-এ ফিরতে সর্বনিম্ন খরচ। O(n² · 2^n) সময়, O(n · 2^n) জায়গা।
- "কোন শহর ঘোরা" সেটটা একটা সংখ্যার bit-এ গুঁজে দেওয়া - [Bit Manipulation](./bit-manipulation.mdx)-এর কাজে লাগা।
- TSP NP-hard: exact-এর সেরা সাধারণ পথ exponential-ই; ~২০ শহর পর্যন্ত DP, তারপরে approximation (MST preorder সবসময় 2 × optimal-এর মধ্যে)।
- শহরের গ্রাফ থেকে দূরত্ব matrix চাইলে আগে [Floyd-Warshall](../graphs/floyd-warshall.mdx)।
- একই (mask, pos) ছাঁচ LC 847 আর LC 943-এও - একবার শিখলে তিনটা সমস্যা।
