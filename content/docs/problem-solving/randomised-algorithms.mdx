## কী শিখব

- এলোমেলোতা দিয়ে adversarial input থেকে রক্ষা

## ধারণা

ধরো, কেউ ইচ্ছা করে তোমার quick sort-কে worst case-এ ফেলতে চাইছে। pivot বাছাইয়ের নিয়ম জানা থাকলে প্রতিপক্ষ এমন ইনপুট বানাতেই পারে। কিন্তু pivot-টা যদি তুমি এলোমেলোভাবে বাছো? তখন ওর কোনো ফন্দি কাজ করে না। এই যে এলোমেলো পছন্দ দিয়ে নিজেকে রক্ষা করা, এটাই **randomised algorithm**। দুই রকমের: **Las Vegas** - ফল সবসময় সঠিক, শুধু সময়টা এলোমেলো (random-pivot [Quick Sort](../sorting/quick-sort.mdx)); আর **Monte Carlo** - সময় নিশ্চিত, ফলে ক্ষুদ্র ভুল-সম্ভাবনা। quick sort-এ random pivot নিলে worst case O(n²) প্রায় অসম্ভব হয়ে যায়, তাই quicksort বা [quickselect](./kth-element.mdx)-এ এটা প্রায় বাধ্যতামূলক অভ্যাস।

## কোড উদাহরণ

```js
// Fisher-Yates shuffle - প্রতিটা permutation সম-সম্ভাব্য
function shuffle(arr) {
  for (let i = arr.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1)); // 0..i-এর যেকোনো একটা
    [arr[i], arr[j]] = [arr[j], arr[i]];
  }
  return arr;
}
console.log(shuffle([1, 2, 3, 4, 5])); // যেমন [3,1,5,2,4] - প্রতিবার আলাদা
```

## কোড ব্রেকডাউন

- শেষ থেকে প্রতিটা ঘরে 0..i রেঞ্জের random index-এর সাথে swap; প্রতিটা অবস্থান সম-সম্ভাব্য বলেই এটা unbiased।
- naive "random দুই ঘর বারবার swap" biased ফল দেয় - তাই Fisher-Yates-ই স্ট্যান্ডার্ড।
- একই ধারণা [quickselect](./kth-element.mdx)-এ: pivot বাছাইয়ের আগে random index-টা শেষে swap করে নাও।

## Complexity

- Fisher-Yates O(n); random-pivot quicksort প্রত্যাশিত O(n log n)।
