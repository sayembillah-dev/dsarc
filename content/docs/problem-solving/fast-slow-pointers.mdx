## কী শিখব

- linked list/cycle-এ দুই গতির pointer

## ধারণা

কচ্ছপ-খরগোশের গল্পটা মনে আছে? এখানেও দুজন দৌড়ায়, একটা এক ধাপে (slow), আরেকটা দুই ধাপে (fast)। এবার ভাবো, ট্র্যাকটা যদি গোল হয়, মানে cycle থাকে? fast তখন একসময় slow-কে পেছন থেকে ধরেই ফেলবে, দুজন একই node-এ গিয়ে মিলবে। মিললেই বুঝবে cycle আছে। এই সরল বুদ্ধিটাই [Linked List](../linked-lists/index.mdx)-এ cycle detection বা মাঝের node খোঁজার ক্লাসিক কৌশল। নাম Floyd's cycle detection।

## কোড উদাহরণ

```js
// linked list-এ cycle আছে কিনা
function hasCycle(head) {
  let slow = head, fast = head;
  while (fast && fast.next) {
    slow = slow.next;               // ১ ধাপ
    fast = fast.next.next;          // ২ ধাপ
    if (slow === fast) return true; // মিলে গেছে -> cycle
  }
  return false;                     // fast শেষে পৌঁছেছে -> cycle নেই
}
// মাঝের node খোঁজা: fast শেষে গেলে slow ঠিক মাঝে থাকে
function middleNode(head) {
  let slow = head, fast = head;
  while (fast && fast.next) { slow = slow.next; fast = fast.next.next; }
  return slow;
}
// ডেমো: 1 -> 2 -> 3 -> 4
const n1 = { val: 1 }, n2 = { val: 2 }, n3 = { val: 3 }, n4 = { val: 4 };
n1.next = n2; n2.next = n3; n3.next = n4; n4.next = null;
console.log(middleNode(n1).val); // 3
console.log(hasCycle(n1));       // false
n4.next = n2;                    // cycle বানালাম (4 আবার 2-তে)
console.log(hasCycle(n1));       // true
```

## কোড ব্রেকডাউন

- cycle থাকলে fast "ল্যাপ" দিয়ে slow-কে ধরে (দৌড়ের ট্র্যাকের মতো)।
- fast যখন শেষে পৌঁছায়, slow তখন ঠিক অর্ধেক পথে, মানে মাঝের node-এ।

## Complexity

- O(n) time, O(1) space।
