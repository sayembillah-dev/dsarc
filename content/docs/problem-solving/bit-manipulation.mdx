## কী শিখব

- Binary representation কী, আর কেন কম্পিউটার সবকিছু এতে ভাবে
- AND, OR, XOR, NOT, shift: পাঁচটা অপারেটরের আসল কাজ
- পাঁচটা কোর ট্রিক যা এক লাইনে লুপের কাজ করে দেয়
- Brian Kernighan-এর popcount, XOR দিয়ে single number, bitmask দিয়ে সব subset
- JS-এ 32-bit signed integer-এর ফাঁদ, `>>>` আর `>>`-এর পার্থক্য

## ধারণা

ধরো, তোমার হোস্টেলের করিডরে ৮টা লাইট আছে, প্রতিটার নিজের সুইচ। সুইচ উপরে মানে অন, নিচে মানে অফ। এখন একটা মজার প্রশ্ন: এই ৮টা সুইচের পুরো অবস্থা কি একটা সংখ্যায় চাপিয়ে দেওয়া যায়?

হ্যাঁ, একদম পারা যায়। প্রতিটা সুইচকে একটা **bit** ধরো: অন = ১, অফ = ০। ৮টা সুইচ মানে ৮টা bit, মানে একটা byte। যেমন সব লাইট অফ = `00000000` = ০। সব অন = `11111111` = ২৫৫। শুধু ১ নম্বর আর ৩ নম্বর সুইচ অন = `00000101` = ৫।

এটাই **binary representation**। কম্পিউটারের ভিতরে সবকিছু, তোমার নাম থেকে ছবি থেকে গান, সব এমন ০ আর ১ দিয়ে লেখা। আর bit manipulation মানে এই ০-১-গুলোকে সরাসরি নিয়ে খেলা: কোনোটা জ্বালানো, কোনোটা নিভানো, কোনোটা উল্টে দেওয়া।

কেন এটা শিখবে? তিনটা কারণ। এক, অনেক প্রবলেমে এটা সবচেয়ে দ্রুত সমাধান, লুপের বদলে একটা অপারেশন। দুই, মেমরি কম লাগে, ৮টা boolean-এর বদলে একটাই সংখ্যা। তিন, কিছু প্রবলেম (যেমন XOR-এর জাদু) bit ছাড়া ভাবাই মুশকিল।

চারটা মূল অপারেটর আগে দেখে নিই:

| অপারেটর | নাম | কী করে | উদাহরণ |
|---------|-----|--------|--------|
| `a & b` | AND | দুটো bit-ই ১ হলে ১ | `5 & 3 = 1` (0101 & 0011 = 0001) |
| `a \| b` | OR | যেকোনো একটা ১ হলে ১ | `5 \| 3 = 7` (0101 \| 0011 = 0111) |
| `a ^ b` | XOR | দুটো আলাদা হলে ১ | `5 ^ 3 = 6` (0101 ^ 0011 = 0110) |
| `~a` | NOT | ০ হলে ১, ১ হলে ০ | `~5 = -6` (JS-এ 32-bit signed) |
| `a << k` | Left shift | সব bit k ঘর বামে, ডানে ০ | `5 << 1 = 10` (0101 → 1010) |
| `a >> k` | Right shift | সব bit k ঘর ডানে, বামে sign bit | `5 >> 1 = 2` (0101 → 0010) |
| `a >>> k` | Unsigned right shift | সব bit k ঘর ডানে, বামে ০ | `-1 >>> 1 = 2147483647` |

XOR-টা একটু বিশেষ: **একই জিনিস দুইবার XOR করলে বাতিল**। `a ^ a = 0`, `a ^ 0 = a`। এই একটা গুণের ওপর দাঁড়িয়ে আছে এক ঝাঁক প্রবলেম।

## ধাপে ধাপে: একটা পুরো dry run

পাঁচটা কোর ট্রিক হাতে চালিয়ে দেখি:

**(ক) `n & 1`: জোড় না বিজোড়?**
শেষ bit ১ হলে বিজোড়, ০ হলে জোড়। কারণ শেষ bit-ই ২⁰ = ১-এর জায়গা। বাকি সব জোড়।
- `13 & 1`: `1101 & 0001 = 0001` = ১, মানে বিজোড়।
- `12 & 1`: `1100 & 0001 = 0000` = ০, মানে জোড়।

**(খ) `n & (n - 1)`: সবচেয়ে ডানের ১-টা নিভিয়ে দাও।**
`n - 1` করলে কী হয়? সবচেয়ে ডানের ১-টা ০ হয়, আর তার ডানের সব ০ ১ হয়ে যায়। ধরো n = 12 = `1100`, তাহলে n-1 = 11 = `1011`। `1100 & 1011 = 1000` = ৮। শুধু সবচেয়ে ডানের ১-টা চলে গেল!

এই ট্রিক দিয়ে **popcount** (কতগুলো ১ আছে) বের করা যায়, Brian Kernighan-এর উপায়ে:

| ধাপ | n (binary) | n-1 (binary) | n & (n-1) | count |
|-----|------------|--------------|-----------|-------|
| শুরু | 1101 (13) | - | - | 0 |
| 1 | 1101 | 1100 | 1100 (12) | 1 |
| 2 | 1100 | 1011 | 1000 (8) | 2 |
| 3 | 1000 | 0111 | 0000 (0) | 3 |

n = 0 হলে থামো। ১৩-এ তিনটা ১ ছিল, তিনবার লুপেই শেষ।

**(গ) `n & (-n)`: সবচেয়ে ডানের ১-টা আলাদা করে দাও।**
Two's complement-এ `-n` মানে `~n + 1`। ধরো n = 12 = `1100`। `~12 = ...11110011` (32-bit-এ), তার সাথে ১ যোগ করলে `-12 = ...11110100`। `1100 & 11110100 = 0100` = ৪। শুধু সবচেয়ে ডানের ১-টা রইল, বাকি সব ০!

এটা Fenwick tree-এ কাজে লাগে (পরে দেখবে [Fenwick Tree](../advanced-structures/fenwick-tree.mdx)-এ)।

**(ঘ) `x ^ x = 0`: একই জিনিস বাতিল।**
ধরো একটা array-তে সব সংখ্যা দুইবার করে আছে, শুধু একটা একবার। XOR করলে দুইবারের সব বাতিল, একবারেরটা বেঁচে যায়। `[4, 2, 1, 2, 1]` → `4 ^ 2 ^ 1 ^ 2 ^ 1` = `4 ^ (2^2) ^ (1^1)` = `4 ^ 0 ^ 0` = `4`।

**(ঙ) `1 << k`: k-তম bit জ্বালানোর mask।**
`1 << 0 = 1` (0001), `1 << 1 = 2` (0010), `1 << 2 = 4` (0100), `1 << 3 = 8` (1000)। k-তম bit অন কিনা চেক করতে: `n & (1 << k)`। জ্বালাতে: `n | (1 << k)`। নিভাতে: `n & ~(1 << k)`।

## কোড: পুরো implementation

```js
// ১. Popcount: কতগুলো ১ আছে
function popcount(n) {
  let count = 0;
  while (n !== 0) {
    n = n & (n - 1);        // সবচেয়ে ডানের ১-টা নিভাও
    count++;
  }
  return count;
}

// ২. Power of two চেক
function isPowerOfTwo(n) {
  return n > 0 && (n & (n - 1)) === 0;  // একটাই ১ থাকলে
}

// ৩. Single number: সব দুইবার, একটা একবার (LeetCode 136)
function singleNumber(nums) {
  let result = 0;
  for (const x of nums) {
    result = result ^ x;    // একই সংখ্যা দুইবার XOR করলে বাতিল
  }
  return result;
}

// ৪. সব subset বের করা bitmask দিয়ে (LeetCode 78)
function subsets(nums) {
  const n = nums.length;
  const result = [];
  // 2^n-টা mask, প্রতিটা mask একটা subset
  for (let mask = 0; mask < (1 << n); mask++) {
    const subset = [];
    for (let i = 0; i < n; i++) {
      if (mask & (1 << i)) {   // i-তম bit অন?
        subset.push(nums[i]);
      }
    }
    result.push(subset);
  }
  return result;
}

// ৫. k-তম bit-এর খেলা
function getBit(n, k)   { return (n >> k) & 1; }
function setBit(n, k)   { return n | (1 << k); }
function clearBit(n, k) { return n & ~(1 << k); }
function toggleBit(n, k){ return n ^ (1 << k); }

// ডেমো
console.log(popcount(13));          // 3 (1101)
console.log(popcount(7));           // 3 (0111)
console.log(isPowerOfTwo(16));      // true (10000)
console.log(isPowerOfTwo(18));      // false (10010)
console.log(singleNumber([4, 2, 1, 2, 1])); // 4

console.log(subsets([1, 2, 3]));
// [[], [1], [2], [1,2], [3], [1,3], [2,3], [1,2,3]]

console.log(getBit(13, 2));   // 1 (1101-এর ২ নম্বর bit)
console.log(setBit(8, 1));    // 10 (1000 → 1010)
console.log(clearBit(13, 2)); // 9 (1101 → 1001)
console.log(toggleBit(13, 1));// 15 (1101 → 1111)
```

## ভ্যারিয়েন্ট ১: দুটো non-repeating সংখ্যা (XOR split)

LeetCode 136-এ একটা সংখ্যা একবার ছিল। যদি **দুটো** সংখ্যা একবার থাকে, বাকি সব দুইবার? সবাইকে XOR করলে পাবে `a ^ b` (দুটো একবারের XOR)। এই XOR-এ যেকোনো একটা set bit মানে a আর b সেই bit-এ আলাদা। সেই bit দিয়ে পুরো array দুই ভাগ করো, এক ভাগে a, আরেক ভাগে b। প্রতি ভাগে আলাদা XOR করলে পাবে a আর b।

```js
function singleNumberTwo(nums) {
  let xor = 0;
  for (const x of nums) xor = xor ^ x;  // xor = a ^ b

  // xor-এর সবচেয়ে ডানের set bit (a আর b আলাদা)
  const diffBit = xor & (-xor);

  let a = 0, b = 0;
  for (const x of nums) {
    if (x & diffBit) a = a ^ x;  // এই bit-এ ১ ওয়ালারা
    else             b = b ^ x;  // ০ ওয়ালারা
  }
  return [a, b];
}

console.log(singleNumberTwo([1, 2, 1, 3, 2, 5])); // [3, 5] (ক্রম যেকোনো)
```

## ভ্যারিয়েন্ট ২: temp ছাড়া swap (XOR-এর জাদু)

তিনটা XOR-এ দুটো সংখ্যা বদলে দাও:

```js
let a = 5, b = 9;
a = a ^ b;   // a = 5 ^ 9 = 12
b = a ^ b;   // b = 12 ^ 9 = 5 (পুরোনো a)
a = a ^ b;   // a = 12 ^ 5 = 9 (পুরোনো b)
console.log(a, b); // 9 5
```

কাজে লাগে, কিন্তু একটা **বিপদ** আছে। যদি a আর b একই ভ্যারিয়েবল হয় (যেমন `arr[i]` আর `arr[j]` যেখানে i === j), তাহলে `a = a ^ b` দিয়ে ০ বসে যায়, আর সব নষ্ট। তাই সবসময় `if (a !== b)` চেক রাখো, অথবা সরাসরি `[a, b] = [b, a]` ব্যবহার করো, JS-এ সেটাই নিরাপদ।

## ভ্যারিয়েন্ট ৩: counting bits (DP + bit)

0 থেকে n পর্যন্ত প্রতিটা সংখ্যার popcount বের করো। DP-র সাথে bit মিলিয়ে:

```js
function countBits(n) {
  const result = new Array(n + 1).fill(0);
  for (let i = 1; i <= n; i++) {
    // i-এর শেষ ১-টা নিভালে যেটা পাও, তার popcount + 1
    result[i] = result[i & (i - 1)] + 1;
  }
  return result;
}

console.log(countBits(5)); // [0, 1, 1, 2, 1, 2]
```

কেন কাজ করে? `i & (i - 1)` মানে i-এর সবচেয়ে ডানের ১-টা নিভে গেছে, মানে i-এর চেয়ে ছোট একটা সংখ্যা যার popcount আগেই বের করা। তার সাথে ১ যোগ।

## JS gotcha: 32-bit signed integer

JavaScript-এ সব সংখ্যা 64-bit float, কিন্তু **bitwise অপারেশন চলে 32-bit signed integer-এ**। মানে:

- `2^31 = 2147483648` থেকে বড় সংখ্যায় bitwise অপারেশন দেবে, কিন্তু আগে 32-bit-এ কেটে ফেলবে।
- `~5 = -6`, কারণ 32-bit signed-এ `~x = -(x + 1)`।
- `>>` আর `>>>` আলাদা:
  - `>>` sign bit বজায় রাখে (arithmetic shift)। `-8 >> 1 = -4`।
  - `>>>` বামে ০ ঢোকায় (logical shift)। `-8 >>> 1 = 2147483644`।

মাথায় রাখো: `n >>> 0` দিয়ে যেকোনো সংখ্যাকে unsigned 32-bit-এ রূপান্তর করা যায়। অনেক প্রবলেমে এটা কাজে লাগে।

## কোড ব্রেকডাউন: মূল popcount আর singleNumber, লাইনে লাইনে

**popcount:**

1. `while (n !== 0)` : যতক্ষণ n-এ আর ১ আছে।
2. `n = n & (n - 1)` : সবচেয়ে ডানের ১-টা নিভাও। n-1-এ সেই ১-টা ০ হয়ে যায়, আর তার ডানের সব ০ ১ হয়ে যায়। AND করলে সেই ১-টা চলে যায়, বাকি সব অপরিবর্তিত।
3. `count++` : একটা ১ নিভলো, গুনে রাখো।

**singleNumber:**

1. `let result = 0` : XOR-এর identity হলো 0, `x ^ 0 = x`।
2. `result = result ^ x` : প্রতিটা সংখ্যা XOR করো। যেগুলো দুইবার আছে, `x ^ x = 0` হয়ে বাতিল। শেষে একবারেরটা বেঁচে থাকে।

**subsets:**

1. `for (let mask = 0; mask < (1 << n); mask++)` : 0 থেকে 2ⁿ-1 পর্যন্ত প্রতিটা সংখ্যা একটা subset। mask-এর bit-গুলোই বলে দেয় কোন উপাদান আছে।
2. `if (mask & (1 << i))` : i-তম bit অন কিনা চেক। অন থাকলে i-তম উপাদান subset-এ।

## Complexity: হিসাবটা কোথা থেকে আসে

**Popcount: O(k), যেখানে k = set bit-এর সংখ্যা।** সবচেয়ে খারাপ কেসে k = 32 (32-bit-এ), মানে O(32) = O(1)। কিন্তু Brian Kernighan-এর উপায়ে শুধু যতগুলো ১ আছে, ততবারই লুপ। সব ১ থাকলে ৩২বার, সব ০ থাকলে ০বার।

**Single number: O(n) time, O(1) space।** একটা পুরো loop, প্রতিটা উপাদান একবার XOR। Extra space শুধু একটা ভ্যারিয়েবল।

**Subsets: O(n × 2ⁿ) time, O(n × 2ⁿ) space।** 2ⁿ-টা subset, প্রতিটা বানাতে O(n)। Output-এই 2ⁿ-টা subset, তাই space-ও এত।

**Count bits: O(n) time, O(n) space।** প্রতিটা সংখ্যার জন্য একটা অপারেশন, আগের রেজাল্ট ব্যবহার করে।

**Fast power (আগের পাতার সাথে লিংক): O(log n)।** প্রতি ধাপে exponent অর্ধেক, তাই log₂(n) ধাপ।

## সাধারণ ভুল আর edge case

**১. `n & (n - 1)` দিয়ে power of two চেক করতে গিয়ে `n = 0` ভুলে যাওয়া।**
`0 & (0 - 1) = 0 & (-1) = 0`, মানে `isPowerOfTwo(0)` true ফেরত দেবে, অথচ 0 কোনো power of two না। সবসময় `n > 0` চেক রাখো।

**২. `>>` আর `>>>` গুলিয়ে ফেলা।**
Negative সংখ্যায় `>>` sign bit ঠিক রাখে, `>>>` ০ ঢোকায়। `-8 >> 1 = -4`, কিন্তু `-8 >>> 1 = 2147483644`। ভুল shift ব্যবহার করলে বিশাল ভুল সংখ্যা পাবে।

**৩. `1 << 31` দিয়ে চিন্তা ভঙ্গ করা।**
`1 << 31 = -2147483648` (32-bit signed-এ), `1 << 32 = 1` (32 দিয়ে mod হয়ে যায়)। 31-এর বড় shift করলে অদ্ভুত ফল পাবে। বড় সংখ্যায় কাজ করলে `BigInt` ব্যবহার করো।

**৪. XOR swap-এ একই ভ্যারিয়েবল।**
`a` আর `b` একই memory location-এ থাকলে `a = a ^ b` দিয়ে ০ বসে যায়, আর আর ফেরত পাবে না। সবসময় `if (a !== b)` চেক করো, অথবা JS-এ `[a, b] = [b, a]` লিখো।

**৫. `~x`-এর ফল মাথায় রাখা।**
`~5 = -6`, `~(-6) = 5`, কারণ 32-bit signed-এ `~x = -(x + 1)`। Boolean-এর মতো ভাবলে বিপদ। `!` আর `~` এক না।

## অনুশীলন

- **সহজ ১:** Number of 1 Bits (LeetCode 191)। একটা সংখ্যার কতগুলো ১ bit আছে। হিন্ট: Brian Kernighan, `n & (n - 1)` লুপ।
- **সহজ ২:** Single Number (LeetCode 136)। সব সংখ্যা দুইবার, একটা একবার। হিন্ট: সবাইকে XOR করো, একই সংখ্যা বাতিল হয়ে যাবে।
- **মাঝারি ১:** Counting Bits (LeetCode 338)। 0 থেকে n পর্যন্ত প্রতিটার popcount। হিন্ট: DP, `result[i] = result[i & (i - 1)] + 1`।
- **মাঝারি ২:** Power of Two (LeetCode 231)। একটা সংখ্যা ২-এর power কিনা। হিন্ট: `n > 0 && (n & (n - 1)) === 0`, এক লাইনে।
- **কঠিন:** Single Number II (LeetCode 260)। দুটো সংখ্যা একবার, বাকি সব দুইবার। হিন্ট: সব XOR করলে `a ^ b` পাবে; একটা set bit দিয়ে array দুই ভাগ করো।

## সারসংক্ষেপ

- Bit manipulation মানে ০-১-এর বোর্ড নিয়ে খেলা; প্রতিটা bit একটা সুইচ।
- `n & 1` জোড়-বিজোড়, `n & (n - 1)` সবচেয়ে ডানের ১ নিভায়, `n & (-n)` সেটাই আলাদা করে, `x ^ x = 0` বাতিলের জাদু, `1 << k` mask বানায়।
- XOR দিয়ে single number, bitmask দিয়ে সব subset, DP+bit দিয়ে counting bits।
- JS-এ bitwise 32-bit signed-এ চলে, `>>>` আর `>>` আলাদা, বড় সংখ্যায় `BigInt`।
- এই ট্রিকগুলো অনেক প্রবলেমে O(1) space-এ O(n) সমাধান দেয়, অন্য কোনো পথে যা কঠিন।
- Bitmask-এর সবচেয়ে রোমাঞ্চকর প্রয়োগ: "কোন শহর ঘোরা হয়েছে" সেটটা bit-এ মনে রেখে TSP-কে n! থেকে 2^n-এ নামানো - [Traveling Salesman](./tsp.mdx)।
