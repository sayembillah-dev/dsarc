## কী শিখব

- সমস্যা ভাগ, সমাধান, জোড়া - তিন ধাপের কাঠামো

## ধারণা

ভাবো তো, ১০০ পৃষ্ঠার বইয়ে একটা শব্দ খুঁজতে বললে পুরো বই কি এক ধাক্কায় দেখবে? না, আগে ভাগ করে ফেলো। বড় সমস্যার ক্ষেত্রেও একই কথা। তিনটা ধাপ: (১) **Divide** - সমস্যাকে ছোট ছোট উপ-সমস্যায় ভাগ করো, (২) **Conquer** - উপ-সমস্যাগুলো recursively solve করো, (৩) **Combine** - ফলাফল জোড়া লাগাও। [Merge Sort](../sorting/merge-sort.mdx) আর [Binary Search](../searching/binary-search.mdx)-ই এই ছাঁচের চমৎকার উদাহরণ।

## কোড উদাহরণ

```js
// Divide & Conquer দিয়ে array-এর max
function maxDC(arr, low = 0, high = arr.length - 1) {
  if (low === high) return arr[low];              // base: একটা উপাদান
  const mid = Math.floor((low + high) / 2);
  const leftMax = maxDC(arr, low, mid);           // বাঁ ভাগের max
  const rightMax = maxDC(arr, mid + 1, high);     // ডান ভাগের max
  return Math.max(leftMax, rightMax);             // combine
}
console.log(maxDC([3, 7, 2, 9, 4])); // 9
```

## কোড ব্রেকডাউন

- মাঝ থেকে দুই ভাগ, প্রতি ভাগে recursion, শেষে দুই ফল থেকে সেরা।
- অনেক D&C algorithm-এর complexity **Master Theorem** দিয়ে বের করা যায় (যেমন merge sort-এ O(n log n))।

## Complexity

- সমস্যাভেদে বদলায়; এখানে O(n)।
