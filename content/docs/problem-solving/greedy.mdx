## কী শিখব

- প্রতিটা ধাপে "এই মুহূর্তে সেরা" বেছে নেওয়া

## ধারণা

ধরো, দোকানদারকে ১২৭০ টাকা ভাঙাতে বলেছো। সে কী করে? আগে সবচেয়ে বড় নোটটা দেয়, তারপর বাকিটার জন্য আবার সবচেয়ে বড়টা। প্রতি ধাপে ওই মুহূর্তের সবচেয়ে ভালো সিদ্ধান্ত (locally optimal) নিচ্ছে, এই আশায় যে শেষ পর্যন্ত সেটাই global সেরা হবে। এই পদ্ধতির নামই **greedy**। তবে খেয়াল রাখো, **সব সমস্যায় এটা কাজ করে না**, শুধু "greedy choice property" থাকলে। আর যেখানে কাজ করে, সেখানে সরল আর দ্রুত (Kruskal, Prim, Dijkstra সবই greedy, দেখো [Graphs](../graphs/index.mdx) chapter)।

## কোড উদাহরণ

```js
// Coin change - greedy, নির্দিষ্ট মুদ্রায়
// বাংলাদেশি নোট: কম সংখ্যক নোটে amount ভাঙা
function minNotes(amount) {
  const notes = [1000, 500, 100, 50, 20, 10, 5, 2, 1]; // বড় থেকে ছোট
  const used = [];
  for (const note of notes) {
    while (amount >= note) { used.push(note); amount -= note; } // যত বড় নোট সম্ভব
  }
  return used;
}
console.log(minNotes(1270)); // [1000, 100, 100, 50, 20]
```

## কোড ব্রেকডাউন

- প্রতিবার সবচেয়ে বড় সম্ভব নোট নেওয়া -> কম নোট।
- **সতর্কতা:** এই greedy শুধু "canonical" মুদ্রা-সিস্টেমে সঠিক; অদ্ভুত মুদ্রায় (যেমন [1,3,4], amount 6) greedy ভুল উত্তর দেয়, তখন [Dynamic Programming](./dynamic-programming.mdx) লাগবে।

## Complexity

- এখানে O(amount/note); সাধারণত sort-এর জন্য O(n log n)।
