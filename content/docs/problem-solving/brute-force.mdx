## কী শিখব

- সব সম্ভাবনা একে একে পরীক্ষা করা - সরল কিন্তু ধীর বেসলাইন

## ধারণা

ভাবো তো, ব্যাগের চাবি হারিয়েছো, আর টেবিলে কুড়িটা চাবি পড়ে আছে। কী করবে? একটা একটা করে সব চাবি লাগিয়ে দেখবে। কোনো চালাকি নেই, তবু কাজ হবেই। এইটাই **brute force**: সব সম্ভাব্য উত্তর একে একে পরীক্ষা করে যাওয়া। প্রায়ই ধীর (O(n²), কখনো O(2ⁿ)), কিন্তু তিনটা কারণে এটাই প্রথম পছন্দ: (১) উত্তর সবসময় সঠিক, (২) সমস্যাটা বোঝার সবচেয়ে সহজ পথ, (৩) পরে optimize করার বেসলাইন।

**নিয়ম:** আগে brute force ভাবো, তারপর optimize করো।

## কোড উদাহরণ

```js
// Two Sum - brute force
function twoSumBrute(nums, target) {
  for (let i = 0; i < nums.length; i++)
    for (let j = i + 1; j < nums.length; j++)
      if (nums[i] + nums[j] === target) return [i, j];
  return [];                          // সব জোড়া পরীক্ষা -> O(n²)
}
console.log(twoSumBrute([2, 7, 11, 15], 9)); // [0,1]
// তুলনা: hash version একই কাজ O(n)-এ করে
```

## কোড ব্রেকডাউন

- সব জোড়া (i, j) পরীক্ষা -> O(n²)।
- মনে আছে, [Hash Tables](../hash-tables/index.mdx) chapter-এ hash দিয়ে একই কাজ O(n)-এ করেছিলাম? এটাই brute force থেকে optimize-এর ক্লাসিক উদাহরণ।

## Complexity

- সমস্যাভেদে O(n²) থেকে O(2ⁿ) পর্যন্ত।
