## কী শিখব

- String অপারেশন আর অপরিবর্তনীয়তা (immutability)

## ধারণা

তুমি বন্ধুকে যে মেসেজটা পাঠালে, ওটাই একটা string, একদল character পাশাপাশি বসে আছে। কিন্তু JavaScript-এ string **immutable**। মানে? একবার বানিয়ে ফেললে ভেতরের কোনো character আর বদলাতে পারবে না। বদলাতে চাইলে নতুন একটা string বানাতে হবে। এখানেই আসল জিনিস, কারণ এই একটা নিয়ম পুরো string handling-এর ধরন বদলে দেয়।

## কোড উদাহরণ

```js
const s = "hello";

console.log(s[0]);            // "h"
console.log(s.length);        // 5
console.log(s.toUpperCase()); // "HELLO" (নতুন string)
console.log(s.slice(1, 4));   // "ell"
console.log(s.includes("ell")); // true

// string থেকে array, আবার array থেকে string (খুব দরকারি)
const arr = s.split("");    // ['h','e','l','l','o']
const back = arr.join("");  // "hello"

// string উল্টানো
const reversed = s.split("").reverse().join(""); // "olleh"
console.log(reversed);
```

## কোড ব্রেকডাউন

- `s[0]` পড়া যায় ঠিকই, কিন্তু `s[0] = "H"` লিখলে কিছুই হবে না। immutable, মনে আছে তো?
- তাহলে বদলাবে কীভাবে? string-কে array-তে ভাঙো, সেখানে বদলাও, তারপর আবার জোড়া লাগিয়ে string বানাও।
- এই `split`/`join` জোড়া string-এর সমস্যায় বারবার কাজে লাগবে, পকেটে রাখো।

## Complexity

- বেশিরভাগ string অপারেশন O(n) (n = দৈর্ঘ্য)। concatenation-এ একটু সাবধান, বারবার করলে O(n²) পর্যন্ত চলে যেতে পারে।
