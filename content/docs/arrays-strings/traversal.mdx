## কী শিখব

- array-এর উপর দক্ষতার সঙ্গে loop চালানো

## ধারণা

ভাবো তো, তোমাকে বলা হলো এক ঘর ভরা জিনিস থেকে সবচেয়ে দামি জিনিসটা খুঁজে দিতে। তুমি কী করবে? একটা একটা করে সবগুলো দেখবে, তাই না? DSA সমস্যার প্রায় ৮০% শুরু হয় ঠিক এভাবেই, array-এর উপর একবার ঘুরে আসা দিয়ে। তাই কয়েকটা দরকারি প্যাটার্ন আগেই চিনে নিই।

## কোড উদাহরণ

```js
const arr = [5, 8, 2, 10, 1];

// ১) সাধারণ traversal
for (let i = 0; i < arr.length; i++) console.log(arr[i]);

// ২) দুই দিক থেকে (two pointer, section 16-এ কাজে লাগবে)
let left = 0, right = arr.length - 1;
while (left < right) {
  console.log(arr[left], arr[right]);
  left++; right--;
}

// ৩) সর্বোচ্চ ও সর্বনিম্ন এক pass-এ
let max = arr[0], min = arr[0];
for (const x of arr) {
  if (x > max) max = x;
  if (x < min) min = x;
}
console.log("max:", max, "min:", min); // max: 10 min: 1
```

## কোড ব্রেকডাউন

- একবার loop মানে O(n), আর বেশিরভাগ সমস্যায় আমাদের আদর্শ লক্ষ্যও এটাই।
- two-pointer জাদুর মতো অনেক সমস্যা O(n²) থেকে নামিয়ে আনে O(n)-এ। কীভাবে, সেটা section 16-এ বিস্তারিত।

## Complexity

- Time: O(n), Space: O(1)।
