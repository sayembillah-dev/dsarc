ভাবো তো, তুমি একটা সিনেমা হলের টিকেট লাইনে দাঁড়িয়ে আছ। সবাই একটার পর একটা, মাঝে কোনো ফাঁক নেই। এখন কেউ জিজ্ঞেস করল, "তিন নম্বরে কে দাঁড়িয়ে আছ?" তুমি গোনা শুরু করবে না, এক নজরেই বলে দেবে। Array ঠিক এমনই কাজ করে, আর String হলো character-দের সেই একই লাইন। এই ছোট্ট ধারণার উপরেই দাঁড়িয়ে আছে DSA-র প্রায় পুরো জগৎ, তাই চলো এগুলো আগে পকেটে পুরি।

**Section Roadmap:** Array কী, memory-তে কীভাবে থাকে, অপারেশনের খরচ, 2D Array, Strings, আর common patterns-এর প্রথম ঝলক।

## সারাংশ

সহজ কথায়, Array হলো ধারাবাহিক index-ভিত্তিক লিস্ট: access O(1), কিন্তু শুরুতে বা মাঝে insert/delete O(n)। 2D array মানে গ্রিড, পুরোটা ঘুরলে O(m·n)। String হলো immutable char array, বদলাতে গেলে split/join-এর সাহায্য নিতে হয়। আর two-pointer, single-pass প্যাটার্নের গোড়াপত্তনও এখানেই।
