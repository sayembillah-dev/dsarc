## কী শিখব

- একটার পর একটা দেখে কীভাবে খুঁজতে হয়

## ধারণা

ধরো, মেঝেতে ছড়ানো বইয়ের সারি থেকে তোমার প্রিয় বইটা খুঁজছো। উপায় একটাই, প্রথমটা থেকে একটার পর একটা তুলে দেখা, যতক্ষণ না পাচ্ছো। এইটাই **Linear Search**। সবচেয়ে সহজ, কোনো পূর্বশর্ত নেই, array sorted না হলেও চলে।

## কোড উদাহরণ

```js
function linearSearch(arr, target) {
  for (let i = 0; i < arr.length; i++) {
    if (arr[i] === target) return i;  // পেলে index ফেরত
  }
  return -1;                           // না পেলে -1
}
console.log(linearSearch([4, 2, 7, 1, 9], 7)); // 2
console.log(linearSearch([4, 2, 7, 1, 9], 5)); // -1
```

## কোড ব্রেকডাউন

- প্রথম মিলেই থেমে যায়, index ফেরত দেয়।
- worst case-এ? target নেই, কিংবা একদম শেষে আছে। তখন পুরো array ঘুরতেই হয়।

## Complexity

- worst আর average O(n); best O(1); space O(1)।
