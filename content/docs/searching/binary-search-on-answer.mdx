## কী শিখব

- শুধু array নয়, "উত্তরের পরিসরে" binary search চালানো

## ধারণা

এখানেই আসল জিনিস। ধরো, তুমি নিশ্চিত উত্তরটা কোনো একটা পরিসরের মধ্যেই আছে, আর শর্তটা **monotonic** (একমুখী): উত্তর X হলে সম্ভব, X-এর বেশি হলেও সম্ভব। এমন প্যাটার্ন পেলেই উত্তরের পরিসরে binary search চালিয়ে সেরা উত্তরটা টেনে আনতে পারো। array লাগবেই না। (একটু advanced, section 16-এ আবার ফিরব।)

## কোড উদাহরণ

n-এর বর্গমূলের floor বের করা:

```js
// n-এর বর্গমূলের floor, binary search on answer
function sqrtFloor(n) {
  if (n < 2) return n;
  let low = 1, high = n, ans = 1;
  while (low <= high) {
    const mid = Math.floor((low + high) / 2);
    if (mid * mid <= n) { ans = mid; low = mid + 1; } // এখনো বাড়ানো যায়
    else high = mid - 1;                               // বেশি হয়ে গেছে
  }
  return ans;
}
console.log(sqrtFloor(17)); // 4  (4²=16 ≤ 17 < 25=5²)
```

## কোড ব্রেকডাউন

- `mid * mid <= n` শর্তটা monotonic, একটা সীমা পর্যন্ত true, তারপর সব false।
- সেই সীমাটাই binary search দিয়ে খুঁজছি, তাই O(log n)।

## Complexity

- O(log n)।
