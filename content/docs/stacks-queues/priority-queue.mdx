## কী শিখব

- অগ্রাধিকার অনুযায়ী বের হওয়া queue-এর ধারণা

## ধারণা

হাসপাতালের emergency-র কথা ভাবো। যে আগে এসেছে সে আগে ডাক্তার দেখবে, ব্যাপারটা এমন না। যার অবস্থা গুরুতর, সে-ই আগে যাবে, লাইনে শেষে দাঁড়িয়ে থাকলেও।

এটাই Priority Queue। সাধারণ queue-তে নিয়ম "আগে এলে আগে", আর এখানে নিয়ম হলো "যার priority বেশি (বা কম, use case অনুযায়ী), সে আগে"।

আসল কাজে এটা বানানো হয় **Heap** দিয়ে (section 12), যেখানে insert ও extract O(log n)। এখানে ধারণাটা বোঝার জন্য একটা সরল (কম-দক্ষ) version দেখি।

## কোড উদাহরণ

```js
class PriorityQueue {
  constructor() { this.items = []; } // {value, priority}

  enqueue(value, priority) {
    this.items.push({ value, priority });
    this.items.sort((a, b) => a.priority - b.priority); // ছোট priority আগে
  }                                                     // sort, O(n log n)
  dequeue() { return this.items.shift(); }              // সর্বোচ্চ অগ্রাধিকার বের
}

const pq = new PriorityQueue();
pq.enqueue("সাধারণ রোগী", 5);
pq.enqueue("জরুরি রোগী", 1);
pq.enqueue("মাঝারি রোগী", 3);
console.log(pq.dequeue().value); // জরুরি রোগী (priority 1)
```

## কোড ব্রেকডাউন

- এই version-এ প্রতি enqueue-তে পুরো array-টা sort হয়, তাই enqueue O(n log n)। শেখার জন্য যথেষ্ট; বাস্তবে heap ব্যবহার করব।
- Heap দিয়ে দক্ষ version section 12-তে শিখব।

## Complexity

- এই version: enqueue O(n log n); heap version: O(log n)।
