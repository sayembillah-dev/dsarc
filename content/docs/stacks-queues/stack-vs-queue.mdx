## কী শিখব

- stack আর queue-এর মৌলিক পার্থক্য

## ধারণা

দুটোকেই তো আলাদা আলাদা দেখে এসেছ। এবার পাশাপাশি রাখি, পার্থক্যটা এক নজরেই পরিষ্কার হয়ে যাবে।

| দিক | Stack | Queue |
|-----|-------|-------|
| নীতি | LIFO | FIFO |
| যোগ | push (top) | enqueue (back) |
| বাদ | pop (top) | dequeue (front) |
| প্রয়োগ | undo, DFS, recursion | scheduling, BFS |

## কোড উদাহরণ

```js
// একই ডেটা stack ও queue-তে ঢুকিয়ে বের করি
const input = [1, 2, 3];
const stack = [];
const queue = [];

for (const x of input) {
  stack.push(x);   // stack-এ উপরে জমা হচ্ছে
  queue.push(x);   // queue-তে পেছনে দাঁড়াচ্ছে
}

const fromStack = [];
while (stack.length) fromStack.push(stack.pop());

const fromQueue = [];
while (queue.length) fromQueue.push(queue.shift()); // demo-তে shift, সরলতার জন্য

console.log("Input:", input);            // [ 1, 2, 3 ]
console.log("Stack (LIFO):", fromStack); // [ 3, 2, 1 ], উল্টো ক্রম
console.log("Queue (FIFO):", fromQueue); // [ 1, 2, 3 ], একই ক্রম
```

## কোড ব্রেকডাউন

- একই input stack থেকে বের হয় **উল্টো** ক্রমে, কারণ শেষে ঢোকাটাই top-এ বসে আছে।
- আর queue থেকে বের হয় **একই** ক্রমে, কারণ যে আগে দাঁড়িয়েছে সে-ই সামনে আছে।
- এই এক পার্থক্যই LIFO বনাম FIFO-র আসল কথা।
- demo-টা সরল রাখতে `shift()` ব্যবহার করেছি; বাস্তবে দক্ষ queue-তে pointer দিয়ে dequeue কর।

## Complexity

- দুটোর মূল অপারেশনই O(1)। পার্থক্য শুধু একটাই, কোন প্রান্ত থেকে জিনিসটা বের হয়।
