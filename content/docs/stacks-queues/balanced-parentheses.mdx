## কী শিখব

- বাস্তব সমস্যায় stack-এর প্রয়োগ

## ধারণা

ভাবো তো, সামনে এমন একটা লাইন আছে: `({[]})`। এখানে সব বন্ধনী কি ঠিকঠাক জোড়ায় আছে? চোখে মেলাতে গেলে গুলিয়ে যাওয়াই স্বাভাবিক।

ব্যাপারটা আসলে সহজ। খোলা বন্ধনী পেলেই stack-এ ঢুকিয়ে রাখি। বন্ধ বন্ধনী এলে stack-এর সবার উপরেরটার সাথে জোড়া মেলাই। মিললে ঠিক আছে, না মিললেই সমস্যা। সব শেষে stack খালি থাকলে বুঝব সব জোড়া মিলে গেছে, মানে balanced।

## কোড উদাহরণ

```js
function isBalanced(str) {
  const stack = [];
  const pairs = { ')': '(', ']': '[', '}': '{' };
  for (const ch of str) {
    if (ch === '(' || ch === '[' || ch === '{') {
      stack.push(ch);                 // খোলা হলে রাখি
    } else if (ch in pairs) {
      if (stack.pop() !== pairs[ch]) return false; // জোড়া মেলে না
    }
  }
  return stack.length === 0;          // সব বন্ধ হয়েছে?
}

console.log(isBalanced("({[]})")); // true
console.log(isBalanced("([)]"));   // false
```

## কোড ব্রেকডাউন

- খোলা bracket পেলেই সোজা push, ভাবনার কিছু নেই।
- বন্ধ bracket এলে stack-এর top-এর সাথে জোড়া মেলাই। মিলে না মানেই ভুল।
- শেষে stack-এ কিছু থেকে গেলে বুঝব কোনো না কোনো বন্ধনী বন্ধই হয়নি।

## Complexity

- time O(n), space O(n)।
