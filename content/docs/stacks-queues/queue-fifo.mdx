## কী শিখব

- FIFO (First In, First Out) নীতির queue

## ধারণা

টিকিট কাউন্টারের লাইনটা ভাবো। যে আগে দাঁড়িয়েছে, সে-ই আগে টিকিট পাবে। নতুন কেউ এলে পেছনে দাঁড়াবে, মাঝখানে ঢোকার সুযোগ নেই। এটাই হলো Queue।

এই নীতির নাম FIFO (First In, First Out): যে আগে আসে, সে আগে যায়। অপারেশন দুটো: `enqueue` (পেছনে যোগ করা), `dequeue` (সামনে থেকে বের করা)।

Printer queue, call center-এর অপেক্ষমাণ কল, BFS (section 13), সব জায়গায় এই একই লাইন চলে।

এখানেই আসল জিনিস। `arr.push()` আর `arr.shift()` দিয়েও queue চলে, কিন্তু `shift()` হলো O(n), বড় queue-তে এটা ধীর হয়ে যায়। তাই object আর দুটো pointer (front/back) দিয়ে এমন version বানাই যেখানে সব অপারেশন O(1)।

## কোড উদাহরণ

```js
// naive: arr.shift() O(n), বড় queue-তে ধীর।
// দক্ষ: দুটো pointer দিয়ে O(1) dequeue।
class Queue {
  constructor() { this.items = {}; this.front = 0; this.back = 0; }

  enqueue(x) { this.items[this.back] = x; this.back++; }  // O(1)
  dequeue()  {
    if (this.isEmpty()) return undefined;
    const x = this.items[this.front];
    delete this.items[this.front];
    this.front++;
    return x;                                             // O(1)
  }
  peek()    { return this.items[this.front]; }
  isEmpty() { return this.back === this.front; }
  size()    { return this.back - this.front; }
}

const q = new Queue();
q.enqueue("A"); q.enqueue("B"); q.enqueue("C");
console.log(q.dequeue()); // A (আগে এসেছিল)
console.log(q.dequeue()); // B
console.log(q.peek());    // C
```

## কোড ব্রেকডাউন

- সহজ version-এ `arr.push()` আর `arr.shift()`-ই যথেষ্ট, কিন্তু `shift()` প্রতিবার সব এলিমেন্টকে এক ঘর সরায়, তাই O(n)।
- দক্ষ version-এ object আর front/back pointer থাকে, ফলে enqueue আর dequeue দুটোই O(1)।

## Complexity

- enqueue/dequeue O(1) (এই version-এ)।
