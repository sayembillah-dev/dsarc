## কী শিখব

- সবচেয়ে ছোট মানটা (root) বের করা, আর নিয়মটা কীভাবে ফিরিয়ে আনা হয়

## ধারণা

Min-heap-এ সবচেয়ে ছোট মান root-এ বসে আছে, তাই ওটা বের করা তো সহজ। কিন্তু root সরিয়ে দিলেই জায়গাটা ফাঁকা, পুরো কাঠামো ভেঙে পড়ে। এবার কী করবে?

কৌশলটা এমন: array-এর শেষ উপাদানটাকে তুলে root-এ বসিয়ে দাও। ও অবশ্য সেখানে মানানসই না, কারণ তার চাইল্ডদের কেউ হয়তো ওর চেয়ে ছোট। তাই ওকে নামাতে হবে: দুই চাইল্ডের মধ্যে **ছোটটার** সাথে swap, তারপর আবার তুলনা, দরকার হলে আবার swap। ঠিক জায়গা না পাওয়া পর্যন্ত এভাবেই ডুবতে থাকে। এই নামার প্রক্রিয়ার নাম **bubble down** (বা heapify down)।

## কোড উদাহরণ

```js
function extractMin(heap) {
  if (heap.length === 0) return undefined;
  const min = heap[0];
  const last = heap.pop();
  if (heap.length > 0) {
    heap[0] = last;                 // শেষটা root-এ
    let i = 0;
    const n = heap.length;
    while (true) {
      let smallest = i;
      const l = 2 * i + 1, r = 2 * i + 2;
      if (l < n && heap[l] < heap[smallest]) smallest = l;
      if (r < n && heap[r] < heap[smallest]) smallest = r;
      if (smallest === i) break;    // নিয়ম ঠিক, থামি
      [heap[i], heap[smallest]] = [heap[smallest], heap[i]]; // swap down
      i = smallest;
    }
  }
  return min;
}
const h2 = [1, 2, 6, 5, 9, 3];
console.log(extractMin(h2)); // 1 (min)
console.log(h2);             // পুনর্গঠিত heap
```

## কোড ব্রেকডাউন

- root বেরিয়ে গেলে শেষ উপাদানটা ওই ঘরে বসে, তারপর ছোট চাইল্ডের সাথে swap করে নিচে নামতে থাকে।
- খেয়াল করো, দুই চাইল্ডের **ছোটটার** সাথেই swap করতে হয়। নইলে min-heap-এর নিয়ম আবার ভেঙে যাবে।

## Complexity

- সর্বোচ্চ উচ্চতাটুকু নামা, তাই O(log n)।
