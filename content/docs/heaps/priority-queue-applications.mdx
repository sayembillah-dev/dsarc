## কী শিখব

- heap দিয়ে দক্ষ priority queue, আর তার বাস্তব প্রয়োগগুলো

## ধারণা

ধরো তুমি একটা গেম বানাচ্ছ, যেখানে শত্রুদের মধ্যে যার জীবন সবচেয়ে কম, তাকে আগে মারতে হবে। বা ধরো একটা download manager, যেখানে জরুরি ফাইলটা আগে নামবে। এমন সব জায়গায় লাগে **Priority Queue**: এখানে যে আগে এসেছে সে নয়, যে সবচেয়ে গুরুত্বপূর্ণ, সে-ই আগে বের হয়।

Section 06-এ আমরা sort করে priority queue বানিয়েছিলাম, insert-এ O(n log n) লাগত। Heap দিলে সেই একই কাজ, insert হোক বা extract, হয় O(log n)-এ। অনেক দক্ষ, তাই না?

**ক্লাসিক প্রয়োগগুলো দেখো:**

- **Top-K:** সবচেয়ে বড়/ছোট K উপাদান (size-K min-heap দিয়ে O(n log K))
- **Dijkstra** (section 13): সবচেয়ে কাছের node আগে
- **Heap sort** (section 09)
- **Median maintenance** (two heaps, section 16)

## কোড উদাহরণ

```js
// MinHeap helper (আগের পাতার ক্লাসটিই)
class MinHeap {
  constructor() { this.data = []; }
  size() { return this.data.length; }
  push(value) {
    this.data.push(value);
    let i = this.data.length - 1;
    while (i > 0) {
      const p = (i - 1) >> 1;
      if (this.data[p] <= this.data[i]) break;
      [this.data[p], this.data[i]] = [this.data[i], this.data[p]];
      i = p;
    }
  }
  pop() {
    if (this.data.length === 0) return undefined;
    const top = this.data[0];
    const last = this.data.pop();
    if (this.data.length) {
      this.data[0] = last;
      let i = 0;
      const m = this.data.length;
      while (true) {
        let s = i;
        const l = 2 * i + 1, r = 2 * i + 2;
        if (l < m && this.data[l] < this.data[s]) s = l;
        if (r < m && this.data[r] < this.data[s]) s = r;
        if (s === i) break;
        [this.data[i], this.data[s]] = [this.data[s], this.data[i]];
        i = s;
      }
    }
    return top;
  }
}

// array থেকে সবচেয়ে বড় k সংখ্যা: size-k min-heap
function topK(nums, k) {
  const heap = new MinHeap();
  for (const num of nums) {
    heap.push(num);
    if (heap.size() > k) heap.pop();  // ছোটটা ফেলে দিই, বড় k থাকে
  }
  return heap.data.sort((a, b) => b - a); // বড় থেকে ছোট
}
console.log(topK([3, 1, 5, 12, 2, 11], 3)); // [12, 11, 5]
```

## কোড ব্রেকডাউন

- ব্যাপারটা হলো, heap-টায় সবসময় সবচেয়ে বড় k-টা মানই রাখছি। size যখনই k ছাড়িয়ে যায়, root-এ বসে থাকা সবচেয়ে ছোটটাকে বিদায়।
- ফলে পুরো array sort (O(n log n)) করা লাগে না, লাগে O(n log k)। k ছোট হলে সাশ্রয়টা বিশাল।

## Complexity

- Top-K চালাতে মোট O(n log k)।
