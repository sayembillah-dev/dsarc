## সারাংশ

Heap অর্থাৎ complete binary tree, parent-child নিয়মে; min/max সবসময় root-এ (O(1))। array দিয়েই বানানো যায় (2i+1, 2i+2)। insert অর্থাৎ bubble up, extract অর্থাৎ bubble down, দুটোই O(log n)। Priority Queue-র ইঞ্জিন; Top-K, Dijkstra, heap sort-এ ব্যবহৃত।
