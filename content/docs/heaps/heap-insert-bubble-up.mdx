## কী শিখব

- heap-এ নতুন মান যোগ করা, আর নিয়মটা কীভাবে অক্ষত থাকে

## ধারণা

ধরো তুমি একটা ভিড়ের লাইনে নতুন এসেছ। শুরুতে তোমাকে সবার পেছনেই দাঁড়াতে হবে। Heap-এও নতুন মান আসলে সে প্রথমে বসে array-এর একদম শেষে, মানে tree-এর শেষ ফাঁকা ঘরে।

কিন্তু এখানেই আসল জিনিস। এই নতুন মানটা হয়তো তার parent-এর চেয়ে ছোট (min-heap-এর কথা বলছি)। তাহলে তো নিয়ম ভেঙে গেল। এবার কী? parent-এর সাথে swap করে ওকে এক ধাপ উপরে তোলো। তারপর নতুন parent-এর সাথে আবার তুলনা, দরকার হলে আবার swap। নিয়ম মেনে যাওয়া পর্যন্ত বা root পর্যন্ত মানটা এভাবে ফোমের মতো ভেসে ওঠে। এই প্রক্রিয়ার নামই **bubble up** (বা sift up)।

আর tree-এর উচ্চতা যেহেতু log n, সর্বোচ্চ log n বারই swap হবে; এর বেশি কখনো না।

## কোড উদাহরণ

```js
function insert(heap, value) {
  heap.push(value);                 // শেষে বসাই
  let i = heap.length - 1;
  while (i > 0) {
    const parent = Math.floor((i - 1) / 2);
    if (heap[parent] <= heap[i]) break; // নিয়ম ঠিক, থামি
    [heap[parent], heap[i]] = [heap[i], heap[parent]]; // swap up
    i = parent;
  }
}
const h = [1, 3, 6, 5, 9];
insert(h, 2);
console.log(h); // 2 উপরে উঠে সঠিক জায়গায় বসবে, যেমন [1,2,6,5,9,3]
```

## কোড ব্রেকডাউন

- মানটা শেষে বসার সঙ্গে সঙ্গেই heap-এর নিয়ম ভাঙতে পারে। তাই parent-এর সাথে তুলনা করে ওকে ধাপে ধাপে উপরে তুলতে হয়।
- কখন থামবে? যখনই দেখবে parent ওর চেয়ে ছোট বা সমান, মানে নিয়ম আবার ঠিক হয়ে গেছে।

## Complexity

- সর্বোচ্চ উচ্চতাটুকু ওঠা, তাই O(log n)।

## অনুশীলন

- একটা খালি heap নাও। এবার 5, 3, 8, 1 একে একে insert করো। প্রতিটা ধাপে array-টা কেমন দাঁড়াল, লিখে ফেলো।
