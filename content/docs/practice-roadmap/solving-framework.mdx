## কী শিখব

- এলোমেলোভাবে না ঝাঁপিয়ে, একটা কাঠামো মেনে সমস্যা ধরা

## ধারণা

ভালো problem solver-রা কোড লেখার আগেই ভেবে ফেলে। এই ৬টা ধাপ মেনে চলো, অচেনা সমস্যাও গোছানো লাগবে:

1. **বুঝো (Understand):** ইনপুট/আউটপুট ঠিক কী? edge case কী কী হতে পারে? উদাহরণ হাতে চালাও।
2. **উদাহরণ আঁকো:** ছোট ইনপুট নিয়ে হাতে সমাধান করো। প্যাটার্ন চোখে পড়ে যাবে।
3. **Brute force ভাবো:** আগে সবচেয়ে সরল (হয়তো ধীর) সমাধানটা ভাবো। কিছুই না থাকার চেয়ে অনেক ভালো।
4. **অপ্টিমাইজ করো:** এখানে কোন প্যাটার্ন খাটবে? ([Problem Solving](../problem-solving/index.mdx) chapter দেখো) Two Pointer? Hash Map? Sorting? Heap?
5. **কোড লেখো:** ছোট ছোট ফাংশনে ভাগ করো, নামগুলো পরিষ্কার রাখো।
6. **পরীক্ষা করো:** সাধারণ ইনপুট + edge case (খালি, ১টা উপাদান, সবচেয়ে বড়, নেগেটিভ)।

## কোড উদাহরণ

```js
// সমস্যা: array-তে দুটো সংখ্যা যাদের যোগফল = target, তাদের index দাও।

// ধাপ 3 - Brute force: সব জোড়া চেক -> O(n²)
function twoSumBrute(nums, target) {
  for (let i = 0; i < nums.length; i++)
    for (let j = i + 1; j < nums.length; j++)
      if (nums[i] + nums[j] === target) return [i, j];
}

// ধাপ 4 - অপ্টিমাইজ: Hash Map প্যাটার্ন -> O(n)
function twoSum(nums, target) {
  const seen = new Map();               // মান -> index
  for (let i = 0; i < nums.length; i++) {
    const need = target - nums[i];      // এই সংখ্যাকে কার সাথে লাগবে?
    if (seen.has(need)) return [seen.get(need), i];
    seen.set(nums[i], i);
  }
}
console.log(twoSum([2, 7, 11, 15], 9)); // [0, 1]
```

## কোড ব্রেকডাউন

- আগে [Brute Force](../problem-solving/brute-force.mdx) (O(n²))। সমস্যাটা বুঝতে আর সঠিকতা যাচাই করতে এটাই প্রথম ধাপ।
- তারপর ধরো, "প্রতিবার বাকি সংখ্যাটা খুঁজছি" -> [Hash Map](../hash-tables/index.mdx) দিলেই খোঁজা O(1), মোট O(n)।
- আর এই "brute -> optimize" যাত্রাটাই interview-তে দেখাতে হয়।
