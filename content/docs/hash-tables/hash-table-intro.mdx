## কী শিখব

- key থেকে value-র দ্রুত ম্যাপিং কীভাবে কাজ করে

## ধারণা

ধরো, ক্লাসে কেউ জিজ্ঞেস করলো, "Rahim-এর roll কত?" Array-তে খুঁজতে গেলে তোমার index লাগে, মানে সংখ্যা। কিন্তু আমরা তো নাম দিয়েই খুঁজতে চাই। ঠিক এখানেই আসে Hash Table। একটা **hash function** key-কে (এখানে "Rahim") একটা array-index-এ বদলে দেয়। তারপর তুমি সরাসরি সেই index-এ গিয়ে মানটা পেয়ে যাও। গড়ে **O(1)**।

ব্যাপারটা আসলে চেনাই। অভিধানে শব্দ দিয়ে অর্থ খোঁজো, ফোনবুকে নাম দিয়ে নম্বর। এই যে নাম দিয়ে সোজা পৌঁছে যাওয়া, সেটাই Hash Table-এর কাজ।

## কোড উদাহরণ

```js
const rollBook = new Map();
rollBook.set("Rahim", 5);   // key থেকে value, O(1)
rollBook.set("Karim", 8);

console.log(rollBook.get("Rahim")); // 5, O(1)
console.log(rollBook.has("Karim")); // true, O(1)
```

## কোড ব্রেকডাউন

- `set(key, value)` মানে key দিয়ে মানটা জমা রাখা।
- `get(key)` আগে key-এর hash বের করে, তারপর এক লাফে সেই জায়গায় পৌঁছে যায়।
- সংখ্যা index নয়, যেকোনো key দিয়েই O(1) access। এটাই Hash Table-এর আসল শক্তি।

## Complexity

- গড়ে O(1)। তবে collision বেশি হলে worst case O(n) পর্যন্ত যেতে পারে।
