## কী শিখব

- দুটো key একই index পেলে কী হয়

## ধারণা

ভাবো তো, দুটো ভিন্ন key যদি হিসাব করে একই index পেয়ে যায়? ঘটে, ঘটেই। এই ঘটনার নামই **collision**। সামলানোর পথ মূলত দুটো:

1. **Chaining:** প্রতিটা bucket-এ একটা list রাখো। collision হলে নতুন entry সেই list-এ ঢুকে যাবে। (সবচেয়ে প্রচলিত)
2. **Open Addressing:** collision হলে পরের খালি ঘরটা খুঁজে নাও (linear বা quadratic probing)।

## কোড উদাহরণ

```js
// chaining দৃষ্টান্ত: bucket[index] = [ [key,value], [key,value], ... ]
// আগের পাতার simpleHash আবার ব্যবহার করছি
function simpleHash(key, size) {
  let hash = 0;
  for (let i = 0; i < key.length; i++) {
    hash = (hash + key.charCodeAt(i) * (i + 1)) % size;
  }
  return hash;
}

const size = 4;
const buckets = Array.from({ length: size }, () => []);

function put(key, value) {
  const idx = simpleHash(key, size);
  const bucket = buckets[idx];
  const found = bucket.find(pair => pair[0] === key);
  if (found) found[1] = value;      // থাকলে আপডেট
  else bucket.push([key, value]);   // নাহলে যোগ (chain)
}
function get(key) {
  const idx = simpleHash(key, size);
  const found = buckets[idx].find(pair => pair[0] === key);
  return found ? found[1] : undefined;
}

put("a", 1); put("b", 2);
console.log(get("a")); // 1
```

## কোড ব্রেকডাউন

- একই index-এ একাধিক key এলে সেই bucket-এর ছোট list-টাতেই খুঁজতে হয়।
- collision কম রাখতে "load factor" (entry/size) চোখে রাখা হয়। নির্দিষ্ট সীমা পার হলেই table **resize** করা হয়।
- collision বাড়তে থাকলে সব entry এক bucket-এ জমে গিয়ে O(n) হয়ে যেতে পারে। তাই ভালো hash function জরুরি।

## Complexity

- গড়ে O(1)। খারাপ hash function হলে worst case O(n)।
