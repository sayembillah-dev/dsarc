## কী শিখব

- key কীভাবে সংখ্যায় (index) বদলে যায়

## ধারণা

Hash Table-এর পুরো কেল্লাফতে দাঁড়িয়ে আছে একটাই জিনিসের উপর, hash function। এটা key নেয়, ফেরত দেয় একটা সংখ্যা, সেই index। এখন ভাবো তো, ভালো hash function-এ কী কী লাগবে? তিনটা গুণ: (১) দ্রুত চলে, (২) একই key দিলে সবসময় একই ফল দেয়, (৩) মানগুলো সব জায়গায় সমান ছড়িয়ে দেয়, যাতে collision কম হয়।

## কোড উদাহরণ

```js
function simpleHash(key, size) {
  let hash = 0;
  for (let i = 0; i < key.length; i++) {
    hash = (hash + key.charCodeAt(i) * (i + 1)) % size; // অক্ষরের কোড যোগ
  }
  return hash;                       // 0 .. size-1 এর মধ্যে একটা index
}

console.log(simpleHash("Rahim", 10)); // যেমন 3
console.log(simpleHash("Karim", 10)); // যেমন 7
```

## কোড ব্রেকডাউন

- `charCodeAt(i)` দেয় প্রতিটা অক্ষরের সংখ্যা-কোড।
- `* (i + 1)` দিয়ে অবস্থানভেদে ওজন দিচ্ছি, তাই "abc" আর "cba" আলাদা hash পায়।
- `% size` ফলাফলটাকে array-এর সীমার ভেতরে আটকে রাখে।

## Complexity

- key-এর দৈর্ঘ্য k হলে O(k)। আর key সাধারণত ছোটই থাকে, তাই এটা প্রায় ধ্রুবকের মতো।
